Survey findings (§3.1)

  • The 560-cell hex plasma grid ships point-coupled (segment circle only): build 14.1 s, tracemalloc peak 143.7 MiB. Transient allocation is 267 B per pair, linear in pairs-per-chunk; the ≤500 cap chunks sources only.
  • 36% of peak (96 B/pair) is a materialised broadcast in Matrix.build_transform (np.tile of target-constant coordinate axes + origins) that np.broadcast_to removes outright.
  • The cap binds on large target grids, not plasma-plasma: 100k-target field grid ⇒ ~13 GB per chunk. The zarr store writes whole datasets (no chunk streaming), so caching never relieves build pressure.
  • Intensity: point is bandwidth-bound; rectangle and polygon compute-bound — polygon only when blocked (unblocked loses 1.9×; production block 16, flat over 8–32; blocked results are not bit-identical across block sizes, ~1e-11 spread — a stored operator is reproducible only for a fixed block).

Kernel numerics (§3.3 track)

  • Complex-step eliminated: two Urankar-variable identities (B² + Γ² = a₀²D², (r sinφ D)² + numer(β₃)² = G²B²) collapse both transcendental derivatives onto quantities the ψ evaluation already computes — ψ, Br, Bz in one real pass. 4336 → 1163 µs/pair (3.7×); cache-blocking 1597 → 858 (1.9×); 5.05× total. Equivalence to complex-step 3.2e-12; all 22 polygon oracle tests unchanged.
  • Faithful Part V groundwork (nova/biot/elliptic.py, 91 tests): the full turn is the paper's case C — every elliptic integral is COMPLETE (4×H(π/2), no incomplete F/E/Π anywhere), and cn K = 0 annihilates the radial A component, reproducing axisymmetry as a structural check. Two printed forms are ill-conditioned as printed and were re-derived by stable routes (eq 24a moments via w = 1 − dn u; eq 23 pole moment elementary over the quarter period), pinned against the printed recursions where conditioned.
  • Equivalence gate (tests/test_biotpolygonanalytic.py): converged oracle (64×96, deviation ≤ 3.9e-11 vs 96×128 everywhere including the contour, asserted); gate 1e-10 beyond 0.5 contour radii, 1e-3 inside; b₁ = 0 must reduce to the test-pinned cylinder_greens; horizontal/degenerate edges tested. Distances measured to the section CONTOUR, not the centroid.
  • Cost floor (benchmarks/analytic_cost_floor.py): 12.5–16.1 µs/pair, dominated by four complete Π per edge (not the g_p residual quadrature); check the quarter-period cn-factor cancellations early — it is the difference between a 30× and 60× win.

Tiled fixed-shape assembly (§3.2)

  • nova/biot/tiledassembly.py: memory-budget-derived tiles, padded section edge counts (zero-weight edges) and padded tail tiles — every in-tile kernel call has one identical shape (asserted by test — the vmap/shard precondition), streamed to zarr-chunk-aligned storage.
  • RAM ~48 B/pair + ~1.5 MB fixed block (vs 267 B/pair today, 5.5× leaner, plan-bounded); budget ≥4 MB/worker costs nothing.
  • Core scaling (320 cells, 64 tiles): 1.89× @2, 3.52× @4, 5.68× @8, 8.78× @16 (55% efficiency at 16 with only 4 tiles/worker).
  • Projected 2000-cell exact-everywhere build: 7.1 min on 16 cores (measured 107 µs/pair rate) — inside the ≤20 min budget with no GPU, no cutoff. With faithful Part V: ~20 s. With the three-band scheme: well under a minute serial.

Near/far evidence (§3.4 — decision input, default unchanged)

  • Negative headline: a bare centroid filament NEVER converges to the section. For a full ring the curvature the second moment multiplies is set by the MAJOR radius, so the error flattens onto an (a/R₀)² floor (~2e-5 for a plasma cell), verified out to 3000 section radii. hybrid_greens' far field inherits a ~1e-4 floor no switch value can fix.
  • A second-moment (quadrupole) corrected filament removes the floor at ~point cost (five Green's evaluations + shoelace second moments): 1e-6 beyond 3.6 (ψ) / 6.1 (B) section radii; 1e-8 beyond 8.4–15.6; bottoms near 3e-10.
  • Order-vs-distance (all components ≤1e-6 of peak): 8×24 beyond 2.2 radii; 4×16 beyond 6.8; suggested three-band scheme (16×48 / 8×24 / corrected filament) evaluates ~1% of the exact-everywhere node count on a hex lattice. Shapes stay fixed within each band.
