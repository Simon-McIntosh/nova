Canonical schema (as implemented)

Long format, one row per atomic value: coil,phase,record_kind,point_group,point_group_raw,feature,feature_raw,axis,value,uncertainty,units,is_formula — record_kind∈{fiducial,transform}; fiducial axes x,y,z (mm), transform axes dx,dy,dz (mm) / rx,ry,rz (deg); 2σ uncertainty as a column, not an axis; raw labels preserved beside normalized ones; repr-round-trip float formatting; sidecar <stem>.meta.yaml carries source identity + digests + egress layout + Metadata-sheet traceability text; sha256 over CSV bytes is the content address.
