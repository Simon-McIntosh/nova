The headline finding: the midpoint rule was an accuracy defect

The zeta integrand carries a logarithmic endpoint singularity whenever the target sits in the plane of a source corner (γ → 0): sin φ vanishes at both ends of the folded interval [0, π/2], so arcsinh β₁ ~ −ln α there. The uniform midpoint rule (~500 panels per unit α) was therefore only ~3.4×10⁻³ accurate in-plane and ~8.7×10⁻⁷ far-field — a latent accuracy defect, not merely a hot spot. Plain Gauss–Legendre at any order cannot reach 1e-12 in that plane either (convergence degrades to algebraic), which fixes the design: two fixed-node rules, not one.

What shipped

  • Production rule (nova/biot/zeta.py): Gauss–Legendre 48 nodes for |γ| ≥ 0.2 r; tanh–sinh (double-exponential, 177 nodes, half-width 3.4) below. Both node sets are data-independent — a whole target × source array evaluates as one broadcast with fixed shapes (the JAX/vmap prerequisite). Worst case over the scan: 5.5×10⁻¹⁴, 18× under the 1e-12 gate.
  • JAX Zeta: tanh–sinh unconditionally — branch-free under vmap, agrees with the numpy path to the gate.
  • Shared rule: greens._zeta (cylinder/rectangle corner kernel) delegates to the same quadrature; its private 785-point midpoint copy is gone.
  • Reference retained: zeta_midpoint kept as the independent comparison rule for the equivalence suite; reference cross-validated three ways (tanh–sinh 1025, scipy adaptive, geometric-composite GL40) to 4e-15.
  • Numerics subtleties (documented in-module): nodes stored as distance from the nearer interval end so sin φ keeps relative precision at extreme abscissae; broadcast blocked at 2¹⁶ doubles — block size dominates throughput (4× vs multi-MB blocks, order of magnitude past allocator churn).

Deviations from the brief

  • Fingerprint migration superseded. The 4-ulp corner-antiderivative pin was NOT loosened to a tolerance: with greens._zeta delegating to the shared rule, both spellings of the Part III formula in test_biotgreens.py drive the same quadrature, so the pin now cleanly isolates the algebra. Migrating as specified would have required a ~1e-4 tolerance (the midpoint reference's own error) — strictly weaker.
  • The archived “5.9 s 10×2000 bow grid solve” baseline is unreproducible: grid.solve on a winding never reaches the Bow kernel with the default filament=True, and filament=False trips a pre-existing ellippinc assertion in nova/biot/constants.py (abs(phi - k*pi) <= pi/2) unrelated to zeta. Re-timing used a point-cloud solve that genuinely exercises Bow (318k zeta elements). The assertion fix is queued as a followup.
