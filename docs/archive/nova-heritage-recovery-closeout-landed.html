Behavioural defects and analytic oracles

FrequencyResponse: append_data built a frame from [frequency, rms_power] while naming two columns. That treats each input vector as a row, so ordinary sweeps either fail on shape or become a two-row transposition; it only appeared to work when each vector happened to contain exactly two samples. The repair builds named columns, sorts by frequency and resets the row index. A closed-form first-order lag now pins one row per sample, 20 log10 |H|, the −3.0103 dB corner and the −20 dB/decade high-frequency slope.

LumpedCapacitance: the single-state solver returned (1, n) instead of the input timebase shape (n,), and loose integration tolerances could leak into the fitted time constant. The output is flattened at the state row and solved at rtol=1e-8, atol=1e-10. The analytic exponential response and recovery of C/hA are both gated.

G-EQDSK interchange

The repair aligned writer keys with what the reader actually returns and added a non-square analytic fixture so an R/Z transpose cannot hide. Round-trip comparisons use rtol=atol=1e-9. This is set by the format: scalar headers use {:16.9f} (absolute quantisation ≤5e-10) and arrays use {:16.9e} (relative quantisation ≤5e-10), so 1e-9 sits just outside the text representation's own resolution.

Example galleries

tests/test_example_galleries.py checks all 11 fenics scripts and all 15 MAST scripts. It parses and compiles each import graph and verifies every referenced nova.* module exists, while also pinning the corresponding fenics and mast optional dependency groups. Result: 28 passed in 4.53 s. The scripts are not executed in CI: several open network catalogues, build meshes, launch plotters or load local training data at module scope, so execution would be a data run rather than an import check.

Salvage register: deleted design suite

Disposition: retain the intent, not the implementation. nova/design remains available on legacy/v1 and is not restored. It depended on removed 1.x frame classes, an unvendored amigo geometry package, spreadsheet configuration and interactive plotting.

The reusable idea is a coupled optimisation: solve coil currents against a target separatrix, then vary conductor and plasma-facing geometry under current, force, clearance and build constraints while minimising length, volume or field error. A future implementation should compose the present InverseDesign current solve with explicit geometry/force constraint objects; it should not revive the historical inheritance tree or its spreadsheet-driven global state.
