Load-bearing findings

  • ISN's fastmcp~=3.2.0 hard dependency drags an MCP server stack (starlette/uvicorn/httpx/authlib/python-multipart). Mitigation here: ISN/ISNC live in the io extra, not core; nova.io modules import cleanly without the extra and io tests skip via mark_import("imas_standard_names"). The fork-hardening item (fastmcp → [mcp] extra) remains open in the ISN fork before upstream release.
  • Git-tag installs do not deliver the built ISNC catalog. ISNC ships no catalog.db in a source install (it is a CI/wheel artifact) and ISN's build hook does not bundle the full standard-names tree — so a git-tag install exposes only ISN's 41-name bundled reference catalog + the grammar. Measured on 10 real equilibrium names: 2 catalog hits, 7 grammar-provisional, 1 unknown. Full coverage needs the test-PyPI wheel path (carries catalog.db) — prioritise the fork wheel publish so the pins can flip to the primary path.
  • ISNC fork contribution identified: beta_normal (normalized beta) is rejected by the grammar and absent from the full catalog (only poloidal_beta exists). Seven other equilibrium names (magnetic-axis coordinates, boundary flux, internal inductance, poloidal beta, q-axis, toroidal current density) are present in the ISNC equilibrium YAML and are delivery gaps only — they become catalog hits under a wheel install.
