The blocking precondition — three independent components

  1. No product consumer reaches the artifact reader. artifact_geometry has 0 external importers; the only reference outside itself is its own test file. It is not wired through a benchmark seam in-tree — the passing after-path stamp builds the artifact table out-of-tree and pokes it into scripts.heldout_mse_gate_eval._TABLE_CACHE, keyed by a signature computed via read_efm_geometry, so even the seam addresses the artifact through the efm reader.
  2. No consumer selects physical identity. machine_identity is imported by exactly three modules, all inside gs/; nothing in statespace/, tokenizer/ or latent/ resolves a physical digest.
  3. There is no artifact to select. MachineArtifactGeometryReader requires explicit cache_directory + digest; ambix packages no default location, and its 15 tests skip unless both environment variables are set.

Why circuits.py is blocked despite being a real donor: the artifact publishes an evidence-typed drive map, but GeometryTable.active_circuits / circuit_drives are empty for the efm reader by design, so operator._CASE_BY_CIRCUIT_ID, built at import from circuits_mod.case_circuits(), is the live case-circuit authority on every production table. Retiring it would silently regress case-circuit classification.
