§1 — Why this exists, and what is already settled

The ring element spreads a source element's current at constant density over its whole section polygon — no jacket, no insulation, no cooling channel, no turn structure. An nturn count scales the result and never subdivides the area. That assumption was nowhere stated until now, and in its absence a four-dimensional quadrature oracle built alongside the element read as an arbiter of the real conductor. It is not one: it shares the assumption by construction.

The assumption is not neutral in sign. Concentrating the same current into discrete sub-conductors inside one outline shrinks each conductor's own geometric mean distance and raises the self inductance, so smearing over the gross outline is the lowest self inductance an outline can carry. A wound coil sits above it — and the machine description sits above the element on all three self terms, which is the direction granularity predicts.

This plan owns that question. It is not a kernel-repair task: the kernels are repaired and merged (see nova-3d-native). It is a modelling question with real decisions in it, and it was split out because a research question wearing a bugfix's clothing is what made the parent plan feel endless.

The shipped dcoil=0.25 mesh overshoots its own converged limit by +5.7e-04 H on a solenoid module — larger than the +4.76e-04 the winding is being asked to explain. So the apparently excellent agreement of the old geometric-mean-distance model at the shipped mesh size was partly a discretisation artifact: at 0.25 m the element reads 0.795495 against a machine value of 0.7954, and the agreement decays as the mesh converges. Every conductor comparison must be taken against the converged limit, and the reconstruction lane's own mesh choice is now a question this plan owns.

Separately, where the target frame declares no section — a grid point, a probe, and the PolyTarget the inductance lane builds — the target-side average is carried by that target's own subdivision instead. That is convergent, not equivalent: the reduced matrix deviates from the exact double integral by 5.7e-03, 2.2e-03, 1.2e-03 and 3.1e-04 H at 60, 134, 265 and 816 targets, and the machine gate at atol 5e-3 first holds at 134. The shipped default passes because it sits above that threshold, not because anything enforces it.

§3 — The as-built conductor geometry exists, and has not yet been used

Located 2026-07-28 in the shared machine-description database, catalogued in /work/imas/shared/imasdb/ITER_MACHINE_DESCRIPTION/3/md_summary.yaml:

111004/1  coils_non_axisymmetric  PBS-11
          Central Solenoid Modules - conductor centerlines
          provenance DET-07879-A   status active   backend hdf5
          /work/imas/shared/imasdb/ITER_MACHINE_DESCRIPTION/3/111004/1

Six coils — CS3L, CS2L, CS1L, CS1U, CS2U, CS3U — one conductor each with turns = 1.00, so the winding is resolved geometrically rather than smeared into a turn count. Roughly 1560 elements per module as cylindrical (r, phi, z) start / intermediate / end triples spanning a full turn in phi. 111003/2 carries the ex-vessel correction coils with feeders, same provider.

Three things must be resolved before it can be evaluated, and each is a real question rather than a chore:

  • The DD version is unparseable. Stamped 3.39.0-115-g143626e. ignore_unknown_dd_version=True alone silently converts to 4.1.1, which the project's DD-matching rule forbids; the correct combination is dd_version='3.39.0' plus the ignore flag. nova's own reader independently branches on <= 3.39 for this cross-section, corroborating it.
  • Feeders are in the path. For CS3U, 1496 of 1558 elements lie in the module (r 1.346–2.160 m, z 4.493–9.713 m); 57 run out to r = 18.3 m at z ≈ 9.98. They must be separated deliberately, not clipped by a magic radius.
  • The cross-section convention is undecoded. Nine points as (delta_r, delta_phi, delta_z) in the element triad, with delta_phi stepping in 45° increments and delta_r ≈ 8.1 mm roughly constant — a polar octagon of ~8 mm radius, not a 49 mm square jacket. Whether that is the cable space, an equivalent section, or a convention misread has to be settled before any number computed from it means anything.

§4 — The field coil anomaly

PF1's self term sits 4.07e-03 H below the machine description and granularity buys at most 28 % of it. Since the solenoid's gap is explained by the same mechanism at the same conductor scale, whatever is happening to PF1 is specific to it. Candidates, none yet tested: a different conductor or grading within the pack; a machine-description value computed on a different outline or turn count than the one modelled (PF1 carries a fractional 248.64 turns); an insulation or ground-wrap thickness that shrinks the current-carrying outline; or a reference computed with a different method for that coil than for the solenoid.

The honest framing: the two coils' discrepancies now have different explanations, and only one is in hand. Closing PF1 by tuning a conductor parameter would be reproducing the model we removed.

§5 — Device throughput, measured in passing

The winding operator is 1,893,376 pairs and was assembled on one H200 as a stress test of the batched path. Host and device agree to 6.8e-14 – 4.6e-12 relative on every pair, which was the check that outranked the physics. Warm throughput: quadrature 1.02–1.65 µs/pair against ~450 µs/pair host; closed form 0.242 µs/pair at tile 128. Compile 65 s cold, 6–7 s from the persistent cache in a fresh process. Two host columns need a sentence each: the closed form's host rate drifts 454 → 1032 µs/pair across the tile sweep where the quadrature's stays flat, and the host reference ran with 8 workers against a 30-CPU allocation, so any quoted ratio must state the worker count.

§ Decisions

What conductor model should the shipped inductance operator carry: uniform current over the gross section (today, with the assumption now stated), uniform current plus an explicit documented granularity correction, or a discrete-turn source built from the as-built centrelines?

Granularity is measured and robust: concentration contributes +6.72e-04 to +6.81e-04 H on a solenoid module across every spare-site placement policy, a 1.3 % spread. But it explains the solenoid and not the field coil, so a correction fitted to close both would be reproducing the geometric-mean-distance model that was just removed.

What standing does the machine-description inductance table have — oracle, cross-check, or a value with its own stated model? It reproduces the solenoid once granularity is modelled, and disagrees with the field coil by four times what granularity can buy.

The table cannot arbitrate its own construction. It is above the uniform-current continuum on all three self terms, which is the direction granularity predicts, and the solenoid gap is closed by a cable space near 30 mm. The field coil's is not closed by any plausible conductor.
