§2 — the tree overflowed on real meshes; repaired against an independent brute force

The brute-force control r-20261002T075725216430-ctta-end-to-end-brute-force (commit 72b14996b) counts superlevel components on the clipped hex-centre triangulation by host depth-first search, sharing only the mesh and field values with the tree. On every persisted compact Solov'ev certificate mesh, the tree at b187b46d4 reported 133 to 138 nodes and 255 edges with overflow set. The synthetic tree tests had not seen it.

The union-find sweep wrote through inactive padded edge slots and corrupted active parents, so regular vertices read as saddles, both arc sets were emitted unmerged, and the edge capacity ran out. Each active root is now updated once, the last usable vertex replaces the padded tail, and join arcs are subdivided for split-only events.
