  • Geometry parity is a self-comparison. tests/test_transport_geometry.py builds its "TORAX reader" reference by constructing StandardGeometryIntermediates from the same Nova record the adapter consumes. Once the reader's smoothing was replicated, machine precision is the expected answer. It validates the adapter's arithmetic; it does not validate the record. No EQDSK, CHEASE or IMAS equilibrium is read anywhere in the transport tests — GeometryType.EQDSK is a label the adapter stamps.
  • The contraction figures are inputs. 0.0020 and 0.840 are passed into _AffineWindow, "an analytic two-side map with a declared combined coupling strength". The test correctly shows one-iteration truncation error scaling with the declared contraction — a numerical-analysis result about the solver. The earlier phrase "measured, not argued" implied a statement about a real discharge and supports none.

Every input the transport surface has seen is synthetic: hand-written parabolic profiles (T_i = 8 − 7ρ², n_e = 1.2e20 − 4e19ρ²) over a single 10 ms step on a circular or analytic-shaped record. The ten-module suite completing in 158 s is itself the tell. No real machine equilibrium has ever driven TORAX through this adapter, and no output has been inspected for physical plausibility.

What is verified, and what is not here

§3's implementation work is complete and stays landed; eight of nine §4 gates are green. The plan is active, not shipped, pending the physics demonstration. Nineteen commits across sixteen nodes. Three things are worth stating plainly at the close, because each is a boundary rather than an omission.

Two declared limits. Differentiated façade calls and batched TORAX ensembles both fail closed unless the configuration is non-adaptive fixed-step: one traced computation needs a static step schedule, and a data-dependent adaptive step count has no reverse-mode path. Adaptive stepping remains available for ordinary solves. This costs the plan nothing, because the coupled window differentiates by the implicit-function adjoint at its converged fixed point — which never needs a gradient through a dynamic trip count.

One measured systematic. The coarea kernel's ⟨|∇ψ|⟩ carries a ~1.8% bias that grid refinement does not remove, set by the smoothing bandwidth rather than the stencil. It is asserted rather than hidden, and the two knobs that reduce it are recorded. Production settings were deliberately not changed on the strength of an analytic-surface test that sees only half the trade.

One unmeasured cost. The uniform-mesh guard adds a host callback per adapter construction, inside the window's iteration loop. No adapter performance gate exists in this plan; whoever first needs the window to be fast owns that measurement.

The independent geometry reference — the record is not accurate enough

Commit 5578e8ea (node eqdsk-geometry-reference). The measurement succeeded and the result is negative, which is what this node existed to find out. TORAX reads iterhybrid_cocos17.eqdsk through its own EQDSKConfig reader; Nova reads the same file through nova.io.geqdsk into the traced FSA assembly and the direct adapter. The cause is the kernel, not the adapter and not the conventions. Three independent facts pin it. Scalars, F and ψ are accurate to well under a percent, so the file is being read correctly. The three-way convention cross-check is bit-clean — the cocos11 twin is bit-identical to the pinned COCOS-17 geometry across all 26 fields and cocos02 differs by at most 9.2e−10 — so signs and provenance are right. What is left is the moment extraction: fixed-bandwidth Gaussian coarea shells against TORAX's cubic contour quadrature, with squared gradients and 1/R² weighting amplifying the discrepancy, and STEP's low aspect ratio amplifying it again. Shape errors come from grid-quantised extrema and one-cell top/bottom bands rather than interpolated contour extrema. j_total compounds all of it and then differentiates on a radial mesh TORAX itself warns about (spacing 0.0787–0.0894 against its own 0.0200 recommendation), which is why 55% appears there without contaminating the current or flux profiles.

This is the same mechanism the analytic-surface node measured at 1.8% on ⟨|∇ψ|⟩. On a real shaped equilibrium it is an order of magnitude worse; on a spherical tokamak worse again. The analytic test could not have found this, because an analytic flux surface is exactly the case a fixed-bandwidth shell handles well.

The node also found and fixed a genuine per-radian versus total-flux ∇ψ scaling at the real-EQDSK boundary — a factor no synthetic record could expose.

One caution about the test itself. Its per-field tolerances are asserted as pass/fail at up to 0.45. As written that is a characterisation baseline wearing an acceptance gate's clothing: a regression to 44% on g2g3 would pass silently. The assertions need relabelling as a baseline, and tightening as the kernel improves.
