The ten-module suite completing in 158 s is itself the tell. No real machine equilibrium has ever driven TORAX through this adapter, and no output has been inspected for physical plausibility.

What is verified, and what is not here

§3's implementation work is complete and stays landed; eight of nine §4 gates are green. The plan is active, not shipped, pending the physics demonstration. Nineteen commits across sixteen nodes. Three things are worth stating plainly at the close, because each is a boundary rather than an omission.

Two declared limits. Differentiated façade calls and batched TORAX ensembles both fail closed unless the configuration is non-adaptive fixed-step: one traced computation needs a static step schedule, and a data-dependent adaptive step count has no reverse-mode path. Adaptive stepping remains available for ordinary solves. This costs the plan nothing, because the coupled window differentiates by the implicit-function adjoint at its converged fixed point — which never needs a gradient through a dynamic trip count.

One measured systematic. The coarea kernel's ⟨|∇ψ|⟩ carries a ~1.8% bias that grid refinement does not remove, set by the smoothing bandwidth rather than the stencil. It is asserted rather than hidden, and the two knobs that reduce it are recorded. Production settings were deliberately not changed on the strength of an analytic-surface test that sees only half the trade.

One unmeasured cost. The uniform-mesh guard adds a host callback per adapter construction, inside the window's iteration loop. No adapter performance gate exists in this plan; whoever first needs the window to be fast owns that measurement.

The mechanism is the finding, and it is not order of accuracy. A local centred-tangent Hermite bicubic cannot recover the global-spline surface information both reference readers use. Fourth order on a smooth analytic surface and 20% on a real EQDSK are perfectly consistent once you see why: the two constructions converge to different surfaces, and both reference routes use the global one. A global spline solves a system in which every cell's polynomial is informed by the whole grid and is C²; a local Hermite stencil is C¹ and blind beyond its neighbours. On STEP's low-aspect-ratio grid the missing within-cell gradient structure is amplified.

So the honest conclusion is architectural rather than numerical: clipped-cell integration is not the right authority for accuracy on real equilibria, however exactly it integrates. Nova already owns the consensual authority — nova/equilibrium/flux_surface_geometry.py, whose RectBivariateSpline contour route agrees with TORAX to 0.16% on Φ. What that route does not currently offer is differentiability: it is host-side scipy, whereas the traced clipped route exists precisely to keep the implicit window gradient alive, and nova.linalg.interpolant.BSpline is a 1-D global fit, so a traced global tensor spline would have to be composed from it as two sequential solves.

Two accuracy-vs-differentiability positions, one measured trade. COCOS twins stayed below 1e−7 throughout, and the characterisation half-width narrowed from 35% to 10%.
