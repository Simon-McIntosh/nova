Reading

The API half is right: a coil-current edit never recompiles. The latency is the trip loop, not the seam, and the demonstrator case was itself a stagnating arm. Open finding carried to the bitwise-magnitude node: omitting prescribed_current (stored vector closed into the trace as a constant) versus passing the identical vector as traced data produced bitwise different receipts (digests d0d4fac5 versus ef8b86a4); the magnitude is measured before the traced path is declared the default.
