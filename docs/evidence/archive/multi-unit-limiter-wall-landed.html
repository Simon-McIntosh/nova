Every limiter unit is read and written as a typed collection (2026-09-08 07:50Z)

Node mulw-readers-lossless (local lane, then codex-terra after a lane change; commits 039cb106, 314e5676, 494088d3, merged at 5b025c5f).

The session names the wall it used (2026-09-08 09:48Z)

Node mulw-session-wall-reference (codex-terra, spec guided; commits a505f8cb, 0fe96e5b, merged at b91f8f57). Lead direction: wall geometry is campaign-stable machine description and does not belong in every session file.

Result. A session writes a reference and no coordinates: the machine identifier, the description source and its kind, a content digest, the data-dictionary version it was read at, and one row per limiter unit giving vertex count, closure and kind. The units are held in memory only long enough to compute the write-time containment receipt, so a session still reports its own labelled points, its X-points by occupiable inclusion and its strike points by exact segment membership, while a consumer dereferences the geometry through the machine readers and checks it against the digest.

Measure. A rasterless Solov'ev session round-trips the reference with its digest and unit table; the persisted MAST artifact dereferences from the reference and reproduces the operator's wall vertices; a legacy session carrying the copied ring reads as one closed vessel unit of unknown machine, source and version with that fact flagged, pinned by a test. Eighteen tests pass on the fast lane, with the artifact test skipping where the compute node does not mount it.

Consequence. This is the single schema move the corpus relabel was waiting on, and it lands together with the multi-unit shape rather than after it, so the schema moves once.

A wall is drawn as its units (2026-09-08 09:55Z)

Node mulw-painters-draw-units (codex-luna, spec guided; commits 2116d329, f09658d8, 7fe2faee, merged at 6a53ed93).

Result. The poloidal painter draws every unit as its own polyline with its own closure, dashes an open structure so it cannot be mistaken for a closed one, and never invents a join between units. Null filtering in the painter and marker containment in the pulse-design view both evaluate against the same vessel-minus-material occupiable model the solver uses, so a picture and the solve cannot disagree about what is inside the wall. The media sources carry the unit collection, and mesh cells exclude material units.

Measure. The committed figure shows the synthetic two-unit fixture and the JT-60SA five-unit description with unit-faithful closure; fifty poloidal and media tests pass, sixteen pulse-design view tests pass, and the single-closed-ring machines are unchanged.
