Under CUDA_VISIBLE_DEVICES='' and JAX_PLATFORMS=cpu, the --extra test environment imported nova.equilibrium.fixed_point and passed 9 of 9 tests in 14.09 s — so the extra that carries no CUDA still carries enough to import the spine, which was the whole point.

The test extra keeps working unchanged. Every existing uv run --extra test invocation still resolves JAX, now transitively through nova-stella[jax] rather than through a second copy of the pin. That mattered: the duplicate pin was the only reason the test lane had JAX at all, and deleting it outright would have reproduced the environment failure that prompted this work.

JAX remains out of [project.dependencies]. A bare import nova and the frame, biot and IMAS surfaces do not need it, so declaring it globally would have replaced one inaccurate declaration with another.
