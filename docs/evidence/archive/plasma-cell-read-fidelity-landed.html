Decision, 2026-09-23. The preceding containing-cell experiment is retained as a negative finding, not accepted as wall parity. Rule. A finite wall-node flux is private when polarity * (psi_node - psi_saddle) >= 0 and its height lies in a private-shadow band beyond the admitted saddle limits: Z_node < Z_lower or Z_node > Z_upper. The height-limit function is shared with topology boundary selection; no cell label contributes to the node verdict. The raster comparator samples flux bilinearly at the wall node and applies the same predicate using its admitted saddle and height limits. Every node's flux-side and height-band verdicts are recorded separately.
