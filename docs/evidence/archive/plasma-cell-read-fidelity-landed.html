Every wall node is read at its own flux

Decision, 2026-09-23. The preceding containing-cell experiment is retained as a negative finding, not accepted as wall parity. Both the containing-cell label and nearest-in-material raster label are proxies. The private flag means that the wall node lies in private flux and cannot be selected as a limited-read contact. Commit 635195df870a11e74a1376156be970ba4c716bb3 applies the rule to every node, including nodes contained by excluded-material cells.

Rule. A finite wall-node flux is private when polarity * (psi_node - psi_saddle) >= 0 and its height lies in a private-shadow band beyond the admitted saddle limits: Z_node < Z_lower or Z_node > Z_upper. The axis-facing interval between the saddle limits is not private. A side without an admitted saddle has an infinite bound and casts no shadow. The height-limit function is shared with topology boundary selection; no cell label contributes to the node verdict. The raster comparator samples flux bilinearly at the wall node and applies the same predicate using its admitted saddle and height limits. Every node's flux-side and height-band verdicts are recorded separately.
