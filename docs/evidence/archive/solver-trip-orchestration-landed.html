Decision boundary: mask-only exit is excluded. The width-1024 timing workload—one synthetic state and one current vector replicated 1024 times—is valid for fixed-shape throughput and bit identity, but not for estimating heterogeneous bank exit incidence. The decision therefore chooses between strict semantics at 1.163 ms/slice and a separately validated residual-progress policy at 0.915 ms/slice; it does not reinterpret the replicated-state run as an incidence census.
