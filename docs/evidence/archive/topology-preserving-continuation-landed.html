Recommended — state-space arclength as a numerical gauge. Carry the last two admitted corrected states and the previous oriented tangent at fixed shape; form the secant delta = x_now − x_prev, normalise by a once-declared dimensionless RMS norm over the axis-to-boundary flux span, orient it against the previous tangent with a where, and predict x_predict = x_now + ds·t. Correct normal to the secant — d_normal = d_newton − t·(t·d_newton) over a compile-time correction ladder — rather than backtracking the predictor toward zero. It survives adjudication because the source declaration and target current stay fixed, so the coordinate cannot trace the banked source-strength curve under another name, and because the existing fail-closed predicate keeps deciding admission. The arclength is explicitly a gauge: the Boolean topology class is not differentiated and no second classifier is introduced.

Rejected — source amplitude, directly refuted by the banked negative at docs/evidence/archive/dual-basin-solve-landed.html#s2-two-class-closed: two bounded composed-map campaigns, 21 rungs and 41 rungs at 5 Newton / 30 GMRES per rung, both terminated converged on the dominating limited root, terminal parity error 5.06e-2 against a 1e-10 recovery floor. Doubling the rung count changed traversal, not the basin endpoint, so the failure is path selection rather than budget.

Rejected — constrained plasma current, and this refutation is the report's most useful finding because the candidate looks independent and is not. ForwardFluxOperator.current_normalisation_amplitude computes a(x, I) = I / Σ unscaled_cell_current(x) and scaled_current_moments multiplies every zeroth and first current moment by that one common a. Target current therefore cannot move source shape, current centroid or topology independently: where a is regular the current and the amplitude are two coordinates on the same one-scalar source-scaling path, and where it is not the guarded normalisation goes non-finite and is refused. The singularity creates no branch-selection mechanism, so this candidate reintroduces the banked one under an implicit coordinate.

Also settled: nova/equilibrium/continuation.py is not an implementation seam here. It continues p' and FF' spatially from the confined domain onto declared open-flux domains — no solve-state path, no homotopy parameter joining roots, no predictor-corrector loop. The implementation contract the recommendation carries is six non-negotiable properties: fixed source/current/conductor/topology inputs along the path; loop carry holding x_prev, x_now, t_prev, arclength, step, refusal state with no Python termination on traced values; the production predicate reused for every predictor and corrector candidate; the existing Krylov-action qualification retained so a refused or zero material step promotes nothing; fixed predictor and corrector budgets with compile-time candidate axes; and a receipt exposing full residual, admitted-advance count, mean advance over the Newton-step norm, total step-equivalents, terminal topology, finite X point, secant degeneracies and every refusal reason.
