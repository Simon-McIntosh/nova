§6 — the commit hook resolves its checkout root in a linked worktree

Node acnwp-hook-worktree-root rewrites scripts/git-hooks/pre-commit to resolve the checkout it guards from the hook's own location — realpath -e of the script, then its directory's parent's parent via cd and pwd -P — instead of git -C … rev-parse --show-toplevel, which inside a linked worktree returns the hooks directory because git exports GIT_DIR while a hook runs. It adds tests/test_commit_hook_in_worktree.py, which builds a scratch repository with a git worktree add tree and shows the clean commit admitted and a file naming a worktree path refused from both the primary checkout and the linked worktree.
