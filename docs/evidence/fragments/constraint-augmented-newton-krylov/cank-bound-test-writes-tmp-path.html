The change

tests/test_reduced_newton_constraint_bounds.py wrote its admission receipt to the committed path docs/figures/constraint-augmented-newton-krylov/compensator-bound/receipt.json on every run, so a full run dirtied a committed evidence file outside the node's scope. The writer now writes beneath the pytest tmp_path, and the test asserts the committed receipt is byte-identical after the solve (RECEIPT_PATH.read_bytes() == committed). The committed receipt is not regenerated.

Note on the gate's cold compile

The CPU backend cold-compiles the fixture for ~390 s, over the repository's 300 s per-test pytest-timeout default, so the first runs timed out in backend.compile_and_load. A persistent JAX compilation cache was enabled for the runs (JAX_COMPILATION_CACHE_DIR under the run's scratch), which brings the file to ~165 s and under the default timeout.
