End-to-end brute-force control for the contour tree

Measure. An independent positive control for nova.equilibrium.contour_tree.build_contour_tree on stored fixtures: for each fixture the superlevel components of σψ on the clipped hex-centre triangulation are counted by a plain host graph search (breadth-first over the carrier's own vertices and edges) and compared with the component count the computed tree implies at each sampled level. The brute-force side shares no union-find, no merge sweep and no tree arc with the receipt; it shares only the mesh and the field values. The comparator is benchmarks/contour_tree_brute_force.py; the gate is tests/test_contour_tree_brute_force.py.

Result at the merged revision

At the virtual merge of main with this node's fixtures, every fixture agrees: the tree-implied and brute-force component counts are equal at every sampled level, and the node count minus the edge count is one.
