Carrier sweep: the duplicate-root combine is order-independent

The indexed sweep folds one contribution per carrier neighbour slot into the visited vertex's parent array. A vertex reached through several edges supplies a root to that array more than once, so the combine is a scatter over duplicate indices and resolves last-write-wins. It is deterministic only because every duplicate slot writes the same thing: an active slot writes the visited vertex, and an inactive slot writes its own root's unchanged parent. Because the writers of one root are all vertices of the same component, any surviving write resolves to that component's root, so the swept tree depends on the graph and not on the order the carrier stores its edges.

tests/test_contour_tree_scatter_equivalence.py exercises the product sweep, not a re-implemented scatter. It permutes the carrier's edge storage order, which permutes each vertex's neighbour slots without changing any neighbour set, and asserts the built tree does not move. Two invariance tests run over all twelve certificate rungs and one MAST carrier under three fixed seeds: one asserts every receipt node field (node_vertex, node_psi, node_valid, critical_type, overflow) is bit-identical; the other sweeps the join and split trees directly and asserts both arc sets and node sets are identical. A third test hand-builds the case the combine is about: a triangle in which the last visited vertex has two active neighbours sharing one root, which must sweep to a single arc with no spurious saddle.

The negative control removes the one position-dependent read in the combine. With the representative no longer chosen by slot position, the join arc set of the MAST carrier moves with the edge order and all three order-invariance seeds fail, so the equivalence the tests pin is measured, not restated.

Measured limitation, recorded rather than asserted. The merged receipt's arc set is not invariant to carrier edge order on the MAST carrier: the join and split arc sets are each invariant, and every receipt node field is bit-identical, but the merged arc set moves. That dependence is introduced after the sweep, by the split-node subdivision choosing an arc by table position, not by the duplicate-root combine these tests cover. The order test therefore asserts the swept trees' arc sets and the receipt's node fields, and the merged-arc dependence is left as a follow-on for the subdivision step.
