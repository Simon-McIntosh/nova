Carrier-indexed contour-tree sweep

Each fixed carrier edge is indexed once into a fixed-width neighbour table. A sweep visit follows and de-duplicates only that vertex's local entries; it no longer creates a matrix over the full edge buffer. The resulting work is linear in carrier vertices for bounded-degree carriers, with a visible overflow refusal if the fixed adjacency width is exceeded.
