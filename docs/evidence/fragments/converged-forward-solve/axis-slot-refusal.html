Comparison adapter refuses an invalid-axis read

The field-swap adapter read_state published a limited or diverted label from a read that licensed no axis, so a NaN axis still produced a plasma decision. It now refuses whenever the read is invalid or its axis is not finite, returning the label refused invalid axis with a NaN axis and a NaN boundary, and naming the refusal in its note. A synthetic field whose single interior extremum is a minimum under the declared positive-polarity convention (a certified loop, winding +1, index sum +1) is the exercising case: the present label path returns limited from it and fails the new test, the fixed path returns the refusal and passes.

The same adapter is driven over the twelve TCV 77549 slices with only crosscheck.py differing between the arms. The pre-repair arm completed all twelve rows: slices 0, 14, 34 and 46 publish limited, 118, 206 and 248 diverted - the seven rows that decided from a NaN axis - and 291 through 1257 coverage uncertified. The repaired arm reached slices 0 and 14 before the fence and both now refuse: done 0 diverted refused invalid axis against the base arm's done 0 diverted limited. Five of the seven previously-labelled rows and the five coverage-refused rows are unmeasured at the head and are marked so in the research record, not filled in from the synthetic case.

The near-fold persistence gate in the fixed-shape read had no suite coverage. The added test takes the double-well field under a large constant background, which leaves the stationary roots and their signed persistence unchanged while the fitted coefficients, and so the binary64 enclosure of the fitted level, grow with the background. At that background the persistence lies at the rounding scale, the root-saddle pair is unresolved, and the read publishes no axis; the same field with no background is accepted. Deleting the persistent comparison makes the refusal disappear and the test fails.

The census multi-axis retention had no suite coverage either. The gather hands the read slot zero (the axis nearest the previous root), then the saddle slots, then the remaining axes, and the read ranks them by signed level, so a dropped axis can never be chosen however strong it is. The added test builds two flux maxima of unequal level on the carrier, seeds the prior root on the shallower one, and requires the census to retain both - the seeded axis in slot zero and the stronger axis behind it. Replacing the axis slots with the seeded axis fails the retention assertion; the suite is otherwise green.

On the certified analytic carriers, the read is compared with the first-root rule by presenting the analytic axis as the single prior root. The 550-cell carrier (607 cells, built in 9.1 s) and the 2000-cell carrier (2097 cells, cold-built in 816.5 s) both return valid=false with a NaN axis: the first root is not the strongest valid extremum there, so there is no chosen axis for the two rules to differ over. The 5000-cell carrier was not read before the fence.
