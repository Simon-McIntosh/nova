For all 97 cells, Shapely returns a GeometryCollection containing a positive-area Polygon and a LineString. The reference helper _kernel_backed_field in tests/equilibrium/test_topology_read.py descends into MultiPolygon but treats any other intersection as one part; its subsequent Polygon-only filter skips the whole collection. A two-cell synthetic control has a 0.5 m² polygon-plus-line overlap and an ordinary interior polygon. The ordinary cell books positive reference current, while the mixed intersection books zero; tests/test_book_ten_thousand.py::test_reference_integrates_polygon_in_geometry_collection fails by that test ID. An independent reference integral agrees with a separately reconstructed reference to 1.32e-10 relative and with the booking to 5.985e-5 relative when the polygon part is included.

The read's valid=True and the booking's valid=True are honest for their own inputs: selected fragment areas are bounded and the booked moments match the independent integral. The fixture's result lacks a validity receipt. A reference guard checking that a positive-area clip under this positive current-density profile does not yield zero current would have refused the defective reference before its moments were compared. The fix is to integrate polygon members of GeometryCollection recursively in the reference helper, then keep the new test green. That helper is outside this node's exclusive write scope, so the test remains visibly red pending an owner change.
