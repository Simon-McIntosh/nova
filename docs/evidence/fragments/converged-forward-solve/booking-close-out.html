The control this node replaces

Before this node the membership was switched by the process environment variable NOVA_BOOK_LEVEL_MEMBERSHIP inside the fixture builder. The mutation therefore never stood in the suite: a run without the variable set exercised the axis-connected path only, and the refusal was reachable only by whoever remembered the variable. The fixture now takes membership as an argument with the axis-connected default, and test_level_membership_books_private_current builds both memberships in one process, prints both booked values, and asserts that the clause helper _assert_private_flux_current_is_zero raises on the level-membership state. The zero-current test calls the same helper, so the two ids cannot drift apart: the control and the clause share one assertion.

Declared mutation: the private-flux zero-current assertion fails when the membership is a level test that is not axis-connected. The mutation was reverted and the revert verified by a fresh run at the head revision, logs/post-revert-check.log, where the helper prints PRIVATE_FLUX_CURRENT=0 and the test passes.
