Cell 103 moment derivative: the non-finite term and the per-cell qualification

The CPU diverted 300-cell certificate row now has a finite first Krylov action and converges in two trips at residual 5.63e-15. The non-finite derivative was the sampled level-set arc taking the square root of a discriminant clamped at zero: its tangent is undefined across the band where the discriminant changes sign, which is the arrangement cell 103 held at arc slots 483 to 505. The square root is now taken off that seam with the double-where pattern, and one non-finite cell can no longer poison every cell through the current normalisation.

The expression

Staged differentiation at the same seed narrows it. Every upstream stage is finite at cell 103: the support vertices' tangent is identically zero, the flux-polynomial coefficient tangent is finite ([-0.1981, -0.6826, -0.3137, 0.2767, -0.1531, 0.0298] against the value [1.0007, 0.01215, 0.005441, 0.006906, -0.007116, -0.005519]), and the density tangent at the cell's fixed quadrature points is finite. The first non-finite tangent is the moving level-set clip vertices of SeparatrixClip: 46 of 366520 entries, all in cell 103.

Those entries are arc slots 483 to 505. Recomputing _traced_quadratic_arc's own discriminant per sample for that cell gives its smallest magnitudes at samples 481 to 507, where it changes sign: sample 482 +4.876e-08, sample 483 -2.254e-07, sample 505 +3.261e-07, sample 506 +2.970e-08. The non-finite band is exactly that sign-change band. The term is

discriminant = jnp.maximum(linear * linear - 4.0 * quadratic * zero_value, 0.0)
root_scale = jnp.sqrt(discriminant)

in _traced_quadratic_arc (nova/equilibrium/separatrix_clip.py, the root_scale line). The clamp makes the value finite on the negative side, where its tangent is zero, and leaves the positive side with a tangent of dD / (2 sqrt(D)); across the seam the tangent is undefined, so the composed tangent is non-finite while every value stays finite. This is the tangency signature the brief named, confirmed here at a sign-changing discriminant rather than an exactly-zero one.

The repair (commit 4688864ee)

Under the lead's 2026-10-24 ruling that concurrent edits to one file from separate worktrees are reconciled at integration, the expression is repaired at its site in nova/equilibrium/separatrix_clip.py with the double-where pattern: the discriminant keeps its sign, a safe value of 1.0 replaces it where it is not resolvable, and the square root is selected by that same mask.

discriminant = linear * linear - 4.0 * quadratic * zero_value
resolvable = discriminant > 0.0
safe_discriminant = jnp.where(resolvable, discriminant, 1.0)
root_scale = jnp.where(resolvable, jnp.sqrt(safe_discriminant), 0.0)

The value is unchanged — sqrt(D) where D > 0 and 0 elsewhere, which is what the clamp produced — while neither the value nor the tangent touches sqrt at zero. At the production seed, cell 103's moment tangent is 2824.328634996701 against a central difference of 2824.179876803612, relative difference 5.267e-05 on a step of 1.0e-6; no cell's moment or tangent is non-finite and the median relative difference over the 340 cells is zero. The first Krylov action of the CPU diverted 300-cell row is finite: 0 of 1536 entries non-finite, QUALIFICATION=ACCEPTED (verify-finite-tip.log, measured from a git archive of commit c4bd20313 with the revision stamped into the log header, so the code it quantifies is the code that is committed).

Per-cell non-finite mask (repaired)

Commit 497942d16 replaces the zeroing qualification with a mask that is carried out of the step. cell_moment_nonfinite in nova/equilibrium/forward_operator.py builds one boolean per cell over every component of CellCurrentMoments — cell_current, radial_moment, vertical_moment — rather than cell_current alone, because a cell can carry a finite total current and a divergent moment derivative. It returns that mask and, when the mask is concrete, the offending indices; a traced mask names none, and the mask itself is the output. Moment values are left exactly as they are, so a non-finite cell reaches the residual instead of being replaced by a zero that reads as a valid cell. The three solve paths (_internal_on_partition, normalised_current_moments, normalised_current_moments_and_observation) call refuse_non_finite_cell_moments, which returns the mask and raises CurrentNormalisationError — the owner in nova/equilibrium/source.py — carrying indices in its message whenever the state is concrete and the mask is not empty. NonFiniteCellMomentError, qualify_cell_current_moments and qualified_cell_current_moments are deleted: one named refusal, not two.

The traced normalisation amplitude no longer signals refusal with jnp.nan. current_normalisation_admissible returns the admissibility flag as an output of the step, and current_normalisation_amplitude returns jnp.zeros_like(target) where that flag is false, so an inadmissible amplitude never scales every cell by NaN; an eager evaluation still raises CurrentNormalisationError at the call.

Ten tests in tests/test_cell_moment_derivative_finite.py cover the behaviour and pass in gate-unit-mask.log (10 passed, EXIT=0). A planted NaN in one cell's radial moment, with that cell's cell_current finite, is flagged by the mask at (103,) with no other cell flagged and no value altered, and is refused by CurrentNormalisationError with indices == (103,) and the index in the message; a non-finite cell_current is refused the same way; a finite state is admitted; a jax.jit-traced step reports the flag, the first offending index and the count across the jit boundary, and the host boundary refuses from the index that traced step reported; an admissible amplitude is flagged admissible and equals 0.5, an inadmissible one is flagged and raises eagerly, and the traced amplitude is finite under a NaN total. The CPU diverted 300-cell row still converges in trip_count 2 at 5.626976272072871e-15 with EXIT=0 (row-mask.log).

The mask reaches the host through the three solve paths above. The driver seam that gs.apply (gs.py:34), the jitted reduced map (reduced_newton.py:353) and the certificate jvp (solovev_certificate.py:996) return is a bare jax.Array, so an array-only step cannot carry a mask out of it, and those three driver modules are outside this round's write scope. The refusal is therefore complete inside forward_operator.py — no cell is zeroed at any path and a concrete state is refused by index at each of them — while threading the traced mask through the driver seam is remaining work that needs a scope extension.
