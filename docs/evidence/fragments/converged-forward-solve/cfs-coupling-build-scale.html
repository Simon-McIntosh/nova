cfs-coupling-build-scale — device-batched coupling assembly

Blocked on acceptance criterion (2). The assembly was extracted and batched on the device (criterion 1), but the batched blocks do not equal the host analytic builder within the required 1e-13 relative. The gap is a property of the packed kernel in nova/biot/polygonanalytic.py, which this node is fenced out of editing, so criteria (3) and (4) were not attempted.

What changed

  • New scripts/analytic_oracle_fixtures/coupling_build.py exposes build_flux_blocks, which assembles the three exact flux rows (uniform, radial, vertical) for one target family through the traced moments kernel of nova.biot.tiledassembly.tile_evaluator — one compiled program per block shape, tiled over (target, section).
  • measure.py build_machine now calls it for the grid, wall and sample families in place of the per-section polygon_analytic_flux_moments_batched host reduction.
  • cache_identity gains a builder_revision digest over the assembly sources, and cached_machine resolves its store root from NOVA_ANALYTIC_ORACLE_CACHE so a later node can point the cache at a GPFS root without editing the fixture.
  • tests/test_coupling_build.py carries the identity row and a negative control that perturbs one block entry by 1e-9 relative and asserts the identity check catches it.

The gate: device blocks against the host builder

One 550-cell synthetic hex family at the spec's rung. The reference is the unchanged host builder polygon_analytic_flux_moments_batched (its own process pool); the candidate is build_flux_blocks. The reported ratio is the maximum absolute difference over the row's peak element. Reproduce with runs/r-20261010T184700018486-cfs-coupling-build-scale/logs/coupling_identity_probe.py.

The uniform row is the packed kernel's primary channel and is already 240 times outside the bound. The two moment companions lose four orders of magnitude to the cancellation of two large partial reductions before the displacement correction, so their own absolute round-off (~2.5e-16 on ~2e-10) sits near 1e-6 relative to the row's peak: at that conditioning no expression graph reproduces the host's order to 1e-13. The node's own regression bound (tests/biot/test_traced_section_moments.py) accepts 3e-10 for the same comparison, which is consistent with this measurement.

Unblocking condition. Either the criterion is restated against the kernel's reachable round-off (the measured per-row figures above), or a device kernel reproducing the host reduction order is added to nova/biot/polygonanalytic.py — a change the node's brief forbids, so it belongs to a node scoped to that module. Because criteria (3) and (4) share the same kernel, they are gated behind this decision rather than measured on a path whose blocks are known not to be the certified ones.
