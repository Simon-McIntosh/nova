Certificate exterior on the exact analytic support

The prescribed exterior is the analytic state minus the internal flux image of the analytic-density plasma current. When that image is integrated on the production spline clip, the exterior and the map's own booking disagree on the same support, and the disagreement appears as an exterior closure term that can exceed the booking error the map-fidelity gate exists to measure. The fixture now integrates that density on the independently computed analytic-separatrix polygon support instead, so the booked image cancels the analytic-density image the certificate books on the same support and the closure term falls to roundoff.

Two pieces implement this. analytic_support_polygons reuses scripts/prototypes/support/geometry.py:analytic_polygons, the certificate's own exact-support definition, applied to the cell polygons the moment geometry carries; _polygon_current_moments integrates the analytic density over those clipped polygons with the fixture's order-15 fan rule, sign-correcting each ring so holes subtract. exact_current_moments selects that path through support_arm, and the exterior cache identity now carries both the support arm and the content digest of nova/biot/polygonanalytic.py, so replacing the support or the contraction module cannot silently reuse an exterior built on the old clip.

Negative control: admitted

The declared negative control is a one-line flip of EXTERIOR_SUPPORT_ARM from "exact" to "legacy", which routes the fixture's default exterior back through the production spline clip and should bring the 2000-cell closure residual back. It was applied to an exported copy of the head tree, never to the working tree, and test_exterior_closure_falls_below_booking[2000] was run against it: FAILED, naming the [2000] test id. The exterior closure returned to 0.017694 against a booking term of 0.008968, so closure again exceeds booking, which is the certified old-exterior level and the return the control declares. The exported fixture was then reverted and verified byte-identical to git show HEAD:scripts/analytic_oracle_fixtures/measure.py.

The first attempt at this control did not fire, and the reason is a defect this node found and fixed. exact_current_moments selected the exact-support path by comparing the requested arm against the module global EXTERIOR_SUPPORT_ARM, so the mutation flipped both sides of the comparison at once and the legacy request still took the exact polygon path. That attempt passed with the closure unmoved at 1.088e-05 while the exterior cache key changed (be061b7073ab2c99) — the fingerprint of a routing test that follows its own default. Commit 7af372a9f compares against the literal _EXACT_SUPPORT_ARM token instead, and the control now fails as declared.
