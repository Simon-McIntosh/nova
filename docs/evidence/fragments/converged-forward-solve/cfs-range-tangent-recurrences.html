Range-function tangent recurrences

The jaxpr of packed_analytic_moments on the five-sided test section reaches these named programs from nova/biot/rangefunction.py: harmonic_multiply, harmonic_add, harmonic_scale, range_function, paired_range_function, product, total, scaled, across_the_range, sine_squared_times, deflate and contract, plus the two inner steps _harmonic_pair_step and _product_sum_step. It reaches no other paired form, and not rising_integral, which is covered anyway because it is built from the same recurrences. Each has a private tangent returning the (primal, tangent) structure jax.jvp returns, and none calls jax.jvp, jax.grad or jax.jacfwd. The point jet reaches no elliptic call inside these operations, so no elliptic tangent is reused. The primal functions are untouched.

Every operation is polynomial in its coefficients, so each tangent is the same loop carried once more with the product rule applied term by term, in the order and arrangement jax.jvp uses. A known-zero tangent, such as the constant harmonic basis of the two ends, is None and its term is left out, as jax.jvp leaves it out. Each loop body is its own staged program, so its compiled body is shared across call sites. All 13 are unrolled exact forms: none needed a scan, because the exact form already compiles within three times its primal (the tangent of harmonic_moments, which did not, belongs to the elliptic family). The wrapping of the point jet in a custom derivative is a later step and is not done here.

Bound 1e-13 for every row; the base jvp was finite on every sample, so no sample was excluded and none needed a higher-precision reference. The identity maximum is exactly 0 on every row, which is a claim about the instrument before it is a claim about the tangents. Each tangent reproduces the base jvp bit for bit because it evaluates the same elementary operations in the same order. The truncation rows show the comparison can see a difference: dropping the second factor's tangent term from the pair step, the last coefficient from a series tangent, or the carried-over order from the deflation, gives maxima from 1 to 9e4 on all 13 rows. The primal half of each tangent equals the base function's output exactly, asserted for every leaf by the bit-identity rows.

The largest compile ratio is product at 2.60, then rising_integral at 2.45 and harmonic_multiply at 2.10. The one-equation rows (range_function, paired_range_function) compile in about 10 ms, so their ratios are timer noise, not a measurement. The compiles ran in place on the fleet allocation rather than in a separate all_debug job, each in its own subprocess with JAX_ENABLE_COMPILATION_CACHE=false. Each tangent compiles in between 0.5 and 1.6 times the time of jax.jvp of the base, so a differentiated jet's cost lies in its many call sites, not in any one tangent.

The negative control sets NOVA_TANGENT_TRUNCATION=1, which applies the one-term truncation inside the identity rows. All 13 identity rows then fail against the 1e-13 bound.
