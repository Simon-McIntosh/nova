Kernel-backed read traces each kernel stage once

Fit and contour flux share one padded value pass, so no remainder batch re-traces the kernel. The polish loop runs one extra masked step, and the jet at the polished point comes out of the same evaluation as every Newton step. The saddle normal form is selected from the forms built in the candidate loop, so it is not evaluated a second time. The analytic fixture has two kernel terms, the booked plasma and the exterior's reference image. Two value stages and three jet stages therefore trace four value kernels and six jet kernels.
