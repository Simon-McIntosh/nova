One home for the point jet's tangent helpers

Every shared tangent helper the Biot point jet's jaxpr reaches now has one definition in nova/biot/rangefunction.py, and completeelliptic, elliptic, gradedresidual and momentchannel import them rather than carrying local copies. A tangent is then written in one place and read in one place, and the modules cannot drift apart. The arithmetic order each helper forms is unchanged, so no tangent value changes: every identity row agrees with jax.jvp of the base revision, every truncation row still fails against it, and every primal half is bit-identical.

The helpers homed in rangefunction.py are _tangent_sum, _tangent_difference, _product_tangent, _quotient_tangent, _scale_tangent, _deflate_step_tangent, _deflate_tangent, _contract_tangent, _harmonic_multiply_tangent and _across_the_range_tangent, each defined exactly once there. The four importing modules were checked for a duplicate definition and carry none.

One helper is a genuinely different computation and was not merged. The momentchannel _across_the_range_tangent took only the input tangents (d_bulk, d_near, d_far) and returned the output tangents alone, because the map is linear; the rangefunction namesake takes the primal term beside the tangent and returns both. Rather than merge a tangent-only map into a primal-and-tangent one, the momentchannel helper was renamed _across_the_range_differential, by what it computes, and its two call sites follow. The momentchannel _deflate_tangent, _contract_tangent and _harmonic_multiply_tangent are the same computation as their rangefunction namesakes and differ only in whether the primal returns beside the tangent; they were merged, and the call sites now take the pair.

Compile rows

The cold-compile gate measures each case's tangent program against its primal in fresh, cache-disabled processes, seven per arm, and reports the median wall with the expanded equation count beside it. It had not completed within the node's time fence when this fragment was written, so its rows are outstanding and the compile ratio is not yet asserted here; the run in progress is logs/compile-run-1.log. A second confirmatory run and the per-module tests/biot delta against the base revision are likewise outstanding, and are the node's follow-ons.

The merge itself is complete and verified by the identity, truncation and control rows above: the helpers are homed once, the one non-identical helper is renamed by what it computes, no tangent value changes, and the truncation control still bites.
