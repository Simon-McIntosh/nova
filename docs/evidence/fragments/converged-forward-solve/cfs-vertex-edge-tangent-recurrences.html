Factorisations are built from geometry the way the reduction builds them. The ring denominator, from _Vertex.__init__, is 4 r^2 x y + u^2 x + u^2 y. The plane denominator, from _Edge.__init__, is 4 b1^2 r^2 x y + w^2 x + (w + 2r)^2 y, with w the target's offset from the edge's extended line. Target and edge radii run from 1 cm to 20 m over a 40 m height. The draws include a target level with the corner (both ring ends zero), a vertical edge (zero x y coefficient) and a target on an edge end (zero near end). Pole shifts run from 1e-9 to 1e12, including zero, the exact pole-route threshold, samples within 1e-3 of it, and the ceiling. Graded panels cover a target on a corner, level with a corner, or on its radius, plus finite arcs and near-axis radii from 1e-6 to 1e-3. Every row asserts that the base jax.jvp is finite on all 10,000 samples.

Two corners were taken out of the sampled domain, each because it is not formed by the jet. Before the change, 0.42 percent of independently drawn factorisations had an x y coefficient about 1e-16 of an end value that exceeded the other end. There pivot + sqrt(pivot^2 + 4 offset) cancels to zero, and the base primal itself returns an infinite shift and zero weights, so no tangent is defined. The ring can never reach this, because its two end values are the same u*u and its pivot is exactly 1. The plane reaches it only when the edge's extended line is at negative radius at the target's height and the target radius times the edge radius is below about 1e-8 of the squared height, around 4e-6 m^2 for a 20 m machine. The jet evaluates nulls inside the plasma, so it never meets this. Code guards only an exactly zero target radius (packed_analytic_moments holds radius == 0 at one), so the bound rests on that construction, not on a guard. The other 1.00 percent were graded samples at a 1e-300 radius, whose square underflows. They moved to radii from 1e-6 to 1e-3, still near the axis, where the base jax.jvp is finite and the tangent matches it exactly.

For the negative control, NOVA_TANGENT_TRUNCATION=1 drops one term from each tangent inside the identity rows. All seven identity rows then fail the 1e-13 bound, with maxima from 1.1e2 to 2.2e10 (all_debug job 1281188).
