Wave test hygiene: figure-receipt writes, and the raster timeout

Two failures this wave were tests writing into the tracked evidence tree. tests/test_equilibrium_diagnostics.py::test_grid_imaged_biot_field_converges_to_the_volume_definition wrote via a module-level RECEIPT_PATH under docs/figures/constraint-augmented-newton-krylov/shafranov-integral/; it now writes receipt.json into its tmp_path. tests/test_certificate_gate_live.py::test_rerendered_part_receipt_is_not_a_live_certificate_row patched PART_ROOT and FIGURE_ROOT, but benchmarks/solovev_certificate.py::_render_persisted_row resolved the persisted figure.filesystem_path against the repository ROOT, so it rewrote the tracked weak-rotation 300-cell PNG and SVG and broke tests/test_certificate_pin.py in the same session; the renderer now honours the caller-supplied figure root through a logical argument, so the test writes only under tmp_path. Measured at the repaired worktree 357e8231c, the three modules in one process give 1 failed 4 passed in 55.40 s with git status --porcelain --untracked-files=no empty, and the wave-flagged test_pinned_certificate_retains_its_census_and_render_integrity now passes; the pre-repair baseline 18152a0d5 gives 2 failed 3 passed with that integrity test failing (sha 'ee6c0bba…' != '61e31a2b…'), so the delta removes exactly that failure. The negative control, a scratch copy of the unrepaired renderer run once on the rerender test, dirties the tracked panel (61e31a2b… to ee6c0bba…, EXIT=1).

The raster receipt timeout is a measurement-concurrency artefact, not a program regression. tests/test_forward_receipt_raster.py::test_reduced_hex_request_receipt_records_absent_raster_flux timed out at 600 s at head with twelve modules running at once. Run alone in fresh processes on compute with the persistent compilation cache disabled, the base arm 7c4a76caf takes 750.72 s and the head arm 357e8231c 1186.29 s; the 1.58 ratio sits outside the 20 percent band, but the traced solve-program jaxpr is byte-for-byte the same size at both revisions — 145 outer equations and 532 509 total, with the only ForwardSolvePolicy difference being the presence of topology (HAS_TOPOLOGY False at base, True at head, one policy leaf each). A program that traces to the identical solve jaxpr cannot carry the extra wall, so the excess is the head arm overlapping the base raster arm for roughly thirteen minutes; no program change is implicated and nothing was changed.
