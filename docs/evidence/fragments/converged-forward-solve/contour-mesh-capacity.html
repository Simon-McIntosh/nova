Size the topology contour mesh from its geometry

Defect (reproduced at the base revision). TopologyGeometry.from_cells sized the contour mesh as vertex_capacity = len(tree_centres) + len(points) + 1, and build_contour_mesh blanked every index when that was exceeded, returning a mesh with zero valid vertices. The read then failed at nova/equilibrium/topology.py:2483 with IndexError: index -1 is out of bounds for axis 0 with size 0. Measured on the imas-efit boundary traces at the coarsest lattice: required 247 vertices against a declared capacity of 231, on all eight records, so all eight rows were unread.

Fix

The carrier is now sized from what it must hold. build_contour_mesh leaves a capacity unset to size it from the carrier the geometry actually produces — the tree centres plus every wall vertex the clipped triangulation generates — so a wide wall cannot overflow a formula. A capacity that is declared is a ceiling: a larger carrier raises ContourMeshOverflow naming both the required and the declared count, rather than blanking every index. from_cells no longer passes the fixed formula and refuses a carrier that admits no valid vertex.

Measure. Every record builds a mesh whose valid vertex count is below its capacity, at every lattice resolution in use. The refusal is exercised by forcing a capacity below the geometry: contour mesh vertex capacity 4 is below the 106 the geometry holds.

Gate

The focused pair — tests/equilibrium/test_topology_contour_mesh_capacity.py and tests/test_contour_tree_mesh.py — passes at head: 17 passed in 12.21 s. The new wide-wall test does not pass at the base revision, where the geometry required 247 vertices against a declared capacity of 231 and the read raised IndexError.

The three-arm regression gate over those two files and tests/equilibrium/test_topology_read.py is begun but not recorded. The base archive, the worktree and a control tree with the fixed capacity formula restored were each run in a fresh process, and none reached its summary line inside the node's time budget; the arms were stopped and no EXIT= line was written. The rerun must run without the forced per-test timeout, which sits below the repository's declared value and is a candidate cause of the failures the two control arms showed before they were stopped. No regression claim is made from them here.
