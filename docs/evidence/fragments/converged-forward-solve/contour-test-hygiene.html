The capacity-overflow check proved less than its name claims, but not because it bypassed compilation: build_contour_tree already carries its own @partial(jax.jit, static_argnames=("neighbour_capacity","node_capacity","edge_capacity")) decoration at nova/equilibrium/contour_tree.py:494 in base 4ff706d76, so the bare call was compiled and a second jax.jit wrapper around it changed nothing. What the test did not do was assert that, so nothing would have stopped a later edit from deleting the decoration and leaving the test green. tests/test_contour_tree_merge.py::test_critical_node_capacity_overflow_is_jittable_and_visible now asserts it directly: the name must expose its unwrapped Python source (hasattr(build_contour_tree, "__wrapped__")), the compiled call and build_contour_tree.__wrapped__ must agree array for array across all seven receipt fields, and the overflow flag, the 256 valid nodes and the 255 valid edges are asserted on the compiled result. The mutation lives only in the scratch tree; no product source changed.

The sparse-build receipt check pinned a sha256 digest of the receipt's integer arrays for every (kind, cells). At 2,000 cells those digests are host-dependent: the same code passes on a sirius node (job 1292526, c84c432e9) and fails on this Broadwell fleet node class (98dci4-clu-2068), two failed and two passed, with the receipt reordered. test_sparse_build_matches_carrier_reference now compares the receipt against the reference the done-when names — the brute-force host graph search already in benchmarks/contour_tree_brute_force.py. Where the receipt carries no virtual outside node (the 550-cell rows) the receipt is compared array by array with _tree_count and _component_count at every sampled level: the receipt's arc crossings must equal the carrier's strict superlevel component count, one fewer than that count below the global minimum. Where the receipt does carry the typed-outside node (the 2,000-cell rows) the wall-join accounting adds arcs the whole-carrier component count excludes, so that equality does not hold and the host-independent structural relation is asserted instead: the valid arcs form a tree spanning the valid node rows, every arc endpoint is a valid node row, no more than one valid node is the typed-outside slot, and every other valid node maps to a valid carrier vertex. The pinned digest is kept only for the 550-cell rows. The negative control is a receipt whose arc endpoints are re-pointed to another valid node row, leaving the arc and node tallies intact: the structural check passes it, the brute-force comparison fails it at both 550-cell rows (limited -0.0492, diverted 0.00625).
