There is no convergence regression to repair

The node was dispatched to find the change that stopped the diverted 300-cell row converging, on the reading that the row reached 5.626976272072871e-15 in two trips at e39ffd109 and 0.0749196925647991 in twelve trips at d3dcd9ce3 and since. Measured in fresh processes, the row does not converge at either revision, and the two revisions build the same carrier. The converged reading is a banked part receipt written on 2026-09-19, which the certificate driver returns without entering the solver.

The receipt the driver serves is September data

benchmarks/solovev_certificate.py keeps one part receipt per (case, requested_cells) under docs/figures/gs-absolute-accuracy/solovev/production-route-parts/. _measure opens that file first and, when it carries render_data, calls _render_persisted_row — whose own docstring reads “Rebuild one panel from its part receipt without entering the solver” — then returns the persisted row. Every solver field in the answer, including terminal_fixed_point_residual, converged, active_set_iterations and target_current_a, therefore comes from the file rather than from the tree.

That file was last written at edb02142f on 2026-09-19, under job 1268058 on 98dci4-gpu-0003. Where the repair belongs

Whatever stops the row converging is not a regression introduced after e39ffd109: the carrier and the declared current are unchanged across the window. The reachable defect on this row is the receipt reuse above, whose owner is benchmarks/solovev_certificate.py. That file is outside this node's write paths, and the row's solver behaviour belongs to the cut-cell and topology read the tracked-read and moment-field-hessian nodes carry, so it is reported rather than edited.

The residual plateau the reproduced rows do show is a frozen-partition Newton stopping with zero mask changes, which is a region decision, not a residual arithmetic. A fresh CPU row at e0e4bca0 stops after one trip at 2.2640848763056183 with its only linear action refused as nonfinite_linear_action, and the fresh H200 row recorded in certificate-300-trip-cap reads 0.07489864728918744 after twelve trips. Both are unqualified at 1e-12.
