The same revision on a GPU

The row itself was then run at e39ffd109 on a GPU, in a fresh process from that revision's own tree (titan, 98dci4-gpu-0002, job 1299226, CudaDevice(id=0)). It does not converge there either: terminal residual 0.3008686198923309, converged false, unqualified, three active-set iterations and sixteen accepted Newton promotions.

The trace is the more informative half. Twenty map evaluations measured a residual and all twenty report the identical value 0.3008686198923305 — sixteen accepted promotions moved the state without moving the measured residual by one bit. A residual that is invariant under the promotions the solver accepts is not a step-length problem; it is the frozen partition the promotions are solved against. That is a region decision, the property the tracked-read and moment-field-hessian nodes carry, not a residual arithmetic this node could repair inside its write paths.

The driver no longer serves a receipt it cannot reproduce

benchmarks/solovev_certificate.py now judges a banked part before it serves it. _certificate_case_setup builds the machine, the analytic fixture and the declared target current once; _receipt_verdict compares the receipt against that setup on three independent facts and returns the reasons it accepted or refused. A refused receipt sends _measure into the solver. Nothing is deleted, rewritten or repaired in place: the banked files are read, judged and left as they were.
