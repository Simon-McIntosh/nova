Equilibrium morphology and test hygiene

Change

Base 63caf693143b26d2a689939bb9073b5f969d2b75 had two in-bounds four-neighbour dilation functions: JAX in morphology.py and NumPy in wall_mask.py. Both returned identical arrays for 100 random masks with populated border rows and columns. morphology._dilate4 now dispatches on the host NumPy mask or device JAX mask and evaluates one false-padded expression; wall_mask calls it. The reported unreachable second return in morphology was already absent at the base revision.

The new border test covers 49 masks, including a corner-only case and random one-row, one-column and rectangular masks. It passed on the edited tree. Replacing false padding with periodic edge propagation failed that test at the opposite edges with EXIT=1, after which false padding was restored. Eight masks also matched between host evaluation and jax.jit(jax.vmap(...)); the existing wall-mask test file passed 10 of 10 tests.

The grep -rn census over docs/plans and docs/research found zero matches for each of the four benchmark names. As a positive control, the same census found four mentions of coefficient_carrier; the shipped coefficient-space document lists that module as a historical artifact but names none of the drivers as current tools. The coefficient-carrier module, its five-test file and four benchmark drivers were removed, deleting 2,930 lines. The deleted test file passed 5 of 5 tests before deletion.

The three _green_block copies and two _solovev copies now resolve to one definition each in tests/conftest.py. A source-text assertion and two source-text receipt fields about the retiring fixed_point.py path were removed; the dimension and conditioning behaviour tests remain.
