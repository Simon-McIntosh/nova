Refusing a non-finite cell moment by index at the solve host loops

A raise written inside the mapped step never runs: every production solve route is traced, so the refusal has to leave the compiled program as an output and be applied by the host loop that drives it. The earlier attempt that put the raise inside the traced code was reverted with the arc-root repair; this node places it where the driver can act on it.

The reduced Newton kernels gain moment_finiteness, a compiled program that reconstructs the flux one reduced state induces, recomputes that state's cell moments, and returns a per-cell boolean mask marking every cell carrying a non-finite moment. _drive_trips — the reduced Newton driver's host loop — reads the mask at the top of each active-set trip and raises NonFiniteCellMomentError (a CurrentNormalisationError) naming the offending cell indices. The certificate solver's Newton loop is now drive_linear_steps in scripts/prototypes/fast_map_production/solver.py, which takes the per-cell mask of the state it is about to step from and refuses the same way before taking the step. Neither driver substitutes a value: a NaN is never replaced by zero inside the solve, so the residual still poisons as it did and the existing non-finite-linear-action refusal remains behind this one.

The two host loops are _drive_trips in nova/equilibrium/reduced_newton.py (the for trip in range(active_set_steps) loop, whose check sits after the fused/non-fused reduction is in hand) and drive_linear_steps in scripts/prototypes/fast_map_production/solver.py, called from run in place of the inline linear_step loop.

The CPU diverted 300-cell certificate row was measured at three revisions with one driver: the base d3dcd9ce3, this node's head c9fd19dcc, and the main checkout's 491406301. All three return the same terminal fixed_point_residual of 0.0749196925647991 after 12 trips with the active set settled and the row reported unqualified, so the refusal reads a mask without changing what the solve reaches; the row does not reach the roughly 5.6e-15 in two trips recorded for the production route earlier, and because the main tip reproduces this row's number exactly, that difference belongs to the tree and the lane rather than to the refusal. The measurements are logs/row/base.log, logs/row/head.log and logs/row/main.log and the three arms differ by no digit.

Five tests in tests/test_solve_nonfinite_refusal.py pass: the mask flags only the planted cell and reads every moment leaf, and each driver's host loop requires the refusal to name the planted cell 103 on a traced route. The negative control removes the two host-loop refusal calls from a scratch archive of the head tree; both planted-NaN host-loop tests then fail (negative-control.log, 2 failed, 3 passed, EXIT=1), so the guard is shown firing rather than merely passing.
