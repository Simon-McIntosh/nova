Refusing a non-finite cell moment by index at the solve host loops

A raise written inside the mapped step never runs: every production solve route is traced, so the refusal has to leave the compiled program as an output and be applied by the host loop that drives it. The earlier attempt that put the raise inside the traced code was reverted with the arc-root repair; this node places it where the driver can act on it.

The reduced Newton kernels gain moment_finiteness, a compiled program that reconstructs the flux one reduced state induces, recomputes that state's cell moments, and returns a per-cell boolean mask marking every cell carrying a non-finite moment. _drive_trips — the reduced Newton driver's host loop — reads the mask at the top of each active-set trip and raises NonFiniteCellMomentError (a CurrentNormalisationError) naming the offending cell indices. The certificate solver's Newton loop is now drive_linear_steps in scripts/prototypes/fast_map_production/solver.py, which takes the per-cell mask of the state it is about to step from and refuses the same way before taking the step. Neither driver substitutes a value: a NaN is never replaced by zero inside the solve, so the residual still poisons as it did and the existing non-finite-linear-action refusal remains behind this one.

The two host loops are _drive_trips in nova/equilibrium/reduced_newton.py — the for trip in range(active_set_steps) loop, which refuses twice: at reduced_newton.py:1503 on the state a trip is about to step from, after the fused or non-fused reduction is in hand, and at reduced_newton.py:1576 on the state the last trip returns, which is the terminal state the solve records, so a moment the final trip's Newton or boundary step produces is refused rather than returned — and drive_linear_steps in scripts/prototypes/fast_map_production/solver.py, called from run in place of the inline linear_step loop. That loop refuses twice: at solver.py:191 on the state it is about to step from, and at solver.py:200 on the state the final step returns, which is the terminal state and panel the run records, so a moment that only the terminating step produces is refused rather than written.
