nova's internal consumers run in COCOS 17 through the convention owner

Base 6ccf43de9. This node walks the internal consumers the census migration list names, confirms each one either already reads its convention from an owner or is one call site that did not, and lands the one that did not beside a COCOS 17 contract for each consumer in its scope.

What the consumers already held

The store shares this node's scope and was measured rather than reworked. SignalStore.cache_key already names the stored fields' convention through hash_attrs, and legacy_cache_key is the identity-only key an older nova wrote under, so a group written before the convention entered the key is refused by StaleConventionError. nova.equilibrium.inverse's boundary constraint already passes psi_boundary through unnegated, because the equilibrium reader applies the source sign once; nova.imas.extrapolate's update and its masked flux display already take their sign from the convention.

The one bare factor

nova/biot/contour.py was the exception. Surface.fit divided the least-squares coefficients by a literal -2 * np.pi, and ContourLoc.plot_fit rebuilt the toroidal current density with the same literal, so the Grad–Shafranov factor existed in a second place beside its owner. The fit now divides by nova.equilibrium.convention.TOTAL_FLUX_FACTOR and the plot rebuilds through toroidal_current_density. Both are the owner's own algebra, and every fitted value is unchanged.

COCOS 17 contracts

tests/test_cocos17_internals.py holds one test per consumer in scope. The contour fit recovers a known (p', FF') pair and rebuilds the current density it was fitted to through the owner; a second test moves the owner's published factor and requires the coefficients to move by the same factor, so the site is bound to the owner rather than to a re-statement. The store key equals hash_attrs({uri, dd_version, cocos}), two conventions of one source get different groups, and a pre-convention group raises StaleConventionError instead of being served. The inverse constraint hands on the reader's psi_boundary byte for byte, so a returned negation reddens it.

Negative control

In a scratch copy of the tree, SignalStore.cache_key was returned to its pre-convention identity, the convention dropped from the key. The test file then reports 3 failed, 4 passed and exits 1: the key-equality test, the second-convention-group test and the refusal test fail, and none of the four contour or inverse contracts does. The log is negative-control.log in this run's directory.

Arms

The gate is every test file that imports nova.biot.contour, each in its own fresh process with its own basetemp, at the base revision and at the head. baseline_suite and after_suite in the manifest carry the revisions, commands, exit statuses and failure ids. The new test file has no base arm, because it did not exist at the base.
