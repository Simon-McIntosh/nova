The edge-consistency measure, its gates, and the reference decision

The measure of section 5 is nova/imas/edge_consistency.py, which reports three forms on one structured grid: the parity chain's own RMS(j_phi_profile - j_phi_grid) / max|j_phi_grid| over the whole scored slice, and two band forms inside 1 - EDGE_BAND_WIDTH <= psi_norm <= 1 — the absolute residual in A/m2 and the residual relative to the local profile current. The band forms never borrow the slice-wide denominator. nova/imas/mast_parity_chain.py reads its grid current through that same owner operator, so the parity chain and this measure are one arithmetic. The edge threshold is EDGE_BAND_RELATIVE_THRESHOLD = 1.0e-3, fixed on the analytic state before any IDS row was read.

The iter-passive-plasma-circuit section 6 reference: revised

The reference choice is revised, not confirmed, and the threshold it is judged against is the stated 1.0e-3. Two facts carry the decision.

First, the repository’s flux-function sense is still the one nova/equilibrium/convention.py books at this base, and the stored profiles read anti-parallel to the map under it: the profile current integrates to a median of −1.13, −1.09 and −1.10 times each slice’s own Ip while the map current integrates to 0.97–1.00 of it. Reversing the whole profile current removes that disagreement, and it is not the whole story: the corrected DINA medians are 0.706 and 0.721, about 700 times the 1.0e-3 threshold. So on the DINA pulses the edge disagreement is not explained by the convention defect; it survives the correction at roughly 70 per cent relative residual.

Second, the corrected numbers separate the sources. CORSICA 130506/6 sits at 7.600, ten and a half times the DINA pair’s 0.706 and 0.721. The relative form is also unusable there for a reason measured rather than assumed: on the probed slice its local profile current changes sign once inside the edge band, with 9.2 per cent of the band cells negative, so the denominator passes through zero and the relative residual stops being a number (9.7896e15). Neither probed DINA slice crosses zero in the band — zero sign changes on both — so that caveat applies to CORSICA alone.

The decision this node records: CORSICA 130506/6 is not confirmed as the section 6 reference and should not be chosen on this measure, on the corrected numbers where it is ten times the DINA residual. Between the two DINA pulses edge consistency does not discriminate (0.706 against 0.721, two per cent), so no source is confirmed on it and the choice must rest on grounds this measure does not cover. One provisional qualification: the correction is applied to the stored profiles for the measurement, while the owner fix that would apply it in the code is not landed at this base; when it lands, the table re-measures against the same fixed threshold.
