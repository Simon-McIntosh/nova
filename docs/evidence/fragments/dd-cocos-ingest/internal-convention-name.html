(2b) One cache-refusal mechanism, and why it is not a key. The equilibrium dataset cache's identity is the store path (the pulse/run name) and the group (the IDS name), both composed in nova.imas.database.Database.update_filename, which every IDS reader shares; the convention is what the reader translates into, not a property of the source identity the key describes, and re-keying it would rename every existing group and orphan every pulse already cached on disk. Those two files, and the tests that assert the group name, are outside this node's fence, so the cache cannot take the SignalStore key route here. Exactly one refusal is kept: build_convention records the convention under CONVENTION_ATTR, and EquilibriumData.load requires that marker and evicts an entry carrying another convention or none, so a foreign entry is rebuilt rather than served. The attribute name is now stated once, used by the writer and the load check, and the load compares it against NOVA_CONVENTION — the owner's value, not a literal.

The refusal, exercised. test_cached_equilibrium_under_the_other_convention_is_refused writes a cached dataset carrying cocos = 11 into a temporary zarr store, binds a reader to that store, and asserts the reader rebuilds and that the refused group's psi_boundary array is no longer served. test_cached_equilibrium_in_the_owner_convention_is_served is the control: an entry carrying the owner's convention is served without a rebuild, so the guard discriminates rather than always rebuilding.
