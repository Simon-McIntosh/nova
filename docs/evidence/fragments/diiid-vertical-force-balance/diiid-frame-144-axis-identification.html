Frame 144: why the limited seed refuses at axis identification

Frame 144's limited-branch seed is the one refusal in the DIII-D cohort: it stops before any Newton promotion, while the diverted seed for the same frame reaches a terminal residual of .... The question is whether the seed really has no admissible axis, or whether an axis is present and the identification rejected it.

It is present and was rejected. The seed carries a flux maximum at R=1.7880 m, Z=+0.0171 m, 0.03 m from the EFIT label axis and 0.03 m from the diverted solution's axis at R=1.759, Z=+0.013. A missing axis is therefore not the explanation.

The rejecting rule

The admitted bit is composed by qualified_o_candidates.qualify, nova/equilibrium/topology.py:1080–1099, and the comparison that rejected this candidate is the third conjunct at

governed_connection = governed_size >= connection_floor   # topology.py:1097

The threshold is nova/equilibrium/topology.py:1076–1078,

connection_floor = jnp.maximum(jnp.floor(_MATERIAL_CONNECTED_FRACTION * material_cell_count), 1)

with _MATERIAL_CONNECTED_FRACTION = 0.01 at nova/equilibrium/topology.py:41. A candidate is additionally screened at topology.py:1081 (finite position and flux) and topology.py:1082 (a resolved boundary).

The values it read for this point, from the census diagnostics: material cell count 1089, so connection_floor = 10 cells; the lattice node at the axis is (1.7871, 0.0166) and reads axis_node_inside_material = True. The candidate therefore lies inside the material and had to own at least ten governed connected cells to be admitted. Its position and flux are finite, so the first conjunct does not exclude it.

Why the run jobs failed. Recommended fix

Admitted. The rejection is a threshold, not a physics result: a fixed 0.01 of the whole material cell count is applied to every candidate, so a genuinely confined axis in a small closed component is refused whenever the grid is large. Change topology.py:1076–1078 so the floor is measured against the candidate's own governed component rather than the total material count, and have qualify return the three conjuncts alongside the admitted bit so NoQualifiedAxisError names which one failed.

Test that would have caught it. A limited read seeded with a map whose only extremum inside the material sits in a component smaller than _MATERIAL_CONNECTED_FRACTION of the full material count, asserting that the read admits the axis (or raises naming governed_connection with the counts it compared). The existing tests/test_oracle_axis_admission.py and tests/test_unqualified_axis_eager_routes.py assert the admitted and refused outcomes but never which conjunct produced a refusal, which is why a seed can be recorded as having "no qualified axis" without the record distinguishing a missing axis from a rejected one.

If a probe needs a hook in nova/: none was needed. The census reads the benchmark's public seed portfolio and the operator's inside_material, both already exposed.
