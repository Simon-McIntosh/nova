Summary

Frame 146's diverted branch terminates with its axis at R=1.234 m, Z=+1.563 m — 0.20 m above the DIII-D limiter top at Z=+1.363 m, with no closed core cells and 0.039×Ip confined. Frames 137, 144, 179 and 44 keep their plasma.

Two hypotheses are refuted by measurement on the same time slice, and one mechanism survives. The coils, the profiles and the current normalisation are adequate: frame 146's limited branch, on the same extracted profiles, the same coil set and the same 1.624 MA target, reaches a held diverted plasma at Z=+0.027 m with 1.134×Ip confined. What differs is not the seed's distance from the label but the size of the first step the active-set iteration takes from it, and the boundary-set trajectory that step triggers.

1. Per-trip trajectory, frames 146 and 137

Both frames' diverted seeds are almost exactly the same distance from their EFIT label — 151.05 Wb for frame 146, 150.27 Wb for frame 137, a 0.5% difference. The first-step promotion amplitude differs by a factor of eighteen.

The boundary-set trajectory diverges at trip 2

Frame 137's active set shrinks monotonically once from its seed — 24, 20, 9, 9, 0 — walking a boundary inward onto the reliable flux surfaces, and terminates with the axis at Z=−0.442 m, inside the vessel, with 71% of the target current confined and a diverted X-point.

Frame 146's active set grows on the second trip, 27 → 40, then collapses through 1 and 0 and stays empty. Once the set is empty there is no boundary row through which a vertical-field correction can be applied: the residual repeats to all printed digits from trip five onward (5.496e-2, sixteen promotions) and the axis is left 0.20 m above the limiter. The alternate-level pattern the stopping rule reports is a period-2 cycle across trips 2–4 (levels 0.2220, 0.0651, 0.0550), after which the plateau is flat and the arm is stopped as a contraction stall.

2. Mechanism: which hypothesis holds

hypothesisverdictmeasurement
The profile or current normalisation pushes the axis up refuted Frame 146 limited: axis Z=+0.027 m, Iconf/Ip=1.134. The normalisation on the same profiles and the same 1.624 MA target produces a centred plasma.
The coil currents give no vertical equilibrium for the extracted profiles refuted Frame 146 limited reaches a diverted equilibrium with a qualified X-point at R=1.353, Z=−1.250 m and 1.134×Ip confined. The coils and profiles support a vertical equilibrium; the diverted branch's failure is not a property of them.
The seed drives an n=0 vertical displacement the fixed point does not restore sustained, with the discriminator moved from the seed to the first step Seeds are equidistant (151.05 vs 150.27 Wb), so seed distance alone does not explain the outcome. The first-step amplitude is 25.28 Wb on frame 146 against 1.404 Wb on frame 137 for that same seed distance, and 146's active set grows before collapsing. The un-restored displacement is real; its cause is the step size and the boundary set it produces, not the seed's displacement.

The mechanism. On frame 146 the diverted branch's promotion step is 6.0× the seed-to-label flux distance (25.28 Wb against a seed 151.05 Wb out) and 18× frame 137's step for an equivalent seed. That step admits more cells than the initial set held — 40 against 27 — rather than contracting onto the reliable flux surfaces. The next trips then remove the set entirely, and an empty active boundary set leaves no rank with which the iteration can correct an n=0 vertical offset. The residual therefore cannot fall below 5.496e-2, and the axis stays where the over-large first step put it: 0.20 m above the limiter.

Frame 144 (diverted seed 109.29 Wb, amplitude 0.929 Wb) lands at Z=+0.013 m with 1.073×Ip, which is consistent: the one arm that overshoots its set is the one that loses its plasma.

3. Recommended fix

nova/equilibrium/fixed_point.py, in the active-set promotion that builds the next boundary set from the current promotion: bound the promotion step by the reliable flux-surface set before the cells are admitted, and refuse a set that contains more cells than the set it replaces unless the residual decreased on that trip.

The hook that makes the guard observable: a forward-solve request carrying a reliable flux-surface set must assert, at termination, that the terminal boundary set is non-empty and that the terminal axis lies inside the limiter when the achieved class is not lost. A terminal axis outside the limiter with an empty boundary set is a defect in the promotion step, and it is currently reported as an ordinary contraction stall.

Neither change is made here: this node measures and explains, and nova/equilibrium/fixed_point.py is owned by a concurrent node.
