The prescribed DIII-D closure is tapered to zero at the magnetic axis

The first departure is in p′ and FF′ evaluation, before the current amplitude or support mask. Both DIII-D extracted tables cover normalised flux 0.05–0.95. Their SampledFluxFunction representation interprets the missing interval between the first knot and the axis as an exterior end cap: at ψₙ = 0, both evaluated gradients are exactly zero. The source therefore imposes jφ = 0 at every correctly normalised magnetic axis. This hole is present when the recovered closure is evaluated on the saved EFIT reference field, before the saved solved field becomes flat or develops multiple maxima.

The source of the hole is the combination of nova/equilibrium/map_extraction.py:209 (the default shell centres start at 0.05), benchmarks/diiid_forward_gs_match.py:1135 (only those extracted samples are returned) and benchmarks/diiid_forward_gs_match.py:1345 (they enter SampledFluxFunction). The first operation that actually removes the core current is nova/equilibrium/solve_request.py:69–77: the compact end-cap basis reaches zero one edge interval below the first knot. Here that interval is 0.05, so the zero falls exactly at the physical axis. At ψₙ = 0.05 the same closure gives a large, positive source current. No pressure/field sign cancellation is needed to explain the hole.

The change belongs at benchmarks/diiid_forward_gs_match.py:1135, upstream of the construction at line 1345: add an explicit inward continuation of p′ and FF′ to the physical axis, initially using the first two reliable knots' linear continuation, so the compact exterior cap lies outside the physical core.
