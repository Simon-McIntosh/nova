landing: a constraint pair whose payload reports its compensator inactive now applies a flux image of exactly zero, and a proposal route that differentiates that image obtains a tangent of exactly zero, on Newton, the rebuilt-model promotion, continuation and descent recovery alike. The rule lives at the one site that applies a pair's image, so no route can gate it separately, and the authored centroid row stays present and drives its unknown to zero. The committed contract is tests/equilibrium/test_solve_vertical_pin.py; a control that deletes the mask reddens every inactive case and no active one.

The rule and its single owner

A vertical-position pin is a CurrentCentroidConstraint whose binding carries an active flag. That flag is the only activity declaration a constraint payload carries: every other functional's payload is row data — sampled points, a level set — that says nothing about presence. Before this node the flag was read in the residual and nowhere else, so an inactive compensator's flux image entered the augmented map while its row was still scored, and the two disagreed off the root.

nova/equilibrium/constraint.py now declares that rule once, as active_payload_mask(functional, payload): it returns the reshaped flag for a current-centroid payload and None otherwise. The residual reads it, and ConstraintPair.flux_delta reads it and applies the image through jnp.where(mask, delta, 0). assemble_augmented_system and reduced_newton._RowAugmentation both call that owner, so every proposal route inherits one mask rather than each gating the image its own way. Because the predicate is shared, the residual and the image cannot drift apart: a future functional that publishes an activity flag changes one function.

The contract: exact zero at the owner, and the image observed from the route

Each scored candidate is read twice, and the two readings answer different questions. The owner reading is the value ConstraintPair.flux_delta returns: rounding cannot enter it, so an inactive binding must slice exactly zero and the assertion is an exact array equality. The route reading takes the same quantity from outside, as the difference between the route's own map at the candidate and that map with the compensator unknown held at zero; a difference of two map evaluations carries roundoff, so it is held to the double-precision floor of 1e-15. The unknown-direction tangent is the route map's JVP and is compared exactly.

Every case carries its own positive control. The same test builds an active binding and requires a nonzero image, a nonzero tangent, and a route reading above 1e-12, so a mask that suppressed everything would redden the case rather than pass it. The shadowed cases freeze one flux coordinate and require both a zero tangent on it and no movement of the map there. The reduced contract goes further and drives both bindings through one compiled program: it traces evaluate(runtime_pair, unknown) once, calls it with the inactive pair and again with the same pair rebound to an active payload, and requires the active call to show an image while the inactive call slices zero at a nonzero unknown of 0.25. The zero is therefore the binding's and not a second trace's.

The sixteen route cases are the cross product of the four routes (newton, rebuilt, continuation, descent), two sources (a radial basis and a circuit-current direction), a shadowed and an unshadowed map, and an inactive and an active binding. The whole file runs 41 tests in one process:
