What is marked. The traced support capacity derives from the realised layout: spline_chain_samples_per_chord + atomic_support_capacity, one traced arc plus the straight edge chain. Before revision f7fefbd780aae7ef3d9707722fc4d80a1f0742cd it was instead the swept product atomic_support_capacity * spline_chain_samples_per_chord, 128 samples reserved for every straight slot. Every receipt here was compiled against the swept product, so each recorded dimensions mapping now carries a dimensions_provenance block in the form the predecessor node established: it names the retiring revision, quotes the superseded swept expression, and gives the bound the current code derives for the same layout. The four layouts and their current bounds are 150 = 128 + 22 for atomic capacity 22, 152 = 128 + 24 for atomic capacity 24, 158 = 128 + 30 for atomic capacity 30 and 148 = 128 + 20 for atomic capacity 20.
