The gate-b panels print the cell count as a magnitude

The frozen-current gate driver (benchmarks/frozen_current_flux_image_gate.py, on main since the merge f0b389834 that restored it) composed both cell-count-bearing titles from the signed row key requested_cells: the six error-panel titles ({case} {requested_cells}) and the comparison suptitle ({case} {requested_cells}: frozen-exact-current image, …). The committed panels therefore drew weak-rotation-reactor-static -110, diverted-single-null -300 and the like, while the case keys, the parts and the per-row report already carried the magnitude. This is the gate-b half of the same finding the moment-order repair closed on main at dd32c8332, which composed its titles from abs(requested_cells).

Both title sites now compose abs(row['requested_cells']); the signed requested_cells field stays the data of record in the parts and the receipt, so only what is drawn changed. The panels were regenerated through the driver's render-only path (--render-only) from the committed receipt.json and parts/, with no solve. Reading the title comments back out of the two SVGs (the SVG is drawn with glyph outlines, so the title strings survive as matplotlib's text comments):

  • absolute-flux-error.svg — six panel titles changed: weak-rotation-reactor-static -110 → … 110, moderate-rotation-conventional-static -110 → … 110, strong-rotation-compact-static -110 → … 110, diverted-single-null -110 → … 110, weak-rotation-reactor-static -300 → … 300, diverted-single-null -300 → … 300.
  • weak-110-frozen-prediction-analytic-terminal.svg — one suptitle changed: weak-rotation-reactor-static -110: frozen-exact-current image, … → … 110: …. Its three panel titles (frozen-current prediction, analytic flux, committed terminal state) carry no cell count and are unchanged.

The error magnitudes in every title (max |error| … Wb = … span) are unchanged, which is the expected reading: the repair touches only how the cell count is printed.
