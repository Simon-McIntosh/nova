The repository-relative path helper has one owner

Four render drivers each carried a private copy of repository_relative, and the four copies had drifted from the committed receipts: sol_ledger_current_census.py relativized the paths it wrote while shafranov_pair_receipt.py and shafranov_combination_discriminator.py still recorded str(path) — an absolute worktree path — for filesystem_path / vector_filesystem_path. A path recorded absolutely stops locating its artifact once the worktree that produced it is reclaimed, which is exactly the failure the repository-relative convention exists to prevent.

What changed

One public helper now lives in nova/database/filepath.py: repository_relative(path) resolves the nearest ancestor holding a .git marker and returns resolved.relative_to(root).as_posix(), falling back to the absolute resolved path when no repository ancestor exists (and to root_dir as the final fallback). Each of the four drivers imports it and drops its copy. The shared relative_carrier_evidence walk keeps its single owner in benchmarks/shafranov_pair_receipt.py, because that receipt shape is a benchmark convention rather than a general path concern and the sibling discriminator already imports this driver for it.

The pair and discriminator render routes now record repository_relative(...) at every filesystem_path and vector_filesystem_path call site, so a receipt written on any route is relative to the repository that produced it. measure.render takes an optional output directory and writes its panel, its vector companion and its figure receipt there, so the render-only route can be exercised against a temporary root without a solve.

Checks

The directory scan in tests/test_render_receipt_paths.py no longer excludes non-render JSON. The historical SLURM preflight record docs/figures/cut-cell-current-attribution/outboard-hole/preflight-receipt.json has no writer in the tree, so its worktree path fields were rewritten to repository-relative form and every other field left unchanged; the scan now reaches it like any other receipt in the four directories.

Four render-route tests call each driver's solve-free render path into a temporary directory carrying its own .git marker, then assert that every filesystem path in the written receipt is relative to that root. Reverting any one call site to str(path) fails the corresponding route test.
