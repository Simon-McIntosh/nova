Scattered-node and rasterised contours stay inside the first wall

Carries followup f-fsa-painters-draw-field-outside-the-wall.

No nova.media painter triangulated a scattered field before this change: the one contour painter, draw_flux_contours, takes a regular grid. The figures that drew field beyond the wall built that grid by interpolating nodes over their convex hull (_raster_field, LinearNDInterpolator) and contoured it unmasked. nova/media/poloidal.py now carries two repairs.

  • draw_scattered_contours triangulates the nodes and masks every triangle whose centroid, vertices or edge midpoints leave the wall units, using the same inside_wall_units predicate (vessel units united, material units removed) that draw_wall callers already hold. The wall argument is required.
  • draw_flux_contours takes an optional wall and blanks grid points outside it, so a hull-interpolated raster draws nothing beyond the wall.

Measure

tests/test_contour_inside_wall.py: 7 passed on a slotted vessel and a vessel with a material hole. With the triangle mask removed, 4 of the 7 fail (negative-control log). The unmasked triangulation of the same nodes is asserted to draw outside the wall, so the inside-wall assertion is shown able to fail. Seven test modules importing nova.media were run each in its own process; none failed (the playable-session module did not finish inside its 540 s bound and is reported in the manifest).

The figure docs/figures/plasma-cell-read-fidelity/exact-mode-construction-comparison.png still shows the old field: its owner regenerates it by passing the wall to draw_flux_contours.
