Check script in each directory

Each directory carries a committed check_report_figures.py that reads its own report.md, resolves every token ending in .svg or .json.gz to a file in that directory, and exits nonzero if any is absent; each .json.gz is additionally decompressed and parsed as JSON, so a corrupt archive fails there. Run before the restore (artifacts absent) the logs are red — MISSING 1 of 1 (compile-memory) and MISSING 5 of 5 (solve-profile), both EXIT=1. Run after the restore they are green: RESOLVED 1 of 1 and RESOLVED 5 of 5, both EXIT=0, with all three archives parsed as JSON.
