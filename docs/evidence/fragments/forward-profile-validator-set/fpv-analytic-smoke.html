Analytic vacuum rung: the coil flux reproduces the reference map

The pinned analytic case is a vacuum test. Its reference equilibrium carries only a 65×65 two-dimensional flux map — global_quantities.ip is 0.0, psi_magnetic_axis holds the -9e40 empty sentinel, and profiles_1d and the boundary outline are empty — so no plasma current and no magnetic axis exist to band. The input bundle carries a single filamentary coil at (R, Z) = (103, 101) m at 1 A and no plasma. The rung therefore validates the free-boundary flux assembly itself; the ITER trio rungs of the plan carry the Ip, axis and area bands.

tests/test_forward_profile_analytic_smoke.py computes the vacuum poloidal flux of the input coil on the reference grid through the package's own coil Green function (nova.biot.greens.greens_psi, the kernel the forward operator carries) and asserts the maximum absolute difference against the reference peak |psi|, on a relative bound of 1e-3 written in the test before scoring. A forward profile solve is not run: the case is vacuum with zero source current, so the Green function is the shipped route, and there is no converged-state receipt to assert. The state is 1-D only, so the case is not a battery rung.

COCOS transform: IDENTITY. The reference psi is total poloidal flux in Wb, in the package's internal COCOS 17 convention, and matches greens_psi with neither a factor of 2*pi nor a sign between them (median per-node ratio 1.0000000009). This is asserted by comparing absolute flux, not absorbed into a fitted scale, so a sign flip or a 2π scale would fail the rung.

Head arm 5 passed, EXIT=0, with the emitted statement “COCOS identity: reference psi is total poloidal flux (Wb), COCOS 17, matches greens_psi with no 2*pi and no sign; coil=(103.0, 101.0) I=1.0 A; map residual=9.418e-10 of peak 1.106280e-03 Wb over 4224 nodes (1 singular excluded)”. Negative control: scaling the input coil current by 1.5 (NOVA_VALIDATOR_CONTROL_SCALE=1.5) raises the residual to 0.438 of the peak and fails the 1e-3 bound, EXIT=1.
