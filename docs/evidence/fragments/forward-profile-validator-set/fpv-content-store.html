Content store lift

Lifted the machine-agnostic content-addressed cache primitives of nova/imas/machine_artifact.py into nova/database/content_store.py. The store now owns the sha256 per-file verification, the verified object root, and the no-clobber directory publication; machine_artifact.py imports them and defines none of them. tests/test_content_store.py covers publication, a verified read, and the refusal of a tampered object.
