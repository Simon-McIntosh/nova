An omitted request clip mode follows the process mode

Repair. ForwardSolveRequest.clip_mode and ResolvedForwardSolveDefaults.from_policy resolved an omitted mode to the literal "chord", so a caller that set the process mode with set_support_clip_mode("exact") and then built a request with no mode solved in chord. The three construction routes in nova/equilibrium/solve_request.py now resolve an omitted mode through forward_operator.support_clip_mode() at build time: the dataclass field uses a default factory, from_defaults fills an absent clip_mode, and from_policy takes a None sentinel and resolves it. An explicit mode always wins, and the request, its resolved defaults and its receipt always hold a concrete mode.
