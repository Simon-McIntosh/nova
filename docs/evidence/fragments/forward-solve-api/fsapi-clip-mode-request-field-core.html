Request clip-mode cache isolation

Repair. The request compilation-reuse key now includes request.clip_mode. A chord, exact, or chord-cells request therefore cannot report an in-process compilation reuse from another support branch.

Cache audit. The request cache is the only receipt-facing reuse ledger. Its key now covers the operator program identity, route, resolved policy, clip mode, array layouts, constraint shape, and enforcement names. The accelerated-program memo uses static route options and now also carries self.operator.clip_mode; source coefficients and current-like request inputs are traced leaves after their layouts are validated, while constraints, pins, carrier identity, and the receipt-only cache-hit input do not select a compiled program. The persistent JAX cache receives the operator pytree, whose static state includes the bound clip mode. ForwardTopologyState._class_margin is a per-topology-state cached read, not a request or program cache.

Gate. The focused CPU regression first fails at the review base because all three mode keys are equal. After the repair it passes: each mode has a distinct real request key; the first chord, exact, and chord-cells requests report no reuse; only a repeated chord request reports compilation_cache_hit=true.
