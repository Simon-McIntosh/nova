Shared benchmark clip-mode migration

Ten shared benchmark helpers no longer mutate the process-global support clip mode. Each mode is threaded explicitly to the operator, profile or request that evaluates support, and a helper that another module imports gains an additive clip_mode keyword whose default None keeps the prior behaviour.

Verification

The ten modules carry no reference to the retired global. Every module compiles under the shared interpreter, and every test module importing one of them runs at the archived base and at the migrated head in a fresh CPU pytest process; the run manifest records the per-module logs, the literal commands and the failure identifiers.
