Seven forward test modules carry the clip mode explicitly

The seven modules that set the process-global support clip mode now pass the mode on the object each test builds. Exact-mode fixtures set clip_mode on the operator they construct (or call with_clip_mode on a driver-built operator); the certificate helpers receive clip_mode as a keyword; the memory module drops the monkeypatches of helpers it no longer calls. The only residual failure shared with the dispatch base is the source-scan allowlist in test_solve_path_census_inputs and the pytest-timeout in the 342-cell seed-bracket test, both unchanged by this migration.
