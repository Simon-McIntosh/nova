Why the default-policy solve stops elsewhere than the comparison record

The comparison record reports two stored-state refusals under the solver's default policy: TCV stops unqualified at relative residual 0.030364200526436996 with reason 12 (ACTIVE_SET_STEP_REFUSED) and a magnetic axis admitted, and ITER stops with no magnetic axis admitted, reason 3 (NONFINITE_RESIDUAL) and a NoQualifiedAxisError. Started today from the same cases, the same stored flux map, the same machine and the same default policy, the solve stops elsewhere on both: TCV at 5.2411575147855504e-4 with reason 8 (ACTIVE_SET_ITERATION_BUDGET_EXHAUSTED) and an axis admitted, ITER at 0.12310610396516597 with reason 12 and an axis admitted.

The difference is not the solver. Between the record's cited revisions the nova/ tree is identical (git diff --stat 9047a3fe5 2a7c7c08b -- nova/ is empty), and the recorded arm's own receipt resolves a ForwardSolvePolicy equal field for field to the one today's arms resolve, on the same 355-node TCV and 341-node ITER StencilMesh and the same coefficient vector. The difference is two inputs the harness takes from the stored imas-efit case, both of which the fixtures no longer carry in the form the record used, and both of which the record's own run copy preserves as data:

  1. the fitted conductor-current vector the fixture supplies, which differs from the record-era one on every one of the 288 TCV conductors; and
  2. the stored flux state the solve starts from, which differs from the record-era state by 21.9 percent of its span in gauge-free RMS on TCV and by 47.4 percent on ITER.

Substituting the record-era values for those two inputs, and changing nothing else — same policy, same route, same mesh, same coefficients — reproduces the recorded TCV arm at 0.030442406985959472 against the recorded 0.030364200526436996, a factor of 1.0026, with the same reason code and a magnetic axis at (0.83545, -0.028185) against the record's (0.83545035, -0.02818493); and reproduces the recorded ITER arm exactly as a refusal, no magnetic axis admitted, reason 3, NoQualifiedAxisError.

The stored seed, and what substituting the record-era state does

The record's run copy keeps the state its TCV arm retained: the same 2995-node flux grid this branch builds, span 0.48433545231819153. Today's stored seed has span 0.43347705160942934, and the two differ by a gauge-free RMS of 0.09505573396245656, which is 21.9 percent of today's span. The record's own policy refuses every globalised step, so the state it retained sits close to the state it started from, and it is the only surviving copy of a record-era state.

Applied as the seed, with the comparison's currents also in place, that state reproduces the recorded arm: residual 0.030442406985959472 against 0.030364200526436996 (factor 1.0026, within a factor of three), reason 12 as recorded, and an admitted axis at (0.83545, -0.028185) against the record's (0.83545035, -0.02818493). With today's seed and the same currents the same arm gives 0.004253522137685281. The seed accounts for the factor of 7.2 that the currents leave.

On ITER the same substitution reproduces the recorded refusal: seeded from the state the record's arm held when its topology read refused, with the measured conductor currents and no fitted binding, the solve raises NoQualifiedAxisError with reason 3 and admits no magnetic axis, in one trip, which is the recorded outcome. The ITER seed is the larger of the two moves: today's stored seed spans -89.3026 to 7.6395, and the record-era state spans 19.6851 to 170.8987, so the two differ by a gauge-free RMS equal to 47.4 percent of today's span. Today's stored-coefficient arm reaches the record-era regime only by solving into it, and admits an axis on the way; started in that regime, it refuses at its first topology read, which is what the record's arm did.

Neither case's record-era seed survives — both were read from fixture files that no longer hold those bytes — so in both cases the substituted state is the record-era state the arm retained rather than the exact seed it consumed. That the substitution lands within 0.26 percent on TCV, and on the recorded axis to eight decimal places, says the retained state and the seed it started from are interchangeable at the precision the record reports.

A nudge far smaller than the fixture drift already changes the class of outcome

The same TCV comparison arm was run twice in one job on one card, once on today's seed and once on that seed multiplied by 1.000314155094935, the ratio of the record-era equilibrium's stored flux span (0.19099370558229956 Wb) to today's (0.19093372278049314 Wb). A relative change of 3.1e-4 in one input of a refusing solve is therefore enough to move the outcome between two of the three recorded refusal classes, so no intermediate input reproduces a recorded residual to a tight band: the band holds only when the record-era inputs themselves are substituted. That is why the reproduction above is a substitution and not a search.

Every terminal state beside the stored state

One panel per terminal state, drawn from the flux each arm left behind: five from the receipt the solve wrote and the ITER refusal from the trajectory pickle the solver dumped when it raised, because a solve that stops at its first topology read terminates on the state it read. Each panel contours the stored imas-efit state and the terminal iterate on one shared level array spanning both finite ranges, draws the wall, and draws both null sets — solid triangle for an admitted magnetic axis, filled cross for an admitted saddle. The panel's own topology read re-derived the axis each arm recorded to within 1e-9 on all five arms that admitted one, which is what confirms each flux vector is drawn on the mesh that produced it. The refusal arm admits no axis, so its panel carries the stored state's null markers and blue contours only.

Nothing was re-solved for these panels: each was redrawn from the flux its arm stored, in one CPU job, by scripts/prototypes/stored_state_refusals/drift_policy_panels.py.
