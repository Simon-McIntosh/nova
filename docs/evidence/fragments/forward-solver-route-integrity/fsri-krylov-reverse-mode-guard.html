tests/test_krylov_reverse_mode_guard.py guards the reverse-mode boundary of _qualified_krylov_step. That step is served by a jax.custom_batching.custom_vmap stream: the stream carries a batching rule and no derivative rule, so a caller that reverse-differentiates through it fails to linearise rather than returning the step's derivative. Five tests pin the boundary:

  1. the implicit Picard route is the reverse-mode positive case: jax.grad of the converged fixture (imported from tests/test_picard_implicit_derivative.py) returns the finite implicit tangent 1.25;
  2. every function that calls _qualified_krylov_step across every module under nova/ is enumerated by parsing the package with ast and must either be covered by a derivative rule or be named in _FORWARD_ONLY_CALLERS with a one-line reason, so an unclassified caller fails the test naming itself. Coverage is classified by call site: a call counts only when it sits lexically inside a function that is itself the rule's subject — a function decorated with custom_jvp or custom_vjp, a function registered as that rule's defjvp/defvjp function, or a function passed as the matvec, solve or transpose_solve argument of jax.lax.custom_linear_solve. A rule merely invoked somewhere else in the enclosing body does not cover the call. The four forward-only callers are _manifold_newton_krylov.newton_body.attempt_step, _newton_krylov_inner.newton_body.attempt_step, kink_aware_newton_krylov.krylov_step and kink_aware_newton_krylov.newton_body.clarke_step;
  3. a direct jax.grad through the raw step raises (ValueError: Linearization failed to produce known values for all output primals), documenting the missing rule;
  4. synthetic classifier controls prove the census can see coverage it must see: a rule-subject decorated function and a function passed as a custom_linear_solve argument both report covered, so the absence checks below mean something;
  5. a synthetic falsifying case — a function that invokes a linear-solve rule in its body but calls the step outside that rule's subject — reports uncovered, which is the regression the earlier fail-open classifier admitted.
