The four toy identity witnesses compare raw bit patterns and exit nonzero on any difference

The witnesses toy_identity.py, toy_self_identity.py, rule_toy_identity.py and exit_toy_identity.py compared fields with np.array_equal(..., equal_nan=True), which accepts a signed zero against an unsigned zero and two NaNs whose payloads differ, and three of the four counted mismatches without ever exiting nonzero. Each now compares the raw bit pattern of every field — an unsigned view of the same width, with shape and dtype checked first — prints the first differing index with both operand patterns, and exits nonzero on any difference.

Defect reproduced before the repair

On this tree's interpreter, np.array_equal(np.array([0.0]), np.array([-0.0]), equal_nan=True) is True while their patterns are 0x0000000000000000 and 0x8000000000000000, and array_equal on two NaNs at 0x7ff8000000000000 and 0x7ff8000000000001 is also True. The old predicate cannot see either difference.

Gate

Each of the four witnesses' own comparison function is driven from a scratch script under $TMPDIR over four pairs: identical arrays (equal), 1.0 against 2.0, +0.0 against −0.0, and two NaNs with payloads differing in the last bit. All four witnesses report a difference for the last three and equality for the first — 16 of 16 PASS, GATE_BITWISE_WITNESSES PASS failures=0, EXIT=0. The same run prints the old predicate accepts the signed-zero and NaN-payload pairs (old_equal_nan_accepts=True), the negative control for the check added here.

Run end to end, the dense arm of toy_identity.py now prints TOY_BASE bit_identical=6/8 and TOY_BASE_FENCED bit_identical=8/8 and exits 1 (previously it printed the same counts and exited 0). The two base-arm differences are genuine bit differences in the achieved reduction at size=12, iterations=8 (0x3fe6d0b6a44caa97 against 0x3fe6d0b6a44caa96) and size=3, iterations=8 (0x0000000000000000 against 0x3c81c475d5e81a26).
