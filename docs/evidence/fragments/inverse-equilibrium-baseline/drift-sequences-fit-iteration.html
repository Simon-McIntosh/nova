The held-map iteration run inside the fit loop over 200 slices of both drift sequences

This node fits the held-map pass of the equilibrium iteration — FluxIterationFit, the column the plan's lead ruling names for this study — over 200 slices of the white and of the 1/f reference sequence, on the same rows, the same noise draws and the same generating state the earlier imas-efit arms were measured on, and reports per-slice and 50-slice-mean error of the axis position, the boundary flux and q95 beside the lag-one controls.

The generating state is the section-1 ITER fixture at 500 cells. The state, the noise model and the pulse writer are probe_rows/study.py's; the held-map driver is probe_rows/iteration.py; every measure is probe_rows/analyse.py's reduction, and the imas-efit column is the same study's own arms.

That is the row convention the earlier record already measured, and it is why the imas-efit column here is the 24-flux-loop arm: a probe row that means a different quantity to the two readers cannot be compared, so the code comparison is stated on the loops the two readers do agree on, while the held-map fit reads its full row set as the reconstruction would in service.
