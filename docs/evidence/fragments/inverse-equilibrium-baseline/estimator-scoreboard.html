Every reconstructed state, one comparator

Each row is a case read from a stored state; each column group is one estimator's state for that case, read through imas-python at the data dictionary version its own dataset was written at and identified by the digest printed in its last cell. Values are the state's distance from the case reference, marked pass or FAIL against the registered bands; the reference-free checks are reported beside them for every column, including where the reference comparison passes. The safety factor is read for every column by one calculator, nova.imas.mast_efit_referee.q95_from_flux_map, applied to that column's own stored flux map on one surface definition (ψN = 0.95), so the q95 column compares two reconstructions rather than two stored definitions; each state's own stored safety factor is printed beside it as that definition difference, and a state carrying no flux map reads not supplied. A declared perturbation is scored as its own column from its own IMAS dataset, and a column whose state is not on disk reads not supplied rather than showing a zero. The list below names, for each column, the state it reads and how that state was formed; the receipt beside this table carries each state's digest.

reference
the generating state of the row-exchange case: its axis, fluxes, current and safety factor from record-10.json, its bounding surface traced on the stored 65 by 129 flux map half a percent of the span inside the recorded boundary flux, and that map written with the state so the safety factor is read from it rather than from a scalar record
imas-efit
imas-efit's reconstruction of the nominal nova-written pulse, read back through IMAS at the version it was written at: its own rectangular 65 by 65 flux map, its own diamagnetic gradient and its own reference radius, so one calculator reads its safety factor from the state it stored
nova-inverse-class
the nova inverse class's result on the same rows: its axis, fluxes, current and safety factor from nova-fit-10.json; its bounding surface traced on the stored flux map the fit recovered at the same edge fraction, and that map written with the state (its coefficients are 1.0 and its terminal residual 8.2e-16)
perturbed-copy
a deliberately defective copy of the nova inverse-class state: current scaled by 1.06, boundary and axis shifted 0.03 m radially, flux span grown 2% at each end, and the stored flux map's minor radius about the axis scaled by 1.06, so the defect reaches the map the safety-factor calculator reads rather than only the scalar q profile
