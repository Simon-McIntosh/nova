Every reconstructed state, one comparator

Each row is a case read from a stored state; each column group is one estimator's state for that case, read through imas-python at the data dictionary version its own dataset was written at and identified by the digest printed in its last cell. Values are the state's distance from the case reference, marked pass or FAIL against the registered bands; the reference-free checks are reported beside them for every column, including where the reference comparison passes. A declared perturbation is scored as its own column from its own IMAS dataset, and a column whose state is not on disk reads not supplied rather than showing a zero. The list below names, for each column, the state it reads and how that state was formed; the receipt beside this table carries each state's digest.
