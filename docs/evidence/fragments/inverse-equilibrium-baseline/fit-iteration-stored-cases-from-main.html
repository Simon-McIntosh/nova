ITER 135013 carries a different constraint label. Under the generating-configuration assumption the imas-efit ITER run carried a synthesised pressure prior (beta_pol = 0.5) and a q0 prior, and nova's magnetics fit carries neither, so the row is labelled same magnetics rows; different constraint sets and no section 2 band is read on it even where the fit converges. The gap is reported rather than judged.

Negative control. The 1.10 gain-error control is judged only where the fit converged; on this run no case converged, so each row records why the control was not run. A missing control value is therefore distinguishable from a control that ran and stayed inside its band, and the clause is not exercised on any converged case in this run.
