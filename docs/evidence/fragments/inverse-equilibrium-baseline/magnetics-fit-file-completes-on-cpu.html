The magnetics-fit module measured as a landing target: the abort, its site, and the collection boundary

Result. The four known-state recovery cases were the whole cost of measuring this module: the unit-level population is 44 tests and completes in 6.46 s serially and 10.32 s under -n 8, while a single known-state case costs 2346.60 s (MAST) to 3266.66 s (Solov'ev) on CPU. They carry the repository's slow marker and always have since the carriers node added it, but a named test path clears the default fast-lane marker filter in the root conftest, so every measurement that named this module selected all 48 tests. The serial arm therefore outran its ten-minute step limit, the -n 8 arm lost xdist workers, and the whole-file run reaches a native abort once more than one known-state case compiles in the same process. The cases now live in tests/test_equilibrium_magnetics_fit_known_states.py with their bodies, markers and assertions byte-identical, so a measurement naming tests/test_equilibrium_magnetics_fit.py collects only the unit-level contracts, and the known states stay reachable by naming their module or with -m "slow or not slow".

The abort: named test, named site, and the condition it needs

The aborting run's own trace names test_known_state_recovery at the line that builds its case, through ForwardProfile.solve into _solve_accelerated and JAX's pjit, and terminates inside libjax_common.so under deserialize_executable (head revision 74f147039) or backend_compile_and_load (base revision 2290fbb8), which the previous node measured in jobs 1336182, 1336288, 1336074 and 1336234. The process ends with Fatal Python error: Aborted and exit 134 before pytest prints a summary, so the arm records no failure ids — the native abort is not a test failure and no Python-level handler can catch it.

The condition the abort needs is more than one case in one process. The same test_known_state_recovery[solovev] run alone passes at both cache settings: 1 passed in 3266.66 s against the default persistent compilation cache, and 1 passed in 3245.69 s against an empty one. The empty-cache arm costing 21 s less than the warm arm says the persistent cache is not what this case spends its time on, so the abort is not a stale or truncated entry being read on its own. Under -n 8 each of the four cases lands on a worker, and the workers die as they reach that compile, which is the [gwN] node down: Not properly terminated line in the population arms.

The split moves the measured module away from that path rather than repairing it: the abort still reproduces whenever the known-state cases run together in one process, and repairing it is a separate node's work on the JAX CPU compilation route.

The negative control

Reverting the split in a scratch tree — the base module restored, the two added modules removed — makes the same command select the known-state cases again, and they fail there: 4 failed, 44 passed, exit 1, with test_known_state_recovery[solovev], [mast], [iter] and test_displaced_flux_loop_is_identified in the failing list, none of which the head arm fails. The run applied a 20 s per-test bound so a timeout records the failure instead of waiting out a 54-minute solve; the bound is the harness's, and what it shows is that the reverted tree selects tests the fixed tree does not.

What changed

tests/test_equilibrium_magnetics_fit.py keeps the 44 unit-level contracts. tests/test_equilibrium_magnetics_fit_known_states.py carries test_known_state_recovery[solovev|mast|iter] and test_displaced_flux_loop_is_identified, moved as a byte-identical move: the same @pytest.mark.slow and @pytest.mark.timeout(3500) decorators, the same assertions, the same fixture and machine construction. tests/magnetics_fit_harness.py holds the receipt persistence and diagnostic-source helpers that both modules and the comparison module use, together with the known-state case helpers physical_case_table, _physical_problem, _known_field_reader, _total_observations and _draw_recovery_panels that the prototype scripts import, and every importer imports them from that module directly, so no helper is re-exported through a test module.

No assertion was weakened. The heavy cases were not deleted and did not lose a marker; they changed module, which is what stops a measurement of this file names the four of them.
