The MAST frozen response carriers, rebuilt

The MAST known state reads its vacuum response from a store of frozen carriers rather than from the Green's function builders, so the store is an input the reconstruction depends on and not a cache it can regenerate on demand. The shared store at /work/projects/imas_gpu/nova/mast_frozen_six_response_carriers was lost with the shared data directory on 2026-11-19. With it absent, the known-state study could not construct its MAST case at all: the loader raised a bare FileNotFoundError from np.load, naming no cause and no remedy. The committed builder now refuses a missing carrier by name, and the store was rebuilt from the same six frozen reference shots.

Where the references were read from, and what was written

Both carriers were built in one batch job, SLURM 1335939 on rigel (host 98dci4-clu-2026), at revision 003e19f7e, from the committed builder in build mode. The digested contract — identity, resolved target, response shape, stored circuit count and the six reference pairs — matches its pin in both cases.

What the check mode measures, and the refusal it must fail against

Check mode reloads each persisted carrier behind an import guard that refuses the three direct builders (nova.biot.greens, nova.biot.polygon, nova.imas.mast_vacuum_response), so a passing check shows the store served the response and the builders never ran. Both grids pass at revision 1158b3a04 with direct_builders=0 (stride warm 0.0157 s, full warm 0.0426 s; logs/carrier-check.log).

The project's own pytest lane at revision 98d3c0977 runs the file's fast population green — 46 passed, 4 deselected in 8.46s, EXIT=0 — including the two checks this change adds: the named missing-carrier refusal and the grid contract resolved from the carrier file name rather than from the consumer default. The four deselected tests are the file's slow known-state population, which runs as its own batch job below rather than in a lane bounded at minutes.

The declared negative control points the store path at an empty directory. The MAST known-state test then fails at construction with the named refusal instead of passing: MissingResponseCarrier: response carrier <path> is absent; rebuild the store with `python benchmarks/mast_response_carrier_warm.py build --grid stored-axis-stride`, one failing test id and EXIT=1 in 7.35 s (logs/negative-control-empty-store.log). Before the builder named the refusal the same mutation failed as an anonymous FileNotFoundError from np.load, which is the reason the store's absence read as a broken study rather than a missing input.
