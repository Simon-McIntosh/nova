One safety-factor calculator on each column's own flux map

The scoreboard compared a safety factor each code stored for itself: imas-efit's at ψN = 0.95 on its own 65-node profile grid, nova's at ρtor = 0.95, and the declared copies from a scalar beside the dataset. That comparison reported 0.148 against the 0.1 band, while the landed row-exchange record reports 0.065 once both maps are read on one definition.

nova.imas.mast_efit_referee.q95_from_flux_map is now the single calculator. It hands a state's own stored poloidal flux map, its own magnetic axis and boundary flux, its own reference radius and its own diamagnetic gradient F dF/dψ to FluxSurfaceGeometry.from_flux_map, on one surface definition. EquilibriumState carries that map and its digest. A state that stores no map reports no measure: its q95 reads not supplied and the stored value is printed beside it, never in place of it.

Repair: flux orientation, signed span, and the owners' primitives

Three defects in the first cut are fixed, each with the check that names it. Flux orientation. The stored gradient was normalised after its physical nodes were ordered, so a map whose flux falls from the axis outward produced descending interpolation coordinates; the value was finite but wrong. The stored gradient is now normalised onto ψN and then ordered, so a map and its fully negated mirror read the same safety factor, which is the invariance test_a_descending_flux_map_reads_its_inward_gradient_tail asserts to 10−12 (reverting the ordering reads 4.88 against the mirror's 4.63).

Signed flux span. The declared perturbation rescaled the stored map by the ratio of the boundary-minus-axis spans over the absolute original span, which reflects a map whose flux span is negative even when no perturbation is declared. The ratio is now taken between the two signed spans, so a zero perturbation is the identity: test_a_zero_perturbation_leaves_a_descending_flux_map_untouched asserts the copy's map and its stored q are the source's, and reverting the ratio reddens it.

The primitives stay their owners'. Nothing in the calculator integrates or composes a field of its own any more: the inward integral is nova.equilibrium.observation.gradient_tail, handed the state's stored F dF/dψ as a function of normalised flux, so it also reads stored nonuniform nodes; the field is nova.equilibrium.convention.flux_function_toroidal_field. The only adapter left is the normalisation of the stored nodes onto ψN, which is what a stored map needs and what neither owner takes today. The regenerated table shifts by 4e−6 (the owner integrates on its 257-node grid rather than the stored nodes, exact for the piecewise-linear profiles here): imas-efit reads 0.06474, still inside the band, and the perturbed copy 0.2441, still a failure.
