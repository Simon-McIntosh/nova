One safety-factor calculator on each column's own flux map

The scoreboard compared a safety factor each code stored for itself: imas-efit's at ψN = 0.95 on its own 65-node profile grid, nova's at ρtor = 0.95, and the declared copies from a scalar beside the dataset. That comparison reported 0.148 against the 0.1 band, while the landed row-exchange record reports 0.065 once both maps are read on one definition.

nova.imas.mast_efit_referee.q95_from_flux_map is now the single calculator. It hands a state's own stored poloidal flux map, its own magnetic axis and boundary flux, its own reference radius and its own diamagnetic gradient F dF/dψ to FluxSurfaceGeometry.from_flux_map, on one surface definition. EquilibriumState carries that map and its digest. A state that stores no map reports no measure: its q95 reads not supplied and the stored value is printed beside it, never in place of it.
