The new route uses the full local volume Gram matrix Q and material differential A. With D = Q A, R = sqrt(D), and W = inv(Q) R, the Newton system has symmetric form B = (1 + λ) I − R G W. The inverse formula p = (b + W B⁻¹ R G b)/(1 + λ) avoids inverting R, so zero differential directions remain representable. Row tiles build B into one column-major buffer, donated to Cholesky; corrections are refined in the original float64 differential system. No float32 factor was used.
