Adaptive diagonal regularisation

The exact differential Jacobian remains in use. Each iteration first tries ordinary Newton, then solves (F'(M) + lambda I) p = -F(M) when necessary. A positive lambda is an implicit pseudo-time step, with local equation F(M + p) + lambda p = 0. Its linear model predicts zero residual. The measured reduction ratio is therefore rho = 1 - ||F(M + p) + lambda p||^2 / ||F(M)||^2.

A step is accepted only for rho > 0.25 and a representable displacement. The first positive lambda is 1e-6; refused positive trials multiply it by ten. An accepted regularised trial multiplies lambda by 0.3 for rho > 0.9, or by two for rho < 0.5. Trying lambda zero first restores unregularised Newton near a nonsingular root.
