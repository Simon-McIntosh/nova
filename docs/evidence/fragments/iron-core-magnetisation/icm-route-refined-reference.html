WEST uniform 40 mm: the 1.2e-12 route gap is rounding at a Newton-matrix condition number near 1e8

The in-place Cholesky Newton route and the existing LU route differ on the persisted uniform 40 mm WEST operator (6 632 cells, 39 792 affine unknowns) by frobenius_relative 1.1953e-12 and maximum_entry_relative 2.2044e-12 over the converged coefficient vector, both routes at tolerance 1e-12 in one process. This reproduces the H200 measurement 1335154 (1.2125e-12 / 2.2887e-12) to within the revision change. Both routes were then solved against an iteratively refined reference and both lie within 1.1e-12 of it, so the gap is double-precision rounding at this condition number, not a defect in either route.

Measurement

The reference is the solution of the first Newton linear system J(0) d = -F(0), which the persisted operator fixes without a nonlinear iteration, refined by iterative refinement whose float64 residuals are accumulated in longdouble until the correction stalls. The first Newton direction carries the converged state to leading order, so its distance from the reference predicts the converged coefficient difference; the measured direction gap (8.13e-13 Frobenius, 1.03e-12 max entry) and coefficient gap agree to this order. The Newton matrix condition number is a Hager one-norm estimate at the same step (||J||_1 = 11.58, ||J^-1||_1 = 8.80e6).

Verdict

Rounding. The reference error (2.39e-16) sits about three decades below the nearest route distance (2.40e-13), so the comparison resolves the gap. Both route distances are more than four decades below kappa*eps = 2.26e-8, the worst-case bound that rounding at condition number 1.02e8 allows. The LU route is the farther of the two, by 3.2× in Frobenius, consistent with the Cholesky route carrying two built-in refinement passes in the original differential system while the LU route does not; neither route is systematically wrong. A planted 1e-10 relative perturbation of a route is read as 1.0e-10 by the same comparison, so the instrument still refuses a real defect well above the rounding band.

Bar proposal

The 1e-12 route-comparison bar is below the rounding band of this operator: the routes themselves differ by 2.2e-12 at tolerance 1e-12 while each lies within 1.1e-12 of a reference that is three decades more accurate. The bar is proposed reset to 1e-11 for the route-to-route coefficient comparison, or stated as ten times kappa*eps at the measured condition number, which admits this rounding-level gap while still refusing the planted 1e-10 route defect. No code, test or interaction value was changed.
