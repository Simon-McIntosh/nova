WEST uniform 40 mm: the route gap is rounding at a Newton-matrix condition number near 1e8

The in-place Cholesky Newton route and the existing LU route differ on the persisted uniform 40 mm WEST operator (6 632 cells, 39 792 affine unknowns) by frobenius_relative 1.2517e-12 and maximum_entry_relative 3.0736e-12 over the converged coefficient vector, both routes at tolerance 1e-12 in one process. Two earlier runs of the same measurement gave 1.1953e-12 / 2.2044e-12 (job 1338206) and 1.2125e-12 / 2.2887e-12 (job 1335154), so the maximum-entry figure itself moves by nearly forty per cent between runs at this condition number, which is the size of the quantity the bar is being asked to judge. Both routes were then solved against an iteratively refined reference and each lies within 1.1e-12 of it, so the gap is double-precision rounding at this condition number, not a defect in either route.

What was compared, and what was not

The reference is the solution of the first Newton linear system J(0) d = -F(0) on the persisted operator, refined by iterative refinement whose float64 residuals are accumulated in longdouble until the correction stalls. It is a reference for the first Newton direction, not for the converged state: the first step carries the state to leading order, so its distance predicts the converged coefficient difference only to that order. The converged coefficient gap between the two routes is measured directly and reported above; each route's converged coefficient distance from a reference converged in extended precision is not measured (see the limits below). The two routes' probe fields at the three graded probes are compared in the same run, and they differ by at most 1.5536e-15 relative (1.5618e-15, 1.2323e-15 and 3.1e-17 at the individual probes), so the coefficient-level gap does not appear in the fields.

Neither route was compared entry by entry against the reference in the converged state, and no interaction value, solve or bar was changed by this measurement.

Measurement

The Newton matrix condition number is a Hager one-norm estimate at the same step (||J||_1 = 11.58, ||J^-1||_1 = 8.80e6). The resolvability check tests the nearest route distance, which is the smaller over routes of each route's larger of its two measures: 2.9007e-13 (the Cholesky route's maximum-entry distance; the LU route's maximum-entry distance is 1.0241e-12). The reference's own forward error, 2.3410e-16, sits 3.1 decades below that tested figure, so the comparison resolves the gap.

Control: a real route defect is refused

The comparison was tested against a genuine route fault rather than a scaled copy of the reference. The Newton matrix is multiplied by 1 + 1e-10 before its own LU factorisation and solve, and that perturbed route is fed to the same distance comparison and the same verdict classifier. Scaling the matrix by 1 + 1e-10 scales its solution by 1 / (1 + 1e-10), so a comparison working as intended must place the perturbed route about 1e-10 from the reference, whatever the route's own arithmetic contributes.

On the persisted operator the perturbed route reads 1.0000e-10 Frobenius / 9.9836e-11 maximum entry from the refined reference, against 2.9007e-13 for the nearest unperturbed route and 1.0241e-12 for the largest. It therefore sits 345× (2.5 decades) farther than the nearest unperturbed route and 98× (2.0 decades) farther than the largest, and the same classifier returns defect rather than rounding on it. A fault of this size is a hundred times the 1e-12 route-comparison bar and ten times the 1e-11 bar proposed below, so the detector refuses it under either bar. Log: refine-route-1338337.log, revision 0aac2aaa.

The same control on the smaller gate_shell 0.08 m mesh (a synthetic interaction table) reads 9.9998e-11 against unperturbed routes at 7.97e-15 and 1.46e-14, 4.1 decades above the nearest, and is likewise classified defect (logs/defect-smoke.log in the run directory, revision 383f60581).

Verdict

Rounding, and both measured checks support it. The two routes' distances are 4.3 decades below kappa*eps = 2.26e-8, the worst-case bound that rounding at condition number 1.02e8 allows, and the farther route exceeds the nearer by only 3.4× in Frobenius (3.5× in the maximum entry). The probe fields the two routes produce differ by 1.5536e-15 relative, 640× below the existing bar, so the coefficient-level gap leaves no trace in a quantity the solver hands downstream. The LU route is the farther of the two, consistent with the Cholesky route carrying two built-in refinement passes in the same differential system while the LU route does not; neither route is systematically wrong.

Bar proposal

The 1e-12 route-comparison bar is below the rounding band of this operator: the routes differ by 3.07e-12 at their largest entry at tolerance 1e-12 while each lies within 1.02e-12 of a reference that is three decades more accurate, and that largest-entry figure varied between 2.20e-12 and 3.07e-12 across three runs of the same measurement. The bar is proposed reset to 1e-11 for the route-to-route coefficient comparison, or stated as ten times kappa*eps (2.26e-7) at the measured condition number, which admits this rounding-level gap while still refusing the 1e-10 factor defect measured in the control above. No code, test or interaction value was changed.

Limits and follow-up

The extended-precision reference covers the first Newton linear system only. A nonlinear reference converged in extended precision would require the material residual and the 39 792-unknown Jacobian to be formed in extended precision on every Newton step, which the current route cannot do within this measurement; each route's converged coefficient distance from such a reference is therefore not reported. The converged coefficient gap between the routes, and their probe-field gap, are reported directly above.

Follow-up work: the measurement rebuilds the affine Newton operands in scripts/west_iron_linear/measure.py, duplicating the assembly that nova/biot/magnetisation.py performs inside the solve. A later node should export that builder from the module and have the script call it, so the two cannot drift; this node deliberately changed nothing under nova/.
