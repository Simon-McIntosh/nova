Exact on-axis integral and its singular case

A circular loop of radius a at height h above an axis target carries BZ = μ0I a²/[2(a²+h²)3/2]. A sheet strip of arclength ds carries I = K ds. If a straight sheet starts at the target (0, z0) with unit tangent (u, v), then a = us, h = vs and u²+v² = 1. Consequently, for u ≠ 0, 

B_Z(δ) = μ₀ K u²/2 ∫[δ,L] ds/s = μ₀ K u²/2 log(L/δ) → +∞  (K > 0).

This is a physical logarithmic divergence, even though the source area element 2πa ds vanishes at the endpoint. For a sheet lying entirely on the axis, u = 0 and the current surface has zero area, so its field is exactly zero. That fact does not extend to a sheet which leaves the axis with u ≠ 0. At disjoint on-axis targets symmetry gives BR = 0 and ψ = 0; their finite BZ still needs implementation.

For completeness, the disjoint-target integral is elementary. Write a(s) = a₀ + us, h(s) = h₀ + vs, d = ua₀ + vh₀, c = va₀ − uh₀, t = s+d and D = sqrt(t²+c²). For c ≠ 0 its primitive is 

F(t) = u² asinh(t/|c|) + (v²−u²)t/D − 2uvc/D,
B_Z = μ₀ K [F(L+d)−F(d)]/2.

For c = 0 and an interval separated from t = 0, the primitive is u² sign(t) log|t|. If the interval reaches t = 0 with u ≠ 0, its improper integral diverges. A horizontal sheet at its axis endpoint is included in the same result with u = 1, v = 0.
