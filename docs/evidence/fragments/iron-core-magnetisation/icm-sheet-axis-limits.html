Zero-radius sources: derived limits

For an edge lying entirely on the axis the area element 2πR′ dl vanishes everywhere. Its sheet field and flux are exactly zero, selected before either evaluation family enters an elliptic or grading expression.

For one source end at R′ = 0 and R > 0, let b = dR′/dZ′, a = sqrt(1+b²), γ = Z′−Z, and d = sqrt(R²+γ²). The root integral is ∫ cos(φ) D dφ = d ∫ cos(φ) dφ = 0, as are its γ and R derivatives. The remaining primitive is elementary: at this end, 

asinh(β) = atanh[(γ − b R cos φ)/(a d)],
S₀ = ∫[0,π] cos φ (−bγ + b²R cos φ) atanh[(γ − bR cos φ)/(ad)] dφ.

Integrating the first two cosine moments of the logarithm gives the closed forms below. The flux primitive is μ₀ R S₀/a². The b = 0 case is S₀ = 0. 

For |bγ| ≤ R:
  S₀ = πb²/2 [γd/R + R asinh(γ/R)],
  ∂γ S₀ = πb² d/R,
  ∂R S₀ = πb²/2 [asinh(γ/R) − γd/R²].
For |bγ| > R:
  C = π sign(γ)/2 [a + b² asinh(1/|b|)],
  S₀ = RC,    ∂γ S₀ = 0,    ∂R S₀ = C.

These expressions serve the scalar primitive, both scalar field families, and the packed field. The grading map also has a regular one-sided limit: writing its fractional panel coordinate as x, w sinh[x asinh(π/w)] tends to πx as w tends to infinity, and its Jacobian tends to π. At the zero source end the elementary primitive above evaluates that limit directly; no infinite width reaches the map. In traced selections the inactive geometry is held at a regular value before division or differentiation.

On-axis target: derived limits

Symmetry gives BR = 0 and ψ = 0. Parameterise the source by arclength s with R′ = R₀+us, h = Z′−Z = h₀+vs, u²+v² = 1, 0 ≤ s ≤ L. Define d = uR₀+vh₀, c = vR₀−uh₀, t = s+d and D = sqrt(t²+c²). Then R′ = ut+vc, and the circular loop's axis field integrates as 

B_Z = μ₀ K/2 ∫[0,L] (R′)²/[(R′)²+h²]^(3/2) ds
    = μ₀ K/2 [F(L+d) − F(d)],

The collinear form applies on intervals separated from t = 0. An interval reaching zero is outside the finite-field domain. Preserving the finite-radius approach

Taking a limit only at zero leaves subtractive cancellation nearby. The root uses its binomial cosine-moment series for q = 2RR′/(γ²+R²+R′²) ≤ 1/4, through degree 31. For sloped small-source ends, the Legendre addition theorem integrates the flux along arclength without quadrature: 

γ₀ = γ − R′/b,    D₀ = sqrt(R²+γ₀²),

H = sign(b) u² Σ[n≥1] q^(n+2) P′_n(t) P′_n(v)/[n(n+1)(n+2)],
S = S₀(γ₀,R,b) + πa²R H,    ψ_primitive = μ₀ R S/a².

The source series uses 80 terms at q ≤ 1/2 on the exterior branch, with analytic γ and R derivatives carried through the same polynomial recurrence.
