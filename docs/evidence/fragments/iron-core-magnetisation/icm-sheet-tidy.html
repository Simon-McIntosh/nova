§2 — The closed-form sheet routes, tidied

Node icm-sheet-tidy closes the five non-blocking findings of the closed-form field review and the blocking finding of the pancake review. No measured value moves: every value test on tests/test_edge_sheet.py and tests/test_biotcompleteelliptic.py stays at the section's 1e-10 floor and passes unchanged — 416 tests, exit 0.

The route flag now means one thing at every slope

Before this node closed=True inverted its own meaning with geometry: it selected the closed form on a sloped segment and the surface-current quadrature on a flat one. The keyword is replaced by route, whose values are "closed" and "quadrature":

sheetroute="closed" (default)route="quadrature"
flat (slope 0)Snow eqs (26)/(27), _pancake_flux/_pancake_field_flat_flux/_flat_field
vertical (slope pi/2) and slopedeq (24) flux, closed antiderivative's own partials for the fieldantiderivative / _sloped_field

test_route_flag_selects_one_family_at_every_slope instruments every evaluator and asserts the flag reaches the closed family's members at 0, pi/4 and pi/2, and the quadrature family's at the same three; test_route_flag_defaults_to_the_closed_form asserts the unqualified call is the closed one; and an unknown route is refused rather than silently resolved.

A value comparison cannot see the route, so the guard does

The closed and graded routes agree to the floor by design, so replacing the closed route's body with the graded one leaves every value test green. Two guards close that: test_closed_flux_route_evaluates_the_elliptic_form spies on complete_kind in the module and requires the closed flux route to reach it and the quadrature route not to, at every slope; and test_closed_field_route_evaluates_the_closed_block requires _pancake_field on a flat sheet and the jitted _closed_root_gradient at every other slope. test_closed_root_is_the_elliptic_block checks the closed R against eq (22a) formed independently from the complete kinds, to 1e-14.

The declared negative control replaces _sloped_field_closed's body with the graded route: 4 failed, 6 passed, exit 1, the four failures being every non-flat slope. The log is /home/ITER/mcintos/.config/reckon/crew/runs/r-20261107T205044504786-icm-sheet-tidy/logs/negative-control.log.

The agreement checks the R block only

Both routes take the paper's arsinh remainder from _arsinh_gradient, so the closed-versus-graded agreement is a statement about R alone: A is shared by construction and cancels identically. The two agreement tests say so in their docstrings, and this record says so here.

The flat sheet's arsinh remainder is the owner's

_pancake_remainder and its private double-exponential rule are deleted. _pancake_terms now calls nova.biot.zeta.zeta(rp, r, gamma, pi/2), this repository's owner of that integral and of the tanh-sinh rule its near-plane case needs. The closed field evaluation, jitted

The closed field route built a fresh root_part closure and ran jax.value_and_grad on it, so every call re-traced the program. The R block is now a module-level jax.jit'd function evaluated through one cached value_and_grad, and configure_dtypes() is called once at import rather than on each evaluation. Ownership and lazy rules

_complete_kind_traced moved to nova/biot/completeelliptic.py as complete_kind_traced, beside complete_kind and _complete_kind_tangent, and sheet.py imports it. The redundant import jax and import jax.numpy as jnp inside _closed_gradient are gone; the module already binds both, and the only import that had a reason to be local — nova.jax.config — is now a module-scope import made once. Every fixed rule still in sheet.py is built lazily behind functools.lru_cache (_gauss_rule, _graded_nodes, _field_rule), as the rules in nova/biot/zeta.py are, so importing the module builds no rule.

The pancake edge-flip control exercises the module's assembly

test_one_edge_flipped_fails_the_pancake_comparison previously assembled its own flipped sum inside the test body, so it never exercised _pancake_flux. It now flips one end's antiderivative as the module calls it and takes the value from the public SheetFlux.flux, so the assembly under test is _pancake_flux's own two-ends difference: a regression that adds the ends returns the reference value and reddens this control.
