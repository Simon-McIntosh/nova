The per-end denominator, and why the gate is still unmeasured

The agreement gate now divides each entry by the absolute sum of that entry's per-end antiderivative terms, which is the denominator the section specifies, and the packed closed form no longer returns NaN beyond a sloped edge's end. Both changes are committed and the fast lane is green. The gate itself is not measured: at the measured cost a 1696-target run is about 46 minutes of compute on eight cores across its three passes, and it did not return inside this node's fence.

The 46 minutes is pure compute. Import and JIT compile are paid again by every spawned shard, and the two suite arms are outside it, so the whole-mesh run does not fit a 60-minute CPU lane. The section already routes heavy gates to betelgeuse under gpu_0003_grpA, which is where this one belongs; the gate was re-run there by nothing yet.

The finiteness clause was failing in this node's own scope

nova/biot/sheet.py was fixed to take the phi = 0 curvature argument and the r1 + r panel centre as magnitudes, because a target beyond a sloped segment's ends or on the far side of its line puts r1 + r b12 below zero and the square root returns an imaginary. The tile does not call that code: it evaluates a packed transcription of the same closed form in nova/biot/tiledassembly.py, which still carried the pre-fix signed forms. So the tile and its own reference both returned NaN for a whole field component on targets beyond an edge end — the two sides agreeing perfectly on an undefined value while the gate failed on finiteness rather than on agreement. Both terms are magnitudes now, and _sheet_arsinh_gradient grades the end nearer the azimuth where its arsinh denominator vanishes, mirroring the host route. The packed form evaluates a block at once, so that end selection is broadcast over the rule's node axis rather than applied to a scalar.

The denominator

packed_sheet_end_scale returns, per pair and per component, the sum of the absolute values of the two segment-end terms that packed_sheet_field subtracts. It mirrors the field's branch structure — the sloped route's two end gradients, the flat route's two pancake ends — so a block mixing flat and sloped edges remains one program, and it reuses the same _sheet_closed_gradient and _sheet_pancake_terms rather than re-deriving the closed form. The tests contract it against the cell incidence exactly as they contract the field, so the gate and its negative control share one denominator.

What remains

  • Run the gate on the H200 rung over the whole mesh: every entry finite, worst entry within 1e-13 of the per-end scale, with the distribution recorded here.
  • Run the negative control there too. It is wired — setting NOVA_SHEET_TILE_REVERSE_NORMALS=0 reverses one cell's edge normals in the device build and drives the same gate test — but no red log was produced inside this fence, so the declared mutation is unproven.
  • The denominator does not by itself close the gate. A read-only attempt measured the worst finite entry at about 1e-8 under the per-end scale across eleven target rows, against 0.077 to 1.67 under the per-edge one, so the residual is a disagreement between the padded tile and the flat walk and not an artefact of a cancelling sum. It needs a pair-level comparison on the pairs that carry it.
