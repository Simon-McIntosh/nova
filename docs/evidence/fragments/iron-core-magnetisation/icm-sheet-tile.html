The sheet tile is built and the mechanism works; the node's numeric gate is not met. nova/biot/tiledassembly.py now carries a sheet tile beside the polygon, moment and arc tiles — packed_sheet_field, _fill_sheet_tile, _warm_sheet_evaluator, sheet_edge_field, cell_edges and cell_interaction — so G is built through the tile plan, padded to the plan's one (block, nodes) shape and scanned over blocks.

The 4.06e-13 is roughly two orders of magnitude above pure round-off and is not absorbed by widening the tolerance. The batched path takes the elliptic block's derivative through a vmap of value_and_grad where the host route calls its jitted scalar form once per end, so the two order the R block differently; B_Z then carries value + r dS/dr, a difference of two order-r quantities, which is where the cancellation is amplified. Settling it needs the per-entry error map over the axes and a fixed order on both sides.
