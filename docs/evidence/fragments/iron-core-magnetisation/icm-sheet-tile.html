The edge-sheet tile and G

The sheet tile is built and G is assembled through it, but the node's 1e-13 agreement gate is not met, and the measurement found a defect upstream of the tile. Two of the three questions are settled: the tile's padding and batching reproduce the closed form exactly wherever the closed form returns a number, and the flat and sloped branches are now both traced and dispatched by edge slope. What blocks the gate is that the host closed form in nova/biot/sheet.py itself returns NaN for roughly three entries in ten on the prototype mesh, and the entries that remain are cancellation-dominated, so the gate's denominator is a small fraction of the terms being summed.

Where the worst entries sit

The worst finite entries are (20, 1025), (19, 1025), (20, 1026), (4–11, 425–432) and (18, 1033). Every one of them carries an entry value near -1.2e-14 against a contribution scale of 3.3e-13: the entry is the small remainder of a sum whose terms are an order of magnitude larger, so the fraction the gate asks for is being taken of a cancelling sum rather than of a well-conditioned one. The tile and the reference print the same value to seven significant digits at every one of them; what differs is the last bits of the accumulated edge-field sum, and no float64 evaluation of this expression can do better on entries whose own value is a hundred-fold smaller than the terms it is made of. That is a statement about the gate's denominator, not a licence to widen it: the gate is reported unmet.

The upstream defect the gate exposed

sheet.py computes 2 sqrt(r (r1 + r b1 b1)) for the lower antiderivative limit, and for a target far from a sloped edge on the side beyond the edge's start, r1 + r b1 b1 is negative — the square root is undefined and the whole B_Z comes back NaN. Measured on target 4 of the prototype mesh: edges 753, 792, 794, 831, 833 and 866 return a finite B_R and a NaN B_Z, while the host route raises the same warning and returns the same NaN. The traced kernel reproduces the host exactly here, so this is not a tile defect — it is a domain the closed form does not cover, and it takes out 29 per cent of the interaction matrix. Nothing downstream can be gated until that branch is written.

The flat branch

Horizontal edges have no slope, so the sloped antiderivative does not apply. The Snow pancake route sheet.py uses — its third-kind blocks expressed as complete elliptic integrals with the characteristic reduced through zeta — is now traced inside the padded tile and selected by edge slope, so no edge is refused. Its agreement with the host route is ~1e-15 on mixed flat and sloped pairs.

What remains

  • The NaN domain in sheet.py: the lower-limit square root needs its complementary branch for a target on the far side of a sloped edge's start. This is a change to nova/biot/sheet.py, which is outside this node's write path, and it is the reason 29 per cent of G is undefined.
  • The 1e-13 gate as specified, once that branch exists: the remaining 1e-8 is concentrated on cancellation-dominated entries, so the gate's form needs a decision — an absolute floor tied to the term magnitudes, or a comparison of the two sides at the level of each edge field rather than each sum.
  • The full 1696-target build to a complete error map. The host has 8 cores and the sharded run did not finish inside this node's fence; the slice above is one shard's worth, contiguous in target index.
