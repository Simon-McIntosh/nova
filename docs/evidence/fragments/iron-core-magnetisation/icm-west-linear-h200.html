Interaction persistence and controls

solve_magnetisation accepts an optional persisted interaction; its default assembly route is unchanged. The response is stored as float64 NPY with a sidecar identity containing the basis and SHA-256 digest of the ordered mesh vertices. Both loading and solving verify the geometry, component layout, shape and finite float64 entries before using the response. Currents, the B-H law and time are excluded from the geometry identity.
