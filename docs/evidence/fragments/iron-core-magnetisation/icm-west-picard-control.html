Frozen-permeability Picard converges on WEST 62751, in 12 iterations against Newton's 4, so the plan's negative control is refuted on the operator the solve uses

The plan asks for a frozen-permeability Picard run on WEST 62751, started from M = 0 at full drive with the continuation the Newton run used, recorded as failing to converge, as the negative control for choosing Newton. Run exactly that way on the Galerkin operator that landed in nova/biot/magnetisation.py, the iteration converges: the solver-normalised residual falls from 0.9977 to 7.78e-11 in twelve iterations, below the 1e-10 tolerance the Newton run used, at a steady 0.276 per iteration once the first two corrections have passed. Newton reaches 5.84e-14 in four. The recorded Newton history reproduced on the same operator, mesh and tolerance to a maximum relative 5.96e-05, which is the roundoff floor of a repeat run rather than a change of operator.

The negative control this node was dispatched to record is therefore not available as stated. What follows records the iteration, its limit, two analytic positive controls that show the iteration is implemented and not merely tolerant, and one further arm that explains where the plan's expectation came from.

The iteration

At each step the secant coefficient c(|B|) = M/B is evaluated at the current iterate's field and held fixed; the next iterate solves (I - diag(c) G) M = c B_ext exactly by dense LU, so no inner truncation is charged to the method. There is no damping, and the start is a demagnetised state at full drive, which is the first of the two continuations the plan permits. The residual is the production F(M) = M - c(|B|) B with B = B_ext + G M. The table records it in both normalisations: ||F|| / max(||M||, ||B_ext||/μ0), which is what the Newton tolerance is applied to, and ||F|| / ||M||, which is the control's own definition and is undefined at the demagnetised seed.

The verdict, and what the two states agree to

The Picard limit is a root of the same equation Newton solved. Its permeability range is 215.55466 to 1616.97181 against Newton's 215.55466 to 1616.97182, and its largest cell magnetisation is 680052.864 A/m against Newton's 680052.876 A/m. The states differ by 1.57e-07 relative at the largest cell, which is far above both residuals: the residual map is flat along the direction that carries that difference, so a residual below 1e-10 does not pin the state below 1e-07 there. Both methods satisfy the tolerance they were held to and both are roots of the discrete problem; the states are not identical.

Positive controls: the same iteration where it must converge

Both controls use the analytic shell of the magnetisation tests (inner radius 0.9 m, outer 1.0 m, 228 cells at 0.04 m) and the same iterate routine as the WEST run. The linear law is a constant μr = 10, for which the frozen coefficient is exact and the iteration must terminate in one solve. The second law rises from 10 to 12 over one tesla, so the coefficient changes between iterates and the iteration must take more than one step while still converging.

Its state matches the production Newton solve to 5.2e-15. A Picard convergence on WEST is therefore a property of that problem and not a harness that reports success whatever it is given: the same code produces a limit cycle on the next arm.

Why the plan expected failure: the same iteration on the centroid-sampled operator

The expectation was formed against the centroid-sampled interaction, which the plan excludes by name because its spectrum of G/μ0 leaves [0, 1] on the mesh then in use and its roots are not unique. Running the same frozen-permeability iteration on that operator, built on this same 1695-cell mesh and driven by centroid samples of the same prescribed field, it does not converge: fifty iterations end on a period-four cycle whose residual repeats 2.3826e-3, 6.1514e-04, 5.5366e-04, 4.2584e-04 and whose largest cell magnetisation swings between 696499 and 1530887 A/m, a factor of 2.2.

The spectrum alone does not explain it, and that is worth recording rather than smoothing over. On this mesh the centroid-sampled operator's volume-weighted spectrum lies inside [0, 1] (minimum 1.90e-04, maximum 0.99976), so the criterion the plan states is satisfied here. What it does not satisfy is symmetry: its volume-weighted asymmetry defect is 2.71e-02, where the Galerkin operator's is 1.78e-17. A non-symmetric operator's spectrum need not be real, so modes whose complex eigenvalues sit near the unit circle produce a cycle rather than a contraction, and the cycle observed has the fixed amplitude such a pair would give. The Galerkin repair made the operator symmetric in the volume inner product, and with it the frozen-coefficient iteration contracts. This arm is a different discretisation of the same case and is recorded as the explanation for the plan's expectation, not as the negative control the plan requires.

Disposition

Measured on the operator the solve uses, clause (2) of this section's done-when is not met: the control that was to fail does not fail.
