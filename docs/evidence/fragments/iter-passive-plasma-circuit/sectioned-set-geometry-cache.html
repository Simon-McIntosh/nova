The sectioned-set cache carries the refined conductor geometry

landing: the sectioned-set cache now stores the refined conductor geometry it was built from, and one loader assembles the machine coupled_plant(machine, source) takes from a cache entry. save_conductor_geometry/load_conductor_geometry in nova/circuit/conductor.py serialise a ThicknessSubdivision (every conductor column, the polygon section overrides, and the circuit and parent map). nova/circuit/passive.py adds save_sectioned_geometry and load_sectioned_machine, returning a SectionedMachine whose conductors, series, coil_names, passive_system and section fields are exactly what the coupled-plant call reads. scripts/iter_sectioned_conductor_set/build.py writes the geometry beside linkage.npy and system.npz at the same key (the key already covers every geometry input), and conductor_geometry in scripts/iter_vessel_evolution/evolve.py reads from the loader instead of rebuilding.

The loaded geometry is bit-identical to an in-process rebuild. The build writes the refined set at the entry, the loader reads it back, and every conductor column, the circuit array, the parent map and the resistance factors are compared with np.testing.assert_array_equal against a fresh subdivide_passive_thickness call (polygon vertices included, value for value). This is measured on the small fixture and on a scratch copy of the real 12 mm entry (key 68df15665ab2ea45f427), whose 1,312 passive circuits are refined and reloaded. The key is unchanged by the addition: the written geometry lands in the existing entry directory, and the pinned coupled-plant entry 28148563521d92a2198b/plant.npz still loads (14 coils, terminal-only, no section block) untouched.

An entry without the geometry is refused by name. load_sectioned_machine on an entry holding only linkage.npy and system.npz raises SectionedGeometryMissing; the test builds exactly that fixture and asserts the refusal, so a pre-change entry is never served as a reduced machine or silently rebuilt.

The production path rebuilds nothing. conductor_geometry in the vessel-evolution driver is load_sectioned_machine over the cached entry. The test patches nova.circuit.conductor.subdivide_passive_thickness with a spy that raises, and drives evolve.conductor_geometry over a scratch entry: the spy records zero calls and the returned conductors and parent map match the fixture. The literal negative control removes the geometry write from the build (write_geometry returns None): the round-trip test then fails on its own assertion — assert path is not None, "the build wrote no geometry beside the linkage" — with EXIT=1, on a test id the head arm passes.
