Importer failure-id delta of the shared point jet

Every file below ran in a fresh process, one process per file and arm, with the JAX compilation cache disabled before JAX initialised, the repository's single project environment as the interpreter, and PYTHONPATH naming the tree under test. Each arm is judged only against the other arm on the same device, because a compile wall differs by device and a failure count does not. The verdict is the set of failed and errored test ids present at head and absent from the base arm on that same device; a failure the base arm already carries is reported, not repaired. An id is a failed or an errored test, not a failed-and-passed line, so a file whose fixtures error contributes those ids as well.
