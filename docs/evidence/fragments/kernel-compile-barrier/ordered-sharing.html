A reproducible constant-folding departure

A scalar CPU probe using the identity geometry gives norm = -2.2621729278774393e-05. Direct division -norm / (4π) is 0x1.e33b6dca45d11p-20; reciprocal multiplication norm * (-1 / (4π)) is 0x1.e33b6dca45d12p-20. Compiling the direct expression times 3.4 gives 0x1.9abf50858824ep-18, while putting that expression inside a two-element map gives 0x1.9abf50858824fp-18. This is a last-bit difference, not a sign of zero. The lowered loop takes the constant norm as a loop operand, so the divide reaches XLA inside the loop body rather than in the outer constant expression.

Titan job 1315040 confirms the first differing named intermediate is radial_central. The original uninstrumented packed output and the instrumented intermediate both reproduce the recorded point and exact hex values: reference -0x1.899fdf4452628p-36, mapped -0x1.899fdf4452629p-36. Among the first 100 identity points, 82 primal entries and 84 tangent entries differ; every other captured named quantity is identical. The tangent at the first point changes from 0x1.68d95c291432cp-38 to 0x1.68d95c291432dp-38. This locates the packed byte-offset-32 departure at the negative field scale rather than at the contour sum or Richardson combination. Production source-row and radial-radial Hessian localization are still pending. The scalar probe is retained as factor_probe.py in the run directory.
