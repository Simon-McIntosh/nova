The panel is drawn through nova.media.poloidal and the census is measured from the committed fixture; the receipt diverted-oracle-census.json beside the PNG carries every number the caption quotes, each under a named JSON path.

The caption, corrected

The one correction to the archived caption is the read axis: it reads (1.78656, 0.04671) m, not the archived (1.78507, 0.04669) m. The read moved because the linear read's magnetic-axis qualification landed after the archived rendering was captured, so the regenerated read reports a different axis while the analytic reference and the non-finite read x-point are unchanged.
