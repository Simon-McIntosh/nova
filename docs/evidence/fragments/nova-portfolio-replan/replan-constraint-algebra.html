The base census of the seven concrete constraint methods reproduced the duplicated algebra: six contain return (self.observed(profile, context, payload) - target) / scale. CurrentCentroidConstraint computes the same scaled observation into held, then selects the carried unknown for inactive rows.

Commit ee3a96d79 introduces _constraint_residual as the single scaled-observation formula; all seven concrete methods delegate to it. The centroid method passes an explicit active-mask option, preserving its inactive-row values.
