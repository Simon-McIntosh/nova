One IMAS entry opener

open_db_entry(uri, mode="r", dd_version=None, backend=None) in nova/imas/dataset.py is now the only place a imas.DBEntry is constructed. It passes dd_version only when the caller knows it, so a store is never opened at a version the caller did not name, and it routes a named backend into the URI scheme, which is how imas-python selects an access layer. The Dataset.db_entry property and Dataset.is_valid both call it. Eleven modules that built entries themselves now call it, each keeping the version that site already passed, and nova/imas/db_entry.py is deleted because its DBEntry subclass had no call sites.

grep -rn "imas.DBEntry(" nova/ --include=*.py returns one line, the opener's own construction: nova/imas/dataset.py:540.
