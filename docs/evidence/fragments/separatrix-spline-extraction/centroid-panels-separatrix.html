The centroid panels draw their assembled separatrix at the raised branch capacity

The three MAST centroid states are drawn from their stored currents and cell moments at a branch capacity of 2,048 segments, and on every lane the separatrix assembly succeeds. The previous record on the same lanes found the assembler refusing with overflow true at the 256-segment capacity the fine display grid then carried; the capacity is now 1 << (2 * (radius.size + height.size) - 1).bit_length(), which is 2,048 for a 401 by 195 display grid, and the refusal does not recur. Each lane's map is built at the 10 mm display spacing floor: 78,195 points, the saddle polished on the map's own tensor spline, and the branches assembled at the map's own saddle flux. The saddle sits 13.19 mm (cpu and titan) and 9.91 mm (full-axis) from the lattice spline's own saddle, and the map reproduces the operator's raster image at the lattice nodes to 0.0e0 and 2.7e-16 relative error. The node mismatch against the converged state remains 8.25e-3 Wb (cpu and titan) and 8.42e-3 Wb (full-axis), as the earlier record reported: it is the fixed-point residual of the state the panel draws, and it is reported rather than absorbed.

The delivered test checked the redrawn receipt's assembler block but not the committed one, so a receipt rewritten without it would have been indistinguishable from a lane whose map was refused. That gap was reproduced before it was closed: a receipt with the boundary_assembler block stripped passed the earlier committed-side checks and is refused by the ones committed here. The test now asserts the block on the committed receipt — available, well_formed and a positive closed-segment count — and asserts that the redraw agrees with it on both well_formed and closed_segment_count.

The current-perturbation control had no way to be run on demand. It is now switched by NOVA_PANEL_STATIC_CURRENT_CONTROL=1: the redraw's copy of the state keeps the stored current, so the one-percent edit never reaches the draw and the contour-movement guard must fail. A control that passes is a guard that does not fire, and this one is reported by its failure, not its success.

The gate is CPU work on a shared partition. One display-map build measured 705, 693 and 667 seconds across the cpu lane's three tests, so the producer's entry point is now memoized per state for the session and each lane builds its map once; that is what lets the file be measured inside one allocation.
