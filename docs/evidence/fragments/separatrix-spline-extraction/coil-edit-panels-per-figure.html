Each coil-edit panel is drawn from its own re-solved state

The five coil-edit converged-versus-non-converged figures were re-solved with the producer invocation each receipt records, one invocation per figure, and each figure redrawn from its own panel-states.npz. Before this node, all five figures read two regenerated archives: the three H200 figures shared one file and the two P100 figures shared another, so every published row carried the same promoted count, saddle offset and solved-node mismatch whatever its lane.

Every figure's invocation was recovered from the solve and render blocks of its own panel-receipt.json, which record the command, job id, partition, device and source revision. The three H200 figures recover the same sweep invocation and the two P100 figures recover the titan one, because that is what those runs actually were: the difference the node repairs is that each figure now carries the state of its own execution rather than a copy of another figure's file. No figure was composed from a neighbour: each receipt's command names its own output directory, and the render test asserts that path appears in the receipt it reads.

The first re-solve stopped at edit 3 of 20 on both P100 figures. The receipt is written after every edit with a strict JSON dump, and the active-set residual trace of that edit carried a non-finite entry, so the dump raised rather than persist the row. A residual the solver could not evaluate is now written as null: the remaining seventeen edits are still sound, and an unevaluated value is not a number a reader can use. The document is still written with allow_nan=False; the serialiser walks it first and turns any non-finite float into null, so no single unevaluated value can abort a sweep and no NaN reaches a reader.
