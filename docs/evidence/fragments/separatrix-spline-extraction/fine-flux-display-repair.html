Fine-grid display flux map — repair

The display flux map now reads its saddles and its separatrix off its own field with the same machinery the solve uses, and evaluates its plasma coupling through the operator's own FluxTarget. The finite-difference saddle search is gone: both the fine map's saddle and the lattice spline's saddle are polished with polish_stationary_points on a tensor spline fit of the field, and the map's separatrix branches are assembled with assemble_separatrix_branches at the polished saddle's own value — the same stationary value boundary_flux_at_admitted_saddle reads from that field, taken here from the polish the map has already run — so a panel draws the separatrix and the contours from one field.

Negative control

Swapping the radial and vertical moment columns in the display build's FluxTarget makes the reproduction test fail: the map then misses raster_image by a relative 2.53e-2 against a 1e-10 gate. The log is negative-control.log in the run directory; its last line is EXIT=1.

The moment columns are exercised

The fixture carries non-zero radial and vertical moment columns that differ from each other, and a test asserts that zeroing them moves the flux by more than 1e-2 relative, so a dropped or swapped column cannot pass unnoticed.

Converged solve

A manufactured source law closes the operator's write-then-read map: the state is iterated through raster_image of its own moments until the map stops moving, and the terminal residual is the largest node change the last evaluation produced. The display map built from that converged state reports a node mismatch equal to that residual (asserted to 1e-6 relative, and within ten times it, as the section requires). Zeroing the builder's mismatch report reddens the test, whose log is control-mismatch.log.

A saddle that is not one is reported absent

The polish is the only authority on where the saddle is, so it is not allowed to fail open. When it does not converge, or when the Hessian at the polished point is not of saddle type, the map reports the saddle position and value as NaN, carries saddle_converged false and assembles no branches, so well_formed reads false. Without that, a seed landing on an extremum would return the seed coordinate and the field's value there, and the panel would draw a separatrix through an O-point. A test seeds the diverted fixture at its own O-point and asserts exactly that refusal.

The separatrix is asserted, not just assembled

A second fixture evaluates a diverted field with one closed lobe and two legs — the same null configuration the branch assembler's own tests use, scaled into a 330 mm box so a 10 mm display grid samples it at the resolution that assembler is exercised at. The test reads display.branches, requires a well-formed assembly with a closed branch and two open legs, and compares every branch array to a direct assemble_separatrix_branches call on the map's own flux, radius, height and saddle level, so the builder's field, level and axis arguments are pinned. Replacing the builder's assembly call with an empty dictionary reddens it; the log is control-branches.log.

What was not produced

A free-boundary profile.solve on the manufactured machine is still not available: the iteration leaves the axis unqualified (NoQualifiedAxisError under the picard and anderson routes), so the converged state above comes from the operator's own raster map under a declared source law rather than from a solve of the machine's equilibrium.
