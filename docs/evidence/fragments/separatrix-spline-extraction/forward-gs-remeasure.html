What changed in the producer

Each frame's forward panel is drawn from a fine display flux map built by nova.equilibrium.display_flux.build_display_flux_map from the state's own conductor and plasma currents, at the 10 mm floor, rather than from the solve lattice's linear in-cell interpolation. The builder is handed the coupling the solve already owns: the uniform plasma Green block at the frame's own cell step, and the exact conductor response at the display points, contracted against the complete 24-conductor current. The operator's two moment entry points are mutually exclusive, so the producer asks for the moments the operator carries and passes them to the map rather than letting the map guess.

The conductor response depends on the coil geometry and the target points only, never on the frame, so it is built once for the fixed grid — the lattice bounding box at the 10 mm floor plus the lattice nodes — as an exact matrix product: each of ten worker processes evaluates the full column set for its own point block, with no coarse read and no spline anywhere. The matrix is written under the shared operand root, keyed by a digest of the coil source and the grid, and each frame contracts it with its own currents; the whole bank reused the stored matrix at digest c8075ff7c3885c0d, which is why the per-frame response build is 0 s. A stored matrix whose columns no longer match the operator's current vector is refused rather than reused. The worker processes are pinned to the CPU with the variable scoped around the spawn, because a spawned worker builds its JAX backend at import and an initializer runs too late to keep it off the card the solve holds.

The trace of the solve's telemetry map passes through ForwardFluxOperator.current_normalisation_amplitude, whose admissibility refusal used to test a flag that can reduce to a concrete value while an operand is still traced, and then call float() on that operand. The refusal is now decided from the operands themselves: a fully concrete inadmissible call raises CurrentNormalisationError, and a traced one returns the non-finite amplitude the solve already rejects. The earlier run of this bank died on frame 3 with ConcretizationTypeError and now records a verdict there like any other frame, which is the behaviour the guard was changed to reach. tests/test_current_normalisation_traced.py runs the function under jax.linearize on both inadmissible and admissible inputs and asserts the refusal; restoring the old flag test makes the inadmissible cases fail with ConcretizationTypeError.

Verdict

The gate is not passed, and the measurement says the same thing the August run said: 0 of 5 frames converge under the registered criterion, and the median interior R-squared of -0.651 is far below the registered bar of 0.90155. The re-measure does not reproduce the August digits and is not expected to — the solver build moved from 0.11.0.post2424 to 0.11.0.post10061 and the registered qualification tolerance from 1e-6 to 1e-5 — but the substance is unchanged: three of the four frames that produced a map ended on a limited or wrongly diverted topology, and the fourth reached a diverted topology 2.3 m from the labelled X-point. Nothing here is an interpolation artefact: every map that was built reproduces the operator's own raster image to at most 4.3e-14 relative error, five orders of magnitude inside the 1e-10 defect threshold. The one producer-independent defect found on the way is fixed where it lived: the current-normalisation refusal under tracing now raises from the concrete host check and returns a non-finite amplitude otherwise, so a frame records a verdict instead of aborting the bank.
