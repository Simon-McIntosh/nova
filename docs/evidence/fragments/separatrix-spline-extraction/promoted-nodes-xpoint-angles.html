The mechanism is the paste at nova/equilibrium/reduced_newton.py:985, mapped = jnp.where(promoted, state, image), inside _reduced_kernels.trip_boundary: on a closing trip the state carried into the next trip is the map, so at a promoted node the terminal state is the pre-paste state and image - state there is exactly the residual the shadow rule exists to hide. A node therefore reads near zero in that column for one of two different reasons, and the two are distinguishable only by the selection source and the operator's own column.

The worst near-zero group is the upper-half interior flood (private flux) nodes (24 of them), at 1.058e-09 Wb. The operator's own column reads 1.061e-09 Wb on the same nodes, so the state and the field of the currents genuinely agree there and the near-zero column is a true agreement rather than an artifact: the flood selected nodes whose residual is already at the solve floor, so the paste changes nothing at them. The reported upper-half column is nevertheless not uniformly zero: the 7 private-wall band nodes in the same half read up to 2.003e-03 Wb, and the operator's raster carries no wall coordinate to check them against. So the half's aggregate column is an artifact of averaging two selections in one figure, and the corrected column is this per-source split, not the half total.

Does the promotion move the geometry by an amount that matters?

The saddle moves 0.3545 mm, and the direction that changes most is the lobe at +0.01° — a fraction of the lobe's own width. A change of that size is well under one lattice cell. The rule a repair would change is the paste itself: the exclude-shadow branch of ForwardFluxOperator.residual_shadow_mask in nova/equilibrium/forward_operator.py decides which nodes keep their pre-paste state, and _reduced_kernels.trip_boundary in nova/equilibrium/reduced_newton.py is where that decision is applied. Narrowing it so a node is kept only where the residual the paste would hide is large enough to matter, rather than wherever the flood or the wall band reaches, would shrink the excluded set without changing the field it exists to protect. Nothing in this node's evidence says the change is needed; it says the mechanism by which a widened set would show up.
