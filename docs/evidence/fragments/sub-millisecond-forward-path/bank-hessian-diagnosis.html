A uniform rectangle with an independent Hessian

A uniform rectangular source spans R = 5.5–6.5 m and Z = −0.6–0.6 m with J = 200 kA/m². For a ring kernel K and source height b, translation invariance gives KZ = −Kb. Integrating over the rectangle gives ψZ = J ∫(Kbottom − Ktop) da. Differentiating this smooth boundary integral supplies ψRZ and ψZZ without a polygon antiderivative, its tangent rules, or an interior singular quadrature. Localisation to the unprotected contour tangent

The shared path is nova/biot/polygonanalytic.py:_packed_moments_height_tangent, whose definition starts at line 3098 in the measured source. It obtains the ordinary derivative with jax.jvp and replaces a height derivative only when a target is within 10−7 m of a source corner's height. That condition does not cover a target almost on an edge's extended line, far beyond the finite edge and far from either endpoint. The contour reduction's plane denominator is formed from that projected line offset in _Edge.__init__ and consumed by _Edge.terms.

This defect lives in the shared kernel called by both routes. The bank builder calls packed_analytic_moments from scripts/prototypes/read_route/jets.py:_source_jets (line 229; call at line 233). The direct route calls the same function from nova/equilibrium/topology.py:BiotMomentCoupling.value_gradient (line 2511; call at line 2514), and BiotMomentCoupling.evaluate (line 2534) differentiates it. The shared entry nova/biot/polygonanalytic.py:packed_analytic_moments (line 3141) selects the custom tangent whose defective function is _packed_moments_height_tangent at line 3098: ordinary jax.jvp at line 3110 remains selected when the corner-height test at line 3117 is false. The near-zero projected offset at _Edge.__init__ line 973 feeds the pole reduction in _Edge.terms line 1062. Those individual derivatives lose cancellation near projected edge lines despite a smooth physical field. Thus the two Hessian routes are not independent validators of this shared tangent.

Repair boundary

A product repair needs a well-conditioned tangent or combined analytic limit for the projected-edge degeneracy in both target coordinates, covering the uniform and linear moment channels. The present height-only fallback is insufficient. The repaired bank and direct point jets then need independent requalification on these retained states and near/far projected-line controls. This measurement changes no product source or qualification budget.
