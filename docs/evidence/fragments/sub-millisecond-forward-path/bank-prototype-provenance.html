One precision comparison, and provenance probes that read PYTHONPATH

The breakpoint report no longer carries its own copy of the precision budget comparison. scripts/prototypes/bank_solve_breakpoint/report.py imports pair_gaps from scripts/prototypes/bank_solve_cycle/report.py, which now owns the four paired keys and their denominators, both arms' oracle gaps, the first-lane oracle-boundary construction, and the limits 1e-8, 5e-4, 5e-4 and 1e-4. The owner's compare reduces the same per-lane gaps by their maximum, so both reports read one definition. Replayed on the existing breakpoint receipts, the report's PRECISION line is byte-identical to the recorded resumed/report.log and precision.json is unchanged.

Every provenance probe under scripts/prototypes/bank_*/ now runs its interpreter with -P, so the empty sys.path[0] entry that a -c invocation inserts no longer shadows PYTHONPATH with the working directory. Measured on this tree's base revision, git grep -n -- '-P -c' -- scripts/ counts 67 -P -c probe invocations across 60 shell files, 59 of them under scripts/prototypes/bank_*/ and the sixtieth scripts/prototypes/fused_newton/run.sh; no file in scripts/ outside scripts/prototypes/ carries one, and no Python source file carries the flag at all.
