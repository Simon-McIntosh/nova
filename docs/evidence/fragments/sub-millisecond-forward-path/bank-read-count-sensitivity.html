Hypothesis for a later product experiment

A fixed near-root polishing schedule could stabilize the common batch read count while keeping the final certificate unchanged. After all lanes enter a declared near-root band, test a fixed number of full-step fresh evaluations, retaining each lane's lowest valid residual state. Certify the selected state with the existing 1e-10 fresh-read limit; only an uncertified batch enters the adaptive fallback. The schedule makes cost insensitive to which side of the tolerance a tiny perturbation lands on, provided the fixed schedule certifies all lanes. It does not promise a fixed fallback cost or bit-identical terminal moments. The candidate must preserve the locked oracle precision budgets as well as the residual limit.

A residual-based acceptance margin is a narrower hypothesis for the search tail: permit a full trial inside a measured residual uncertainty band while leaving the final 1e-10 certificate strict. At the recorded lane-11 state, a margin exceeding 2.06484e-11 would accept the state that eight trials eventually select anyway. A margin sized at 1e-16 in residual units would not address this tail, and an acceptance margin alone would not remove the earlier tolerance split. These are hypotheses only: no product rule, tolerance or test is changed here.

The next experiment should use common saved seed arrays, deliberate perturbations at the measured 1e-14 relative moment scale and independent cold compilations. It should test both read-count stability and unchanged certification/answer budgets. The present measurement identifies the sensitive comparisons; it does not establish that either proposed rule succeeds.
