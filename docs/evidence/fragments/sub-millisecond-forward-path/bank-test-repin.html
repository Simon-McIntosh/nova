The restart width and the permutation the reference needs

test_block_gmres_cap_mid_cycle_leaves_unwritten_columns_out_of_the_update now reads the restart width from _block_gmres's own width = min(20, right.size) rather than restated: it parses the assignment from the function's source and fails loudly if the form changes, then caps the cycle at a quarter of that width. It also asserts that _apply_block_inverse of its matrix is an orthogonal permutation — entries in {0, 1} with every row and column summing to one — which is why the raw-matrix Arnoldi reference agrees with the preconditioned run.

Negative control. A scratch copy sets the matrix's [0, 0] entry to 4.0, so the first cell block inverts to 0.25 and the applied block inverse is not a permutation. The new assertion fails with array([0., 0.25, 1.]) against array([0., 1.]) and the test is reported failed; the log is negative-control.log in the run directory.
