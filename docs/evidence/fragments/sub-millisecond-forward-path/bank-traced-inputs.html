Traced coil currents, flux-function tables and centroid targets

The bank retains the fixed external field in exterior and each coil's unit-current response in coil_exterior, with shape (nodes, coils, six jet entries). Both are padded to the node bucket. A traced coil_count masks unused columns. The content store persists the responses and count alongside the existing bank arrays.

driven_operands contracts each lane's current vector into one effective exterior before entering the existing solver. The nodal contraction, stationary-point row window, Bell read, residual and Jacobian all use that same exterior. The row-window lookup scatters nodal jets into occupied cache slots; unpopulated slots cannot overwrite a live node. Calls without currents or a pin retain the existing batched solver path.

The 33 knots span normalized flux 0 to 1 uniformly. Cubic Hermite interpolation uses centred interior slopes and one-sided endpoint slopes; the endpoint value is held outside the knot interval. Interior-knot first derivatives are continuous. A difference-form polynomial reproduces a constant table exactly. The profile uses the existing SI toroidal-current-density convention. Its analytic normalized-flux derivative is selected by both booking tangent entry points and the bank Jacobian, including per-lane profile callbacks. Existing constant-gradient certificate profiles remain accepted.

The pin follows VerticalPositionPin: its source is the existing uniform radial-field jet, or the declared coil direction. Its dimensionless amplitude is converted by source_scale. Current-centroid height is sum(z_cell * I_cell + local_vertical_moment) / sum(I_cell), so cell-local moments are translated before summation. The height row is scaled by row_scale. An outer scalar Newton correction eliminates this row through the existing moment Jacobian and the analytic external-field booking tangent, including moving saddle geometry. Every corrected field is solved and read afresh before acceptance, with at most eight outer corrections. The receipt returns pin_amplitude and pin_error; an unsatisfied pin cannot report convergence. A changed pin field invalidates the carried factor.
