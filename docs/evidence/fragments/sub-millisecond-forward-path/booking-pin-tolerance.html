Booking pin: tolerance against a stored reference

Node booking-pin-tolerance · plan sub-millisecond-forward-path §3 · base b48deaa93f5

What changed

tests/test_bank_step_booking.py::test_book_primal_keeps_exact_diverted_moments pinned the SHA-256 digests of the six booked arrays for two CPU families. The digests were red at the base revision because the same case produces different bits on the same CPU, so the pin measured bit identity rather than the result.

The test now asserts each booked field against reference arrays stored in tests/data/booking_primal_diverted.npz (2,769 bytes, six fields), within 1e-12 relative. Fields with exact zeros and sign changes (cell_current, radial_moment, vertical_moment) use an absolute floor of 1e-15: those fields peak between 1e-3 and 1e-1, so the floor sits far above the roundoff a reordered sum leaves on a zero entry and far below any entry carrying a physical contribution. normalization and raw_current are scalars (1.0 and 1.5034747433199205), and valid is boolean and compared exactly. The digests survive only in the failure message, so a red run names the field that moved without pinning bits.

Reference provenance

The arrays were written from the diverted case on the CPU lane. The command recorded in the test docstring imports _booked_diverted, which exists from revision 936c1b95c10bc177a519d33fdc74916c07b8c912, and rerunning it at that revision reproduced all six fields: same dtype, same shape, same bytes each (ALL-FIELDS-BIT-IDENTICAL True).

Controls

Scale by 1 + 1e-15 (passes, as required). Scaling the stored radial_moment by 1 + 1e-15 in a scratch copy of the tests tree changes its digest from b109cedeb1d0… to 9e96577609f1…, so the bits moved, and the test passes: 1 passed, exit 0. The change is a thousandfold inside the 1e-12 tolerance, which is the size of the noise a reordered accumulation produces.

Scale by 1 + 1e-9 (fails, as required). The same perturbation at 1e-9 relative returns FAILED tests/test_bank_step_booking.py::test_book_primal_keeps_exact_diverted_moments, 1 failed, exit 1. The pair brackets the tolerance: 1e-15 is accepted, 1e-9 is refused.
