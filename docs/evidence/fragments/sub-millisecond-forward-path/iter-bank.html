Component budgets and source-cell corner samples

The decision of 2026-11-14 permits 1e−8 relative for plasma-containing Hessians, retaining 1e−10 for flux, gradients and every coil-only jet entry. Bank moment and direct-kernel mixed and vertical Hessians agree at about 2e−9 relative. The independent check bank-hessian-reference, run r-20261114T075414565081, could not resolve the stricter 1e−10 plasma budget. The decision attributes its large reference errors to sample nodes on source-cell corners, where ψZZ is discontinuous. These second derivatives guide null finding; they do not define the unchanged 1e−10 terminal residual budget. This qualification is mutual agreement with the direct kernels at the stated budgets, not an independently established 1e−10 Hessian oracle.

The qualification code expresses the budgets per jet entry. A guard test admits a 2e−9 plasma Hessian discrepancy, refuses the same discrepancy for coil-only jets, refuses a Hessian discrepancy above 1e−8, and refuses a flux discrepancy above 1e−10. The merged container convention remains: an absent coil response is None in memory, serializes as a zero-width response, and reads back as None.
