One rule for near-tied read candidates

topology.extremum_index selects the lowest canonical candidate index among scores within 1e-12 * abs(best) of the best. Minima use negated scores and the same rule. The margin exceeds the reproduced equivalent-seed roundoff, while preserving every leader separated by more than that margin. There is no absolute floor: a zero best ties only exactly. Candidate order is the canonical order of the fixed mesh, wall or null slots; a reordered array must carry those canonical indices. The returned value is the winning array position. JAX reductions implement the rule under both jit and vmap. NaNs are ignored; all-NaN inputs return -1. Equal masked infinities choose the first index, with admission still decided by each caller's existing validity mask.
