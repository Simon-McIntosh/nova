This certificate retains every terminal production-route solve. Three Cerfon-Freidberg single-null rungs satisfy the 1e-12 fixed-point-residual qualification; thirteen rows do not. Verdict and re-certification cost

Partial qualification: 3 of 16 rows. The three residual-qualified single-null rows reproduce the closed-form field at the stated terminal bound. The thirteen remaining rows are evidence of a production termination, not evidence of absolute accuracy. Regenerating all sixteen rows is a GPU measurement: the source receipt records H200 row walls alongside each row and must be run in one allocation with persisted per-row receipts; the default CPU test below only protects the published census from silent drift.

The prior NaN-era docs/figures/gs-absolute-accuracy/solovev-certificate.json is superseded by the named production-route receipt. It is retained only as historical non-finite diagnostic evidence and is not a certificate source.
