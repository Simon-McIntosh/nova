Coil-edit non-convergence under the vertical current-centre row

Why sixteen of twenty warm-started coil edits stop short of the tolerance when the vertical current-centre row is imposed, per edit, from the per-trip traces of a single titan job that ran the constrained sweep and its unconstrained control arm.

What was measured

One titan allocation (job 1275764) at revision 15b3aa2f8 ran the twenty-edit sweep of benchmarks/coil_edit_latency.py twice. The first pass imposed the vertical current-centre row through the machine interface the constrained route uses; the second was the same driver with --without-vertical-centroid, which keeps the row's pair out of the compiled solve and persists no centroid row, so both arms run identical code and differ only in whether the row is imposed. Host 98dci4-gpu-0002, partition titan (a P100 rung, off the shared reservation), no uv on the node, the root interpreter run directly with PYTHONPATH at the worktree, TMPDIR=/tmp in the submit environment and in the payload, persistent compilation cache reused. The figure and every artifact beside this page are the constrained arm's own outputs, copied byte-identical from that job's scratch directory.

Each edit takes the frozen MAST 22086 slice-43 mixed seed, multiplies the P4-upper (circuit 8) current by 1 + f for f stepping 2% from −18% to +20%, and solves the reduced Newton route warm-started from the preceding edit's terminal state. The solve settings are the sweep's: tolerance 1e-8, newton_steps=12, active_set_steps=16.

Sixteen edits did not converge and four did. Most non-converged edits report the same termination word, active_set_settled, so the word alone carries no diagnostic; edit 7 is the one exception and reports its budget exhausted after sixteen trips. What separates the rest is in the per-trip trace: how many Newton steps each trip accepted, how many it rejected, whether the trip's closing active-set read moved the mask, and the seed's own residual on the edited operator before the first trip. The seed probe is a zero-step solve (newton_steps=0, active_set_steps=1), and it is measured without the row so that the seed residual stays the same quantity every earlier sweep recorded.

The row moves the solved set, and the control arm says so. The unconstrained arm reproduces the banked readings exactly — 10 of 20 converged, 12 drawn closed, 14 axis-enclosing cycles — so the numbers below are the row's own effect and not a change on main. Convergence differs between the arms on ten states and the drawn-closed set on nine.

Grouping the non-converged sixteen

Almost all of the sixteen non-converged edits terminate with the same word, so the table groups them by the mechanism their traces support instead. The mechanism is decided by two facts only: whether any Newton step was accepted at all, and whether the closing active-set read ever moved the mask.

Stall — the closing read never moves the mask — edits 3, 5, 6, 9, 10, 11, 12, 14, 15, 16, 18, 19

Every member takes exactly one trip, and that trip's closing mask read reports a difference of 0, so the loop ends there: a trip that promotes nothing and does not reach the tolerance exits the trip loop. How much Newton work that one trip does varies widely — edits 14, 15, 18 and 19 spend the whole newton_steps=12 budget in accepted steps with no rejection, while edits 10 and 11 accept one step and reject one. Terminal residuals run from 1.463e-08 Wb (edit 18, the closest of the sixteen) to 6.226e-03 Wb (edit 6), against seeds of 2.585e-03 to 3.882e-02 Wb.

Most members' terminal residual is below their seed's, so most are a stop while descending rather than a failure to descend. But not all: edit 10 ends above its seed, 2.585e-03 to 3.002e-03 Wb, so the group is not uniformly a descent cut short and the claim that it is does not hold under the row.

The mask-stable seed is a consequence of the warm start: from edit 1 onward the seed is the previous edit's terminal state, whose active set is already stationary on the new operator. The one edit not warm-started from a predecessor (edit 0, seeded from the base frame at the shot current) shows mask motion in every trip (19, 19, 4, 0) and converges, which is the contrast that makes the group coherent.

Refused first step — no Newton step accepted — none under the row

The unconstrained arm produced two edits whose line search refused the first step, leaving the terminal residual bit-for-bit equal to the seed probe's own. Under the row the group is empty: no edit accepts zero Newton steps, and no edit's terminal residual equals its seed's exactly. The trace distinction that arm needed — on the host route an exhausted line search with no accepted step and a mask difference of 0 is reported as SUFFICIENT_DECREASE_REFUSED, where the compiled trip loop has no branch for it and its settled = difference == 0 test answers ACTIVE_SET_SETTLED for both — remains the right thing to look for; it simply has no member here.

Partial walk — several trips, mask still moving, cut short — edits 1, 4, 7, 8

These are the four whose closing active-set read does move the mask. Edit 1 takes two trips, mask differences 32 then 0, and descends 2.242e-02 → 4.943e-03. Edit 4 takes five trips, mask differences 51, 49, 49, 29, 0, and descends 1.160e-02 → 5.665e-03. Edit 8 takes four trips, 29, 29, 29, 0, and descends 6.009e-03 → 9.509e-05, the lowest residual of the sixteen. Edit 7 is the outlier of the whole sweep: sixteen trips, a mask difference that moves by 27 or 29 on almost every one, and it ends with its active-set iteration budget exhausted rather than on a mask-stable trip — and above its seed, 5.845e-03 to 6.514e-03 Wb. A walk that was working and was cut short is the reading for the first three; edit 7 is a walk still moving when its budget ran out.

What the traces rule out, and what they cannot say

  • No topology change. Every edit's achieved class is diverted with read_status: qualified, and so is every seed probe's class both before and after the first trip. The non-convergence is not a topology transition between the seed and the edited state.
  • The class margin is uninformative. class_margin is null on all twenty edits and on the seed probes, so the traces cannot say how close each state sits to leaving the diverted class. A margin would have made the near-miss hypothesis testable; it is not available here.
  • Off-support leakage is exactly 0.0 Wb and the reduced dimension is 642 on every non-converged edit, unchanged from the converged ones: the active set is not losing or gaining support discontinuously in a way the leakage counter sees.
  • The termination word is not the mechanism. The compiled trip loop's exit test is settled = difference == 0, which folds a refused-first-step exit (SUFFICIENT_DECREASE_REFUSED on the host route) and a mask-stable stop into one active_set_settled label. Any reading of the convergence rate from the termination word alone is reading the label, not the cause. Under the row exactly one edit carries a different word — edit 7, the sixteen-trip walk, which exits on active_set_iteration_budget_exhausted, and the other fifteen non-converged edits all read active_set_settled.
  • No solver code was changed. The forensics ride the existing result fields; the sweep, the route, and the tolerance are as the sweep ran them.
