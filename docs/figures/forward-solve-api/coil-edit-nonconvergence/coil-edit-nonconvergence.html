Coil-edit non-convergence forensics

Why ten of twenty warm-started coil edits stop short of the tolerance, per edit, from the per-edit traces of a single H200 re-run of the sweep.

What was measured

The twenty-edit sweep of benchmarks/coil_edit_latency.py was re-run once on one reserved H200 (98dci4-gpu-... "NVIDIA H200 NVL", partition betelgeuse, reservation gpu_0003_grpA, no uv on the node, the root interpreter with PYTHONPATH at the worktree, persistent compilation cache reused). Each edit takes the frozen MAST 22086 slice-43 mixed seed, multiplies the P4-upper (circuit 8) current by 1 + f for f stepping 2% from −18% to +20%, and solves the reduced Newton route warm-started from the preceding edit's terminal state. The solve settings are the sweep's: tolerance 1e-8, newton_steps=12, active_set_steps=16.

Ten edits converged and ten did not. Every non-converged edit reports the same termination word, active_set_settled, so the word alone carries no diagnostic. What separates them is in the per-trip trace: how many Newton steps each trip accepted, how many it rejected, whether the trip's closing active-set read moved the mask, and the seed's own residual on the edited operator before the first trip. The seed probe is a zero-step solve (newton_steps=0, active_set_steps=1), so it records the residual the warm seed carries on the edited operator.

Grouping the non-converged half

All ten non-converged edits terminate with the same word, so the table groups them by the mechanism their traces support instead. The mechanism is decided by two facts only: whether any Newton step was accepted at all, and whether the closing active-set read ever moved the mask.

Stall — one trip, full Newton budget spent, mask already stable — edits 1, 2, 4, 6, 8, 10

Each of these edits takes exactly one trip, and that trip consumes the whole newton_steps=12 budget in accepted steps with no rejection, while its closing mask read reports a mask difference of 0. The loop ends there: a trip that promotes nothing and does not reach the tolerance exits the trip loop.

The cost is that these seeds receive one trip's budget and no more. Twelve Newton steps move the residual a long way — edit 1 from 8.171e-03 to 2.374e-06, six orders — but not to 1e-8, so a solve that is still descending fast is reported as settled. The residuals of the group run from 1.506e-08 (edit 10) to 4.422e-03 (edit 6), against seeds of 2.869e-03 to 8.171e-03. Every member's terminal residual is below its seed's, so none is a failure to descend; all are a stop while descending.

The mask-stable seed is a consequence of the warm start: from edit 1 onward the seed is the previous edit's terminal state, whose active set is already stationary on the new operator. The one edit that is not warm-started from a predecessor (edit 0, seeded from the base frame at the shot current) shows mask motion in every trip (18, 34, 6, 0) and converges, which is the contrast that makes the group coherent.

Refused first step — no Newton step accepted — edits 17, 19

These two take one trip, accept zero Newton steps, reject one, see a mask difference of 0, and return the seed unchanged: the terminal residual is bit-for-bit the seed probe's residual (2.11060409400877 for edit 17, 2.92200350800961 for edit 19). The line search refused the first step, so nothing moved.

This is the case the termination word misnames. On the host route the solver separates a refused-step exit from a settled active set: an exhausted line search with no accepted step and a mask difference of 0 is reported as SUFFICIENT_DECREASE_REFUSED. The compiled trip loop has no branch for that case and its settled = difference == 0 test answers ACTIVE_SET_SETTLED for both. The trace, not the word, is what distinguishes them.

Partial walk — several trips, mask still moving, cut short — edits 16, 18

These are the two whose closing active-set read does move the mask. Edit 16 takes two trips with mask differences 32 then 0, one rejection per trip, and descends 1.278e-03 → 8.365e-04. Edit 18 takes three trips with mask differences 26, 22, 0, one rejection per trip, and descends 4.870e-03 → 2.311e-03 → 1.849e-03. Both end on a trip whose mask difference is 0 while the residual is still above tolerance: a genuine active-set iteration that was working and was cut short, not a stalled or refused one.

What the traces rule out, and what they cannot say

  • No topology change. Every edit's achieved class is diverted with read_status: qualified, and so is every seed probe's class both before and after the first trip. The non-convergence is not a topology transition between the seed and the edited state.
  • The class margin is uninformative. class_margin is null on all twenty edits and on the seed probes, so the traces cannot say how close each state sits to leaving the diverted class. A margin would have made the near-miss hypothesis testable; it is not available here.
  • Off-support leakage is exactly 0.0 Wb and the reduced dimension is 642 on every non-converged edit, unchanged from the converged ones: the active set is not losing or gaining support discontinuously in a way the leakage counter sees.
  • The termination word is not the mechanism. The compiled trip loop's exit test is settled = difference == 0, which folds a refused-first-step exit (SUFFICIENT_DECREASE_REFUSED on the host route) and a mask-stable stop into one active_set_settled label. Any reading of the convergence rate from the termination word alone is reading the label, not the cause.
  • No solver code was changed. The forensics ride the existing result fields; the sweep, the route, and the tolerance are as the sweep ran them.
