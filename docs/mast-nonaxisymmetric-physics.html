§1 — Outcome

Nova provides the production MAST model for non-axisymmetric drive fields, passive structures and circuits. It represents correction/RMP/ELM coils and leads, era-keyed sensor geometry, circuit semantics, passive screening and vacuum taring. Plasma response remains outside this first scope; exposed plasma-on channels carry flags and uncertainty inflation.

§2 — Research-first build

  1. Produce a geometry and circuit provenance research document covering engineering drawings, literature, IMAS availability, channel eras and uncertainty.
  2. Land versioned MAST 3D geometry and drive semantics using Nova's native 3D kernels and machine-description identities.
  3. Model open/shorted/era-dependent coil boundary conditions and passive screening with identifiable vacuum-shot gates.
  4. Expose vacuum taring through Nova's standard-name IO and machine API, then rewire Ambix to consume it.

§3 — Evidence gates

Evidence must include source provenance, per-era channel ledgers, vacuum/off-on contrasts, coil and passive Green-function cross-checks, held-out ramp residuals, uncertainty calibration, CPU/JAX parity and commit/environment identities. Negative results and unresolved plasma-response contamination are recorded explicitly.

§ Decisions

Which repository owns the production 3D/passive physics?

The user-directed architecture places all physics-spine capabilities in Nova and keeps Ambix as a consumer.

Work decomposition
1. Evidence manifest: source installed active/passive/TF topology and diagnostic construction from MAST-specific public or catalog evidence. Reject MAST-U-only dimensions unless an unchanged component is explicitly documented.
2. Nominal model: build component-family resistivity priors, positive resistance/inductance matrices, documented circuit signs and a bounded nominal TF path. Mark all inferred quantities generated with uncertainty.
3. Vacuum cohort: select no-plasma, single-coil and mixed-excitation shots; pin acquisition/calibration chains and exclude plasma-contaminated windows.
4. Passive refinement: fit identifiable grouped R/L parameters, not one free value per mesh element. Require passivity, positive dissipation, stable cross-shot values and improvement on held-out transients.
5. Diagnostic adjudication: solve toroidal-probe orientation, 150/330 bank assignment and saddle traversal sign as constrained continuous/binary inference. Leave ambiguous items unresolved when evidence is not decisive.
6. TF fidelity: validate the axisymmetric average against R*Bphi, then validate ripple/error-field structure separately. Do not absorb plasma response into a vacuum geometry correction.
7. Productization: expose a versioned Nova API and artifact with uncertainty, write focused synthetic and corpus-backed tests, and compare against the retained Ambix 3-D path before any donor retirement.

Done when
- The nominal model runs before calibration and every seed carries evidence and an uncertainty interval.
- Held-out vacuum residuals improve for each promoted parameter block; ablations show that passive, diagnostic and TF blocks are identifiable rather than compensating for each other.
- The resistance/inductance system is passive and numerically stable across supported shot ranges.
- Discrete orientations, banks and signs are promoted only with decisive held-out evidence; ambiguity remains explicit otherwise.
- Nova matches or improves the retained Ambix 3-D vacuum-field and subtraction evidence at recorded tolerances.
- Axisymmetric work was never held behind this plan; only 3-D donors are candidates for retirement after native parity.
