§1 — Current state

Nova 2.0 has the domain package structure and most generic physics components: equilibrium forward/inverse/moment/harmonic models, passive and screening circuits, JAX current diffusion, coupling generation, machine abstractions, standard-name IO and IMAS-facing infrastructure. The main refactor is approximately 90% complete and physics adoption approximately 60% complete.

§3 — Ownership and launch recommendation

Nova owns all production physics and IMAS mechanics; Ambix consumes Nova for labeling and ML. Finish refactor convergence first. Then run Wave 3 reconstruction/transport and MAST machine-description work in parallel. Run MAST non-axisymmetric/passive completion after the 3D substrate. Only after those gates pass should the H200 catalog solve and Ambix consumer cutover run.
