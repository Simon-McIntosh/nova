§2 — The three defects the parity work found

None of these was the hygiene the plan set out to do. Each was found by writing a test that drove two implementations of one thing and compared them.

  • A silently absent Force index. The numpy operator took the index from its caller; the jitted one read an index variable off the dataset and, on KeyError, passed — leaving a Force operator with no index. Indexing with a missing index inserts an axis rather than selecting a gain, so the interaction came back a plausible shape and a wrong value. Both now take the caller's index and raise on absence. (e4ec7a0c)
  • An empty profile ladder that raised on one arm. The traced ladder returned a well-formed (n, 0) basis at zero terms; the host arm tried to column-stack nothing and raised. A channel carrying no free coefficients is a valid request. (b31e198d)
  • A missing degenerate-fit guard. The biquadratic stationary point divides by the Hessian determinant, which a planar cluster drives to zero. One copy floored it and the other did not, so the same degenerate cluster returned a finite coordinate through one path and ±inf through the other — and an inf rides a vmapped batch into every gradient that touches it. (ed33cf3a)

The same commit removed a -11 sentinel from null_type's default branch. That branch is unreachable: selecting it needs 4AB − E² > atol > 0, which forces AB > 0, so A and B share a sign and an earlier condition has already fired. Its only reader was a checker nothing called, which also tested for a −10 the function never returns.

§3 — One listed deletion was refused

nova/jax/fieldnull.py was listed for deletion as a "class-for-class copy of nova/biot/fieldnull.py". That premise was wrong. biot defines DataNull/FieldNull (numpy, njit, PointLoop); the jax file defines a different FieldNull whose stencil property builds the hexagonal neighbour patch and flattens it with ravel_multi_index — a construction that existed nowhere else in the package. It has zero live importers, so it reads as dead; but boundary-push-port-audit names it as the original the boundary accelerator would generalise instead of building.

Resolved on owner direction: the construction moved OUT of the jax directory to nova/geometry/hexstencil.py, is now tested in its own right, and both former copies read it. The research doc's citation was repointed at the new home.

The owner also corrected the geometry as stated. The stencil is a six-point hexagonal ring; the array is seven columns wide because the centre cell is prepended to it. The code says so in both other homes — biot/fieldnull.py comments use 6-point stencil over exactly those six offsets, and PlasmaGrid.tessellate keeps exactly-six-neighbour vertices before prepending the centre column. "Seven-point" was the packed array width, not the stencil.

§4 — The greens retirement was gated, measured, and refused

Item 4 proposed retiring four legacy scipy host kernels whose xp-threaded twins already run under numpy, gated on a cost/accuracy check at the call sites. Measured (benchmarks/greens_elliptic_route.py), the hosts stay.

The decisive finding is semantic, not performance. Off the filament the two routes agree to round-off — 2e-15 of the regime's own scale for the point form, 2e-12 for the four-corner section rule, over targets from a nanometre off the filament to the far side of the machine. They part in exactly one place, and it is not a tie: on the filament the host returns the divergence inf, while the Bulirsch descent returns the first kind's finite part, which arrives as a small negative flux. An infinity is testable; a plausible-looking negative number is the one wrong answer a caller cannot detect.

Cost confirms it. The descent is what makes a twin differentiable — fixed trip count, no data-dependent branch — and for the first two kinds it runs 6–50× the Cephes pair per element, putting the filament twin at 1.9–3.9× the host over 64–65536 targets. Only those two kinds are a choice: scipy carries no complete third kind, so the corner antiderivative already takes all three from the descent on both routes, and its twin costs only 1.2–1.6×.

A third finding bounds both routes. Neither rescues the small-k² bracket: K − E is a difference of two numbers both near π/2 whose value is of order k², so both stand at 1e-3 of the field scale by k² ~ 1e-9. That is the arrangement, not the special function — the fix would be to split the pole off the bracket, and it applies wherever either route is used.

§7 — What this leaves

Two items were deliberately not taken, both recorded rather than silently dropped:

  • The wall_flux convention split. The serial path returns a 3-tuple with (0, 0, 0) at zero polarity; the traced path returns a 4-element array with all-NaN. NaN is the safer convention — (0, 0, 0) is a well-formed coordinate and flux a caller cannot distinguish from a real result — but adopting it changes what Limiter.update_wall publishes at zero plasma current. Two callers; documented on both sides pending a validated change.
  • The organising fault behind the misfiling. nova/jax/ is the package's only technology-organised directory and holds a subset of the traced code rather than the whole of it, which is what let two numpy modules drift in. That is now nova-jax-dissolution, with the single-file and traced-default decisions already locked.
