§1 — The substrate is verified; the problem is now an optimisation

Kirk (arXiv:1312.6507) names coil positioning as MAST's dominant intrinsic error-field source and records that the copper inside the P4/P5 cases was never surveyed. The misfit programme localised a surviving vacuum residual beside the P4 coils. Between those two facts sits an inverse problem: solve for the coil geometry the vacuum measurements actually imply.

The substrate check ran on 2026-08-07 (~/.cache/nova-mast/misfit-localization/autograd_check.py). The biot operators were written JAX-compliant for accelerator throughput, and that same property now delivers derivatives: the traced polygon quadrature kernel (tiledassembly._traced_psi_gradient, statically unrolled, branch-free) reproduces the reference numpy kernel to 8×10⁻¹² and returns exact geometry Jacobians — jax.jacfwd of (ψ, B_R, B_Z) with respect to rigid section shifts and individual polygon vertices agrees with central finite differences at the FD truncation floor (~10⁻⁶), second derivatives are finite (Gauss–Newton and Newton both available), and jacrev agrees with jacfwd to 10⁻¹². Two conditions attach, and they are §2.1's work: the vertices → (edge, weight, norm) pack must run inside the trace (the numpy pack_section needs a traceable twin — a 15-line transcription matched to machine precision once the orientation convention was honoured: the counter-clockwise edge sum yields −f(φ), so the kernel's sign is minus the shoelace sign), and only the polygon quadrature path is verified — the other kernel classes need the same treatment. For the record: the ambix gs/polygon.py kernel is an independent numpy implementation using complex-step derivatives (exact, but target-side only and not traceable); nova's dual-namespace stack is the substrate here.

§2 — Implementation

  1. Kernel differentiability audit and refactor. Inventory every biot kernel class — polygon quadrature (verified), closed-form polygon (polygonanalytic.packed_analytic_greens), ring filament (greens.py), arc filament (arcbandedcoupling), line elements — and bring each to the traced dual-namespace pattern with geometry as trace inputs: xp namespace, static shapes, no value branching, plus a traceable pack_section twin (fixed topology; the horizontal-edge zero-weight mask computed as a static mask outside the trace). Each kernel gains an autograd regression test in the style of the banked check: value parity with the numpy reference, jacfwd against central differences, jacrev-jacfwd consistency. This stage is useful far beyond this plan — it makes every nova coupling operator differentiable end-to-end.
  2. Geometry parametrisation. Per-coil parameter blocks at increasing freedom: rigid (ΔR, ΔZ), scale, tilt/shear, per-vertex freedom for the pack outline, and the discrete chamfer-side state for the 23-turn lattice (branch comparison, not a continuous parameter). Priors and bounds from metrology where it exists (Kirk Table 1 offsets; the description's own 17.3 mm / 3% P4 asymmetry as a hypothesis, not a constraint).
  3. Problem class A — sensor-space (the MAST case). Recorded currents fixed; minimise the weighted misfit between measured vacuum couplings and modelled couplings over geometry parameters, per coil and jointly. The banked signed couplings (couplings.npz, 41 rows) are the immediate targets; calibrated flux loops join when mast-flux-loop-calibration lands. Identifiability first: the geometry-Jacobian singular spectrum at the real sensor set decides how many geometry modes the array resolves (the current-space answer was rank 10 of 13 — the geometry-space answer bounds what any fit may claim), and regularisation follows from it.
  4. Problem class B — flux-map-space. Given fixed coil currents and a target flux map with the plasma contribution subtracted (an equilibrium-reconstruction by-product, or the toroidal-harmonic misfit maps), solve the coil set's geometry to match the map on its grid. Same machinery, different data functional — this is the form any machine with a trusted reconstruction can consume without raw sensor access.
  5. Validation ladder, then MAST. Synthetic recovery throughout: perturb a known geometry, generate exact data (with realistic noise from the measured floors), recover, report bias and resolution limits per parameter class. Then the MAST application: P4/P5 members first (seeded from Kirk's offsets), scored against the surviving-misfit patterns, cross-checked against the provenance plan's linear symmetry scan (which this generalises), with the verdict — geometry correction found and quantified, or bounded as unresolvable at this array — recorded in a research note and, if found, delivered as a machine-description correction through the established registry route.

Done-when: kernel family audited and refactored with autograd regression tests green; identifiability spectrum for MAST geometry modes published; synthetic recovery ladder banked; MAST P4/P5 solve completed on both problem classes with confidence bounds; verdict recorded and any geometry correction handed to the registry.
