§1 — Purpose, and the measurement that warrants it

Nova's free-boundary Grad–Shafranov fixed point has a root-selection problem, not a convergence problem. Given prescribed coil currents and extracted flux functions, Newton converges briskly — and converges to the vacuum root, where the plasma current is zero. Damped and relaxed Picard-class routes hold the plasma branch instead but orbit it without ever entering a convergence region. Two machines and two independent reference sources produced that same split, so it is a property of the map rather than of any one dataset.

This plan makes prescribed total plasma current a constraint of the solve. Because jφ = −2π(R·p′ + FF′/μ₀R) is jointly linear in (p′, FF′), a common amplitude λ scales Ip exactly, so the constraint solves in closed form:

λ = Iptarget / ∫ jφunscaled(ψ) dA

Applied inside the map, this does not penalise the vacuum root — it removes it from the map's range, because a zero-plasma-current state would require infinite λ. Newton is then left with only plasma roots to find. The system stays square, GMRES is unchanged, no weight is introduced, and the constraint holds exactly at every iterate rather than asymptotically.

A prototype has already measured this and it works. On a representative ~1 MA DIII-D frame, from the same seed and the same 24-conductor input:

Prescribed Ip is an admissible input, not a label-derived crutch. It is in the competition input set and can alternatively be supplied by a partner transport solve, so it is the same class of declared input as the conductor currents. A route depending on it is admissible end to end rather than only as an illustration.

§2 — The one negative result, and what it forecloses

The prototype's second measurement is a genuine negative and must not be lost in the first one's shadow. Pinning reduced the Picard spectral radius from 1.2577 to 1.1456 — an 8.9 % improvement, still above one. The map is not made contractive.

Consequence: the damped and relaxed fixed-point routes that were observed to orbit are not rehabilitated by this constraint, and this plan must not claim they are. The constrained solve is a Newton route. Any downstream work that hopes to recover a cheap Picard iteration from current pinning is proceeding on a refuted premise.

Why that is consistent rather than contradictory, and worth stating because it was misread once already: Newton converged in four iterations on a map with ρ = 1.1456. A spectral radius above one defeats Picard and leaves Newton well posed — the Newton residual Jacobian is (I − M′) with eigenvalue 1 − ρ ≈ −0.15 to −0.26 here, far from singular. An unstable equilibrium is still a regular root. No vertical-position constraint belongs in this design; that caveat was raised against the prototype and withdrawn on exactly this reasoning.

§4 — Promote the constrained map from benchmark to the solver seam

The prototype deliberately lives in benchmarks/ with nova/equilibrium/ read-only, because peer sessions were active in that tree. That was right for a prototype and is wrong for a capability: a constrained map that only exists in a benchmark cannot be driven by efit-forward-parity, by the DIII-D onboarding, or by any batched production route.

The promotion is small in surface and large in reach. The amplitude elimination is one multiplication inside the map plus a guard; the Ip functional it needs already exists as an exact clipped-support integral. What must be authored carefully is the contract: which caller supplies the target, what happens when it is absent, and how the receipt reports λ so a reader can see how far the prescribed amplitude moved the extracted profiles.

Done-when: the constrained map is reachable through the public forward seam with a target-current argument, an absent target reproduces today's unconstrained behaviour bit-for-bit, the λ guard fails loudly rather than dividing, and the prototype benchmark is rewired to drive the seam rather than its own copy — with its landed numbers reproduced.

§5 — Cross-machine validation

The prototype measured DIII-D. The dichotomy it addresses was mapped in most detail on a MAST EFIT reference by efit-forward-parity, whose eight-route survey found newton_krylov and Anderson converging on the vacuum root at 0 A while five damped hybrids and a kink-aware nonmonotone route retained the plasma basin at 1.009–1.165× reference current without closing. That reference is the natural second test, and it is a sharper one: its external field reads diverted-class, so a topology pin cannot discriminate the vacuum root from the plasma root there at all.

That last point is this plan's clearest justification. Where topology pinning is degenerate, a current constraint is not — the two roots differ by ~934 kA whatever their topology class.

Done-when: the constrained solve runs on the MAST parity reference and reports whether it reaches the plasma root where the unconstrained routes did not, with the same two metrics as §3 and the label-parity figures that plan already scores.

§6 — Boundaries: what this plan does not own

Stated explicitly because an adjacent plan is building an adjacent mechanism and duplication here would be expensive.

  • dual-basin-solve owns topology pinning, hysteresis branch selection, the continuation ladder and warm-start economy. This plan owns one different mechanism: constraining total current by amplitude elimination. They are complementary — current pinning selects which root, topology pinning prevents in-solve class switching, and the MAST finding shows the second cannot substitute for the first. Coordinate; do not reimplement.
  • Basin entry by homotopy or continuation is not this plan's mechanism. If the constrained map turns out to need a continuation ladder as well, that ladder belongs to dual-basin-solve and is consumed here.
  • Vertical-position control is out of scope and is not merely deferred — it was considered and refused on the §2 reasoning.
  • The explicit augmented-row formulation is not the recommended design. It was prototyped as a comparison and dropped when it alone required a public clipped-support primitive the forward operator does not expose. If it is ever revived, the weighting is stated in the decision below so the design question does not have to be re-derived.

§7 — The missing solenoid half, and the inclusion ladder

The competition dataset ships ECOILA and no channel for ECOILB. Those are the two halves of the same central solenoid, 48 turns each. At the measured scale of 1.0172, the missing half carries 48.83 ampere-turn units against the present half's 48.0 — so the released data supplies roughly 49 % of the actual CS drive and presents it as the whole thing. ECOILB is 65.4 % of all missing ampere-turns; the E567 and E89 pairs, at 6 and 7 turns, are 16.0 % and 18.7 % between them.

This section measures the forward solve as those conductors are added incrementally, every added current derived from the shipped ECOILA channel times its measured per-coil scale — so no rung consumes a label-recovered value and the whole ladder is inference-admissible. The diagnostic question is whether the X point migrates monotonically toward the labelled divertor leg as ampere-turns are restored. A conductor set that spans the deficit should improve monotonically and its metrics should agree; one that does not, does not.

First-frame result, held at n=1: ECOILB alone cuts the X-point error 65 %, from 0.4531 m to 0.1574 m — and then the E567 pair pushes it straight back to 0.4520 m. The metrics also disagree about which rung is best: fractional RMS is worst at the ECOILB rung (0.7011, above the shipped-only 0.4162) and best two rungs later (0.1639). Either the per-coil scales do not transfer from the netCDF pulse they were measured on, or the five conductors do not span the missing field.

Done-when: the preregistered five-frame ladder scores complete with the zero-current Armijo policy now locked, and the receipt states whether the non-monotonicity pools across frames or was a property of the first one. The single-frame result is not generalised until then — this campaign has already been misled once by a single unrepresentative frame.

§ Decisions

Is the current constraint imposed by closed-form amplitude elimination or by an explicit augmented residual row?

Elimination keeps the system square so GMRES is unchanged, enforces the constraint exactly at every map evaluation rather than asymptotically, and introduces no weight to tune. The augmented row additionally required a public clipped-support observation primitive the forward operator does not expose, which is why the prototype's augmented arm was dropped — the arm needing new surface was the arm not recommended. Recorded for completeness in case the row is ever revived: both blocks must be non-dimensionalised by their own scale, the flux block in the exact clipped-cell area-weighted discrete L2 norm divided by the flux span and the current row as the relative current error, since a raw pointwise l2 grows as the square root of node count and is therefore grid-dependent while a current integral is not.

When a line search visits a state whose unscaled plasma current is zero or sign-reversed, does the solve fail loudly, clip to the band edge, or reject the step and continue?

Locked 2026-08-21 because two nodes have now stalled on it and a worker correctly refused to guess. A line search LEGITIMATELY probes inadmissible states - that is what a trial step is - so aborting the whole solve because a trial point has zero or sign-reversed unscaled current is the wrong failure boundary. Reject the trial, shrink the step, continue. The guard keeps its full meaning where it matters: an ACCEPTED iterate outside the finite positive band still raises LambdaOutOfBand loudly, and a converged state that required a rejected-forever direction fails rather than returning something that does not satisfy the constraint. Clipping to a band edge stays refused as originally recorded - it would silently return a state violating the constraint. Sign reversal likewise stays refused, since a negative common amplitude reverses both the pressure gradient and FF-prime and is a different physical source rather than a current normalisation. Implementation note carried from the two stalls: the division must not be reached before the admissibility test, which is the ordering defect itself.

Which target current does a production solve consume, and what does it do when none is supplied?

Open. The optional form preserves every existing caller unchanged and is the lower-risk promotion, but it makes the constrained route opt-in and therefore easy to forget where it matters most. The explicit form forces every caller to state its provenance — dataset channel, partner transport solve, or none — which is the more honest contract and the more disruptive one.
