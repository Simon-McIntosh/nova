§1 — The finding and the owner's strategy

The free-boundary map has multiple genuine roots. On the closed-form oracle fixtures the same external field supports two machine-precision fixed points (residuals 2.5e-15 and 2.2e-15, axis separation ~74.8 mm), h-independent — measured by the recovery re-baseline (commit 0bed363d). Corrected by measurement 2026-08-21 (commit 46c55d1d): both banked roots are limited — the closed-form read binds the outboard wall, the alternate root the inboard wall, with exact wall-contact equality in all four production reads, and the analytic formula has no stationary saddle for R>0 (its only mathematical saddle sits at the excluded coordinate axis). The bank proves two fixed points, not two topology classes; the genuinely diverted in-domain X-point fixture is constructed and banked under this plan. Production's cold current-centroid seed converges to the alternate root; source-strength continuation collapses to the vacuum branch at intermediate amplitudes. Accuracy is settled — the recovery gates hold each root to round-off — but which root a cold solve reaches is unmanaged.

Owner strategy 2026-08-21 (the imas-efit precedent): where both basins exist, solve both — a diverted solve and a limited solve side by side — and make the selection afterwards, from history (hysteresis). The GPU route makes the second solve nearly free: the batched fixed point already amortizes to 30 ms/state at batch sixteen, so a two-branch portfolio rides the same batch. Solving each branch with its topology pinned also removes the failure mode where a solve switches topology class mid-iteration and crashes convergence — the branch never has to decide its own topology, only converge within it.
