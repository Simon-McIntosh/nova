§1 — Public capability and name

The public solver is ForwardProfile. Nova's locked class matrix is ProblemRepresentation: ForwardProfile maps prescribed sources and flux-function profiles to equilibrium flux; ReconstructProfile maps measurements to a fitted profile state; InverseDesign maps shape targets to conductor currents. This problem is exactly the first cell. Introducing Constrained, Known, Direct or another solver family would weaken that matrix and create two names for one capability.

ForwardFluxOperator remains the differentiable trial-flux map used by fixed-point methods. It is an implementation-level operator, not a second public equilibrium problem. ForwardProfile.solve becomes the clear eager/JAX façade returning a typed equilibrium result and conservation ledger.

§2 — Mathematical contract

Inputs are machine geometry, external conductor currents, an initial flux state or seed policy, boundary targets, COCOS/total-flux convention and one immutable flux-function state. For the static closure the state supplies pressure and F=R B_phi with derivatives consistent with those primitives. Nova evaluates the toroidal-current source on the topology-defined domain and finds the fixed point of external plus plasma-generated flux.

The solve has no magnetic measurements, no whitening matrix, no priors and no least-squares coefficient update. A caller that needs reconstruction first uses ReconstructProfile or, in the Ambix workflow, supplies the posterior source state produced upstream.

An absolute source state predicts I_p, beta_p and l_i. A target I_p may instead close one explicitly declared common source amplitude; this is a scalar equality in the nonlinear solve, not profile fitting. Enforcing additional moments requires additional physically named profile degrees of freedom and a prior. That conditioning belongs in Ambix or ReconstructProfile; ForwardProfile exposes the differentiable moment map without choosing a correction.

Each optional physics term is a typed force-balance closure with its own required functions and manufactured solution. The first extension is toroidal rotation with isothermal flux surfaces. The second is a static SOL extension of pressure and toroidal-field-function gradients across the separatrix on topology-qualified common-SOL and private-flux masks. Arbitrary cell-current images may be used only as field-response diagnostics; they do not qualify as a force-balanced equilibrium source.

§5 — Sequencing and exclusions

The source/result types and analytic fixtures can land while the boundary accelerator finishes. Closing the plan requires the accelerated topology read and the Ambix interface contract. This plan does not fit profile coefficients, train a closure model, infer a state from diagnostics, design coil currents, model non-axisymmetric fields, or claim a sheath/neutral/halo-current closure.

The first useful integration is a one-slice static absolute-source solve, followed by batched static ensemble members, rotation, and then topology-qualified SOL continuation. The SOL continuation is an optional, strictly additive extension: the bulk plasma solve's correctness always takes priority, and an undeclared continuation leaves the static path byte-identical. The physical motivation for extending the flux-function parametrization beyond psi_N = 1 is that real SOL current — mixed poloidal/toroidal, connecting between the divertor plates — must itself satisfy force balance and hence the GS constraint, exactly as the confined plasma does. Field-aligned SOL current is deferred until the material-boundary return path and sheath closure are physically specified.

The solved flux map has a second consumer beyond the Ambix seam. The flux-surface-averaged geometry record assembled from it — V′, the ⟨1/R²⟩ and diffusion-coefficient metrics, F and q on the toroidal-flux coordinate — is the geometry input of the transport forward solve (flux-function-forward-transport), and the transport-evolved p′ and FF′ return through the same typed flux-function state as a first-class source for this solve. The geometry record is therefore a public output contract of ForwardProfile, convention-pinned exactly like the field itself and supplied at both interval endpoints so the transport moving-grid term is correct.

§ Decisions

Should the first public solve accept only absolute source functions, or also one common-amplitude target- I_p closure? Recommendation: ship absolute-only first, but design the typed scalar closure now and add it only for a concrete shape-family consumer.

The first public path must preserve supplied physical sources exactly; a typed one-amplitude target-current closure can be added later for a concrete shape-family consumer.

How should target beta_p and l_i affect a prescribed-profile solve? Recommendation: ForwardProfile reports their residuals and Jacobian; if they must reshape profiles, Ambix conditions its ensemble or calls ReconstructProfile .

ForwardProfile reports plasma current, beta_p and l_i residuals and Jacobians without modifying profiles; any profile reshaping remains Ambix conditioning or ReconstructProfile work.

Which toroidal-rotation thermodynamic closure is the first supported physical model? Recommendation: isothermal flux surfaces, benchmarked against analytic rotating equilibria; add polytropic support later.

The isothermal-surface model has a complete typed thermodynamic closure and analytic rotating-equilibrium benchmarks, making it the smallest verifiable first implementation.

How is the private-flux region treated in the first SOL implementation? Recommendation: an independently specified low-pressure continuation with at least value and first-derivative continuity at the separatrix, never an unexamined copy of the common SOL.

Private flux has different material connectivity and receives an independent low-pressure continuation with explicit separatrix continuity rather than copying the common SOL.

Is field-aligned/poloidal SOL current part of this plan? Recommendation: defer it to a boundary-current plan unless a material return-current and sheath/halo closure is supplied.

Field-aligned or poloidal SOL current cannot conserve the full circuit until material return paths and sheath or halo boundary conditions are specified.
