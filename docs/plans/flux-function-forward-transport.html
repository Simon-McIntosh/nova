§1 — Authority and capability

ForwardTransport joins ForwardProfile as Nova's second deterministic physics forward. Given a flux-surface-averaged geometry record, an initial 1D profile state, boundary and actuator waveforms, and a declared source and transport-model selection, it advances the flux-surface state over an interval and reports conservation receipts — the flux-consumption ledger, the plasma-current ledger, and the achieved boundary conditions. It takes no measurements, contains no least-squares update, and never rescales its inputs silently. Fidelity is an explicit model selection carried in the result provenance, not an approximation the consumer must reverse-engineer.

The authority split with Ambix is unchanged from the flux-function seam: Ambix owns inference, closure corrections, uncertainty and causal provenance; it conditions the state that enters this solve and consumes the state that leaves it. Nova owns the deterministic evolution operator, exactly as it owns the free-boundary fixed point. The evolved p′ and FF′ hand back through the same typed FluxFunctionState contract that feeds ForwardProfile — transport is a producer at that seam, not a private pipeline.

§2 — Fidelity ladder

Transport fidelity is a ladder of declared rungs behind one public contract. Each rung is a physics forward with identical input and receipt types; selecting a rung changes the physics carried, never the seam.

The native rung stays permanently: it is the dependency-free, fully differentiable floor, already verified to <1% RMS against TORAX itself on shared geometry, and it is the correct vehicle where a learned or fitted closure is the object of study. The embedded rungs buy the verified physics surface Nova will not reimplement — coupled heat and particle transport, neoclassical closures, the source catalogue, adaptive nonlinear stepping, pedestal and sawtooth models. Evidence and the full capability-gap inventory: transport-forward-contract.

The coupled rung's contract unit is the window, and its exchange is a waveform. Equilibrium and transport advance at different native rates, so the coupled solve works on a declared time window with each side consuming the other's trajectory: transport integrates against the interpolated geometry waveform, the equilibrium solves at its coarse sample times against the interpolated source waveform, and the exchange iterates to a fixed point (waveform relaxation). Conventional staggered co-simulation is this contract truncated at one iteration, so both schemes are points on one measured axis rather than competing designs. A window carries four declared knobs — window length, per-side sample grids, iteration cap and convergence tolerance — and returns convergence receipts: iterations used, a contraction estimate, exit residual per exchanged field, and any damping applied. Window length is a policy the receipts justify — short where shaping evolves quickly, long in flat-top — with the contraction estimate as the adaptive signal. A window that cannot converge raises; it never returns a silently degraded state.

Innovation purity is the principle that assigns the fixed point to Nova. The assimilation layer upstream learns from model–measurement innovation, and an unconverged seam would confound that signal with numerical splitting error — teaching corrections to compensate the solver rather than the plasma. Nova therefore converges the window to its declared tolerance and surrenders the convergence behaviour as typed receipts, which the consumer classifies beside the innovation: slow contraction is itself physics. Gradients cross the window implicitly — a converged fixed point differentiates by the implicit-function adjoint without unrolling the iteration, so learned closures train through the coupled solve exactly when it converges. The window machinery is public at two granularities: the converged solve_window with receipts and implicit gradients is the default, and the single-sweep equilibrium/transport waveform primitives remain public pure functions for declared compositions that own their own convergence receipts.

§3 — Implementation work

  1. Dependency gate. Resolve the TORAX ≥1.3 imas-python==2.1.0 / h5py<3.15 pins against the imas-python ≥2.2 stack, per the locked pin-resolution decision. Nothing else in this plan starts until the environment resolves with TORAX ≥1.4.3, because the geometry-override API, Redl bootstrap and the Newton-solver gradient fix all postdate 1.1.1.
  2. FSA record completion. Extend the traced flux-surface assembly with the surface averages the geometry adapter needs — ∮dl/B_p, ⟨|∇ψ|⟩, ⟨|∇ψ|²⟩, ⟨1/B²⟩ — plus per-surface R_in, R_out, elongation and triangularity, all through the same contour-free coarea kernel, fixed-shape and jit/vmap-safe.
  3. Geometry adapter. Build the Nova FSA record → TORAX geometry handoff on the route the geometry-handoff decision selects, holding geometry at both t and t+Δt so the moving-grid term is correct.
  4. COCOS boundary tests. TORAX declares no COCOS and normalises signs by construction; Nova pins COCOS 17 provenance. Bank explicit round-trip sign tests — ψ orientation, I_p, F, Φ and the flux-function derivatives — at the adapter boundary in both directions.
  5. ForwardTransport façade. One public entry point over the ladder: typed immutable inputs (geometry record, initial state, waveforms, model selection), typed receipts (flux budget, I_p ledger, achieved boundary values, solver diagnostics), rung recorded in provenance. The native rung and the TORAX rung sit behind the same contract. Any engine failure raises; a zero-filled or otherwise fabricated fallback state is prohibited.
  6. Return channel. Map the evolved TORAX state (pprime, FFprime, I_p) into the typed flux-function seam so an evolved state is a first-class ForwardProfile source, with the derivative/consistency checks the seam already mandates.
  7. Coupled window solve. Drive TORAX step-wise from Nova over a declared window: solve the free-boundary equilibrium at the coarse sample times, assemble FSA records, advance transport across the window against the interpolated geometry waveform, hand the evolved drive waveform back, and iterate the exchange to the declared tolerance. Expose solve_window — converged fixed point, convergence receipts, implicit-function gradients — as the default, and the single-sweep equilibrium/transport waveform primitives as public pure functions. The waveform type carries the evolving coordinate map (Φ_b(t), axis and boundary references) so temporal interpolation never mixes radial coordinates, and the geometry adapter is authored in jnp directly from the traced FSA record — bypassing TORAX's host-side geometry builder — so the implicit gradient survives the geometry leg.
  8. Ensemble batching. Batch members by vmap over the frozen transport state, preserving member identity end-to-end, matching the weighted-ensemble handoff locked at the Ambix seam.

§4 — Acceptance gates

  • Environment: the stack resolves with TORAX ≥ 1.4.3 and imas-python ≥ 2.2 simultaneously; import-time x64/XLA side effects are pinned by a shared-process test.
  • Geometry: a TORAX run driven by the Nova-built geometry record matches the same case driven by TORAX's own geometry reader to a declared tolerance, on a shaped (non-circular) equilibrium.
  • COCOS: sign round-trips for ψ, I_p, F, Φ, p′ and FF′ pass in both directions against pinned COCOS 17 provenance.
  • Physics: the native rung's existing analytic, torch-parity and TORAX cross-check gates stay green; the multi-channel rung reproduces a published TORAX reference case through the Nova façade.
  • Loop conservation: the coupled loop closes the flux-consumption and plasma-current ledgers across intervals; boundary I_p continuity holds at the declared tolerance; no rung mutates its input state.
  • Window contract: a converged window and the same window run staggered (iteration cap one) agree within tolerance where coupling is weak and diverge measurably where it is strong; receipts report iterations, contraction, exit residual and damping; a non-converging window raises rather than returning a degraded state.
  • Gradients: implicit-function gradients of a scalar functional through a converged window match finite differences, and the gradient path survives the jnp geometry adapter.
  • Numerics: jitted and eager paths agree; a vmapped member batch matches the member-by-member loop; engine failures raise rather than degrade.
  • Seam: an evolved state round-trips the typed flux-function contract and drives ForwardProfile to a converged, force-balanced equilibrium with receipts.

§5 — Sequencing and exclusions

The dependency gate is first and alone; it is small but it gates every other item. The FSA record completion and COCOS tests can proceed against the native rung in parallel once the environment resolves. The coupled loop lands last, after ForwardProfile's static absolute-source contract is green in the sibling plan, which this plan depends on.

Excluded: developing turbulent-transport or pedestal models (TORAX owns its physics; Nova validates the boundary); any measurement fitting or profile identification inside the forward solve; field-aligned/poloidal SOL current (deferred with the same boundary-current reasoning as the equilibrium sibling); porting TORAX's geometry construction to jnp for end-to-end differentiability, unless the loop-differentiability decision is revisited with a load-bearing gradient consumer. Consumer-side migrations — lifting the ambix estimators off whole-run TORAX calls and retiring the torch donor — belong to the ambix integration plan, not here.

§ Decisions

Which engine strategy carries the transport forward capability? Recommendation: the embedded ladder — TORAX for multi-channel fidelity with the native ψ-diffusion rung retained as the differentiable, dependency-free floor — because rebuilding TORAX's verified closure surface in Nova is person-years of work the Apache-2.0 dependency already provides, while the native rung remains the right vehicle for learned-closure study.

Locked at the 2026-08-10 coupling-contract brainstorm: the embedded ladder carries the multi-channel physics while the native ψ-diffusion rung remains the dependency-free differentiable floor. The windowed coupling contract presumes the embedded TORAX step as the high-fidelity engine, and rebuilding its verified closure surface in Nova is person-years the Apache-2.0 dependency already provides.

How is the TORAX imas-python==2.1.0 / h5py<3.15 pin conflict resolved against the imas-python ≥2.2 stack? Recommendation: a uv override-dependencies entry now, validated by the full IMAS round-trip suites, with an upstream issue asking TORAX to relax the equality pin — because the override is reversible and unblocks immediately while the upstream fix removes it permanently.

Owner ruling 2026-08-20: the project allows pinning to the latest TORAX version - use it. The landed evidence is the mechanism: uv override entries (imas-python >= 2.2, h5py >= 3.15) plus the optional transport extra co-resolve TORAX 1.4.3 with imas-python 2.3.0 and h5py 3.16.0 on Python 3.14.2, with the shared-process x64/XLA pin green. The upstream ask to relax the equality pin remains owed so the override can eventually be dropped.

Which route hands the Nova FSA record to TORAX? Recommendation: construct the standard geometry adapter object directly — explicit fields, explicit signs, no experimental layer — keeping the in-memory IMAS equilibrium IDS as the interchange/egress format rather than the coupling mechanism, because TORAX's IMAS geometry path is marked experimental and only its file route is integration-tested.

Does the coupled equilibrium–transport loop need end-to-end gradients? Recommendation: Picard fixed-point coupling first — gradients flow through transport steps but not through geometry construction — deferring a jnp port of the geometry builder until a specific gradient consumer (design optimisation or whole-loop calibration) is named, because the port is real work with no current load-bearing user.

Resolved by the windowed-waveform design: the converged window differentiates by the implicit-function adjoint without unrolling, so learned closures train through the coupled solve exactly when it converges. The jnp geometry adapter built directly from the traced FSA record bypasses TORAX's host-side geometry builder and keeps that gradient path intact; a port of TORAX's own builder stays unnecessary until a consumer needs gradients through TORAX's reader path itself.
