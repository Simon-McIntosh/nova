§0 — The owner directive and the measured asymmetry

The owner directed (2026-08-23) that plasma-cell-resolution refinement and operator scaling be sequenced in the solver lane and landed, with the DIII-D forward-gate re-evaluation held behind it. The numbers the parity campaign measured and this plan carries: nova resolves the plasma interior with 248 cells against the reference's ~2,141 over the same region — 8.6× coarser where the physics is — and matching it costs 0.44 GB of coupling against a single-device dense ceiling near N=76,600, so the resolution half is nearly free and lands first. The cost asymmetry that decides the two axes against each other: mesh refinement is quadratic in interaction-matrix build compute, about 8.8 CPU-hours per nine-block build at reference-native resolution against roughly 2.4 minutes on device, while raising operator order changes no mesh, leaves the interaction matrices identical and rebuilds nothing.

Two carried cautions gate the reading. The observed mesh orders span 0.97–3.39 in two strata, so any order claim is per-stratum. And the imposed-boundary diagnostic showed refinement improving the bulk while worsening the extreme by a factor 31.8 — a refinement verdict quoted only in the bulk norm would repeat that mistake. Every verdict in this plan is judged against a criterion from scoring-criteria-derivation (declared prerequisite), never against the inherited 1e-8 bound.

§1 — Raise the default interior resolution to reference-native

Fix the default that sits 8.6× coarser than the reference it is scored against: raise the default interior resolution to at least the reference-native equivalent (~2,141 cells over the same region), measure the coupling memory and the interaction-matrix build cost at the new default on CPU and on device, and hold the forward suites green at the new default.

Done when: the new default is in place with the measured coupling (GB) and build cost (CPU wall and device wall) stated in the receipt, the forward suites pass at the new default with counts quoted, and the residual/geometry rows re-measured at the new default are banked beside the 248-cell baselines.

§2 — Raise the operator order on a stated scheme

Raise the operator order on a stated discretisation scheme, re-measure the observed order on the same ladder that produced 0.97–3.39, report the two order strata separately, and demonstrate build-compute independence from the mesh: the interaction matrices are byte-identical before and after the order change, and the build time does not move with the order.

Done when: the scheme is named in the receipt, the re-measured per-stratum orders are banked beside the carried ones, and the matrix-identity plus build-time-invariance demonstration is quoted. The new mesh spacing this work introduces is also the third spacing the held-out criterion's asymptotic qualification is waiting on (two spacings existed when it was derived): re-fit the per-stratum orders on three spacings and bank the refreshed criteria beside the two-spacing values in the same receipt.

§5 — Resolution self-consistency: every plasma-adjacent default at the new scale

Owner directive (2026-08-23): the plasma-cell default does not move alone. Every plasma-cell-adjacent resolution default is bumped to a consistent scale — in particular the rectangular contour/flux-map grid, which should sit at similar resolution to the plasma mesh — and the full set is audited for self-consistency. Known anchors: Frame.dplasma (−500 → −2100 in the demonstration commit), the reference suite's own pinned SUITE_CELLS = −500 (tests/test_equilibrium_forward_reference.py:265), and the rect contour-grid default whose owner the inventory must trace (map-extraction and flux-surface machinery consume stored 65×65 maps; the solve-side lattice and levelset grids have their own defaults). The inventory states, per default: current value, owning symbol and consumer paths, the scale it implies beside the 2,210-cell plasma mesh, and a proposed value with its cost.

The SUITE_CELLS investigation rides in this section: the passive-closure reproduction move measured 0.6098 points against a 0.15 ceiling at the pinned −500 carrier (6.2× the documented 0.098-point direct response), and both the old-default and bumped-default workers reproduced the identical value, so the anomaly is independent of the global default. Before any repair, measure the same passive-closure move on a suite-cells ladder (−500, an intermediate, and the reference-native equivalent, all as explicit arguments): a move that collapses toward the documented response at denser cells convicts the coarse carrier and the fix is the consistency bump this section owns; a mesh-independent move convicts the closure path and routes to a defect node with the mechanism named.

Done when: the inventory table is banked with a consistency verdict and proposed value per default; the passive-closure mesh-response ladder is banked with its verdict (coarse-carrier artifact versus mesh-independent defect); and the follow-on bump or defect node is named from those receipts rather than assumed.
