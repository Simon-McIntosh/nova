§1 — Objective and S2 role

Build the canonical MAST geometry registry directly from the L1/L2 Zarr catalogs used by Ambix training. The registry must identify the physical machine and installed diagnostic pose over discrete operational shot ranges. EFIT filament counts, AMM channel counts, cell tilings, mesh resolution, padding and numerical weights are retained as provenance only and can never create a configuration.

This plan is the geometry authority immediately upstream of mast-machine-description and physics-spine-adoption. It is attached to S2 before machine-description authoring because both consumers need the same answer to “which physical MAST configuration applies to this shot?”

§2 — Locked identity contract

Contributes to identityNever contributes to identity
Active-conductor geometry, turns and polarity Number of filaments or cells used to approximate a conductor
Passive geometry, material grouping and electrical topology Number of passive elements used by a solver discretization
Wall/limiter geometry and TF physical configuration Mesh resolution, quadrature order, padding or source weights
Diagnostic position, full path and sensitive-axis orientation Channel availability, absent arrays or a one-shot catalog dropout

A range boundary is admitted only when a canonical physical digest changes and the source evidence supports a real hardware reconfiguration. Missing catalog evidence is represented separately and does not split the range.

§3 — Research already landed

The linked catalog geometry evidence and full-corpus report establish the starting point:

  • 11,573 L2 stores were scanned; 11,556 carry a complete recoverable physical snapshot.
  • Three Ambix-compatible EFIT setup digests cover 11,016 matching L1 shots, but all complete observations collapse to one physical digest, 67f789d3d8b40135.
  • The directly observed physical range is 11766–30471. Sixteen stores omit both passive and wall arrays; shot 26963 omits only vertw. All 17 are missing evidence, not machine configurations.
  • One snapshot contains 13 active components, 16 passive families, 78 poloidal probes, 44 flux loops, 36 ordered saddle paths and 96 soft-X-ray chords.
  • Six prototype tests pin subdivision invariance, path invariance, range-hole handling, real setup-to-physical collapse and the 26963 dropout adjudication.

§4 — Deliverables

  1. Catalog geometry reader. A maintained Nova module that reads only static L1/L2 arrays, joins L1 orientation/span to L2 named placement, validates required families, and emits typed physical objects plus source-completeness records.
  2. Canonical registry. Stable geometry payloads and digests independent of component subdivision, with source paths, units, tolerances and representation provenance.
  3. Shot-range map. Ordered, non-overlapping physical configuration ranges; observed, inherited and missing-evidence status are separate fields.
  4. DD 4.1.1 authorer. pf_active, pf_passive, wall and magnetics generated with imas-python. TF and diagnostics not fully represented in the catalogs remain explicit authoring gaps rather than guessed geometry.
  5. Consumer seam. Nova and the migrated Ambix physics select geometry by shot through the registry, not by EFIT setup digest or mesh count.

§6 — Acceptance gates

  • Subdividing or merging equivalent active/passive source elements leaves the physical digest unchanged.
  • Changing any conductor outline, passive topology, wall contour, turns/polarity, diagnostic position, sensitive axis or ordered path changes the digest.
  • Every shot lookup returns one configuration plus an evidence state; missing source data cannot silently fall through to a different configuration.
  • All complete L2 stores map to the published registry, and the 17 incomplete stores are reproduced as explicit gaps.
  • DD 4.1.1 validate/reopen/round-trip tests preserve geometry to the declared physical tolerance and preserve diagnostic orientation/path ordering.
  • Representative Nova operators agree across all three historical setup aliases after they resolve to the same physical machine.

§7 — Boundaries and residual gaps

The catalog proof is complete for the axisymmetric components and magnetic/SXR diagnostics listed in §3. It does not yet supply detailed TF winding geometry or full installed poses for every non-magnetic diagnostic. Those gaps are fields to source or scope explicitly during IDS authoring; they are not permission to infer geometry from a signal grid, and they do not revive the old EFIT/AMM digest as machine identity.
