Scope. The fourteen pending plans not coordinated by S19. From S10 to S17: ensemble-forward-seam, forward-profile-validator-set, separatrix-spline-extraction, profile-owned-solve-domain, mast-nonaxisymmetric-physics, diiid-forward-onboarding, machine-description-retirement, diiid-pulse-replay, dual-branch-selection, efit-baseline-demonstration and mast-catalog-gpu-solve. Nodes. For each plan in scope, the report records:

  • what landed, with commits and the files that carry it;
  • whether the plan's status and impl agree with the code;
  • implementation depth: deep (implemented, tested, reached from a real call site, used) or shallow (scaffolding, an uncalled module, docs only), with the call-site and test evidence named;
  • the open followups and whether each carries a done-when;
  • the next critical node, or a recommendation to close or supersede the plan.

Read-only against the code: no source changes, no GPU, no SLURM jobs.

Done when. docs/evidence/replan-2026-09-24/plan-currency-and-depth-a.md and …-b.md each carry one row per assigned plan with every field above, each claim citing a file, line or commit.

§2 Thin interfaces to shared infrastructure

Node replan-thin-interfaces. Finds where nova reimplements, or couples tightly to, shared machinery:

  • the reckon crew and plan layer (scripts, docs/state, receipts);
  • the local model lane;
  • fleet and SLURM placement (scripts/h200_test_lane, sbatch payloads, partition and reservation literals, --mem handling);
  • imas-python data access;
  • hard-coded GPFS paths.

For each coupling, the report names the files and the refactor that reduces it to a thin interface, with a one-line done-when. Read-only: no source changes.

Done when. docs/evidence/replan-2026-09-24/thin-interfaces.md lists each coupling with its files and line counts, the refactor, and its done-when. The counts come from a bounded search: named subtrees, no whole-tree walks.
