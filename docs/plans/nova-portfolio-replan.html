§4 Consolidate before extending: shared algebra, hot modules and evidence integrity

Why. reckon's review of the crew dispatch pattern (crew pattern review §8) measured nova's primary branch from 2026-08-15 to 2026-09-26. It found no broad rise in flapping: mature source churn was 9.27% before 12 September and 9.39% after, while the local lane's share of code landings rose from 7.7% to 65.1%, and the five worst reversals were mostly metered-lane. What did change is where effort went and what the evidence says. In the week beginning 19 September, 95 of 872 first-parent commits touched nova/ or tests/. nova has the highest attempts per landed node of the five projects (2.23). The figure-and-solver audit found 103 of 348 fleet-made figures misrepresenting their physics. And a structural census of nova/ found repeated algebra where one implementation should exist (§7). Four modules changed in every one of the six weeks: nova/equilibrium/fixed_point.py, forward.py, forward_operator.py and topology.py.

Nodes. Each is independent unless stated.

  • replan-constraint-algebra: the seven identical residual methods and five identical dual_flux_image methods in nova/equilibrium/constraint.py share one tested implementation. Each constraint keeps its observed quantity, payload and registration, and JAX tracing and array axes are preserved. Done when the census's identical-body groups for those methods report one implementation and the fast lane shows no added failure against its base revision.
  • replan-small-primitives: one uniform-axis validator (map_extraction.py, diiid_efit.py, mast_efit.py) with each caller's tolerance policy passed explicitly; one owned read-only array constructor; one atomic receipt writer for calibrate/sweep.py, catalog/mast_geometry.py and imas/mast_parity_gate.py; one trimmed-string check beside require_string; one canonical digest beside canonical_json. Done when each group reports one implementation, with the census's candidate list in the reckon data directory docs/research/data/crew-pattern-review/code-depth/ as the checklist.
  • replan-hot-module-contracts: each of the four modules that changed every week gets a short contract, as a module docstring naming its public entry points and invariants and one contract test that fails if an invariant moves. Any later node that writes one of these files cites the contract in its brief. Done when the four docstrings and tests exist and the fast lane is green at the merged head.
  • replan-figure-repairs: schedule and drain the repair followups the figure-and-solver audit filed on their owning plans, starting with the 103 figures that misrepresent their physics. A figure of a state that did not converge carries its residual and converged flag, or is retracted. Done when every repair followup the audit filed is resolved, with its figure re-scored or retracted.
  • replan-fast-lane-restored: the default fast lane is a gate a node can run. The review's readiness census (§8) found that from 2026-08-29 to at least 2026-09-19 the default pytest collection failed on 10 errors — five modules importing _separatrix from a benchmark that no longer exported it — so the repository's own default test command ran no test for four weeks while nodes promoted on targeted gates; the break is repaired at head. At head, the lane selects 7,273 tests and had observed 1,204 passes and 14 failures after 25 minutes, 16.7% of the way through. Done when a complete run of the default selection at head records its passed, failed, errored and skipped totals and its wall time, each of the 14 observed failures is fixed or carries a named owner, and the lane (or a declared quick subset of it) completes within a budget a node can afford — with that budget stated.

Done when. The five nodes above land, and nova's default fast lane at the merged head has no added failure against the complete head run that replan-fast-lane-restored records.
