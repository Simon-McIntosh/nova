Null identification authority

The lead's hypothesis at the S19 triage of 2026-09-03 was that errors in the O-point and X-point identification drive the convergence and stability failures. Six read-only investigations tested it against the twelve-arm MAST bank, its EFIT flux overlays (docs/evidence/mast-bank-efit-overlays.html), the exact Solov'ev certificate, the DIII-D gate frames, the code path and the commit history (reports under ~/.config/reckon/crew/reports/nova/triage/). The verdict is split. X-point placement error does not separate converged from stalled rows: displacement to the nearer EFIT X-point spans 7.4 to 39.0 mm across the bank with converged arms at 30 to 32 mm and the tightest agreement (7.4 mm) on a stalled arm, and the flagship stall on 22086/43 pure is located at the acceptance policy in fixed_point.py, so the acceptance remedy on solver-convergence-regression stays the primary lever. But the same reports found identification defects that are real, reproducible and currently unguarded: the read path the solve actually uses ranks X candidates by flux with no containment test (the polygon containment fix landed only in the class-margin comparator); two shots (21986/46 and 21989/55, four rows, all nonconverged) latch onto the same off-axis limiter coordinate near the upper wall and read limited against EFIT's diverted; on exact Solov'ev solutions the diverted case returns no qualified axis at two of four resolutions and a 143.7 mm axis error at a third while its residual gate still marks a row qualified; and no receipt anywhere banks Nova's own O-point beside EFIT's, so the hypothesis could not be tested on the axis at all. This plan makes identification a checked property, so that the convergence question can be asked on arms whose topology read is known to be right.

§2 — Connected, contained stationary points on the read the solve uses

Both stationary points are admitted by rules that never ask whether the candidate belongs to the plasma. For the O-point (scout nia-axis-disjoint-mechanism, the 21985/51 rows): o_point_index is a flux-only argmax, qualified_o_candidates forces each candidate's own cell into the material mask it is tested against and accepts any overlap, and the second admission pass in _fixed_design_read seeds at the first pass's winner, so a coil-adjacent well inside the vessel qualifies and outranks the true axis, and the Newton residual then converges around it. The O-point rule to land: test each candidate's flood component against the original material mask, require the component to span a stated fraction of the material cells, rank only among candidates connected to the plasma's confined component, and seed the second pass from a property independent of the first pass's winner so it can rescue a correct axis but never change it; pinning tests are the synthetic two-well map, the two 21985/51 arms from the bank operands asserting the axis within a cell pitch of R 0.90 m, and a seed-invariance regression. For the X-point: the candidate-selection audit found two parallel topology readers. Topology.read_qualification (nova/equilibrium/topology.py, the entry point ForwardFluxOperator.read calls on every default path) selects the X-point by argmax of the polarity-signed flux offset over all candidates in the fixed-capacity stencil table with no geometric screening (x_point_index, lines 335 to 345), and its legacy boundary predicate decides between the X-point and the wall extremum by a height band rather than containment. The polygon ray-cast containment (_points_inside_polygon) lives only in traced_boundary_read (connectivity_boundary.py), which the solve consults for the class margin and nothing else. Apply the same containment to the candidate set before the flux ranking on the solve's read path, keep the wall-extremum comparison on the contained set only, and add the regression the audit names: a flux map where an out-of-vessel saddle outscores the true X-point on flux, asserting the qualification's x_point is the in-vessel one. Add the end-to-end parity test between the two readers on a battery that includes an out-of-vessel saddle. Done-when: both tests green in the default lane, the seven referee tests green, and the twelve-row bank regenerated with the contained read showing which rows changed selected saddle, boundary flux or trip-1 partition (expected none on the eight label-agreeing rows; any change is stated).

axisless-trial-conditioning

Lead decision 2026-09-08, and it is a conditioning rule rather than the control-flow choice that was offered. TWO REGIMES, discriminated by magnitude. When there is NO plasma current, or very little compared with a matrix norm of the coil currents, the axis-free path is correct: there is genuinely no axis to find, the computation must proceed without one, and IT MUST RETURN FINITE VALUES RATHER THAN NaN. When there IS plasma current, and supporting measurements, an unqualified axis read does not mean the iteration should proceed without an axis. Consuming the unqualified axis for normalisation, which is the NaN this work began with.
