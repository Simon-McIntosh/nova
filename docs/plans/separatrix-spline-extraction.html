§1 — Four boundary contracts where there should be one

The extraction seam map (docs/figures/efit-baseline-demonstration/extraction-seam-map.md, commit 43d03cf6) established that no single LCFS polyline is shared by the solve, the production MAST scorecard, transport geometry, and the EFIT corroboration figure. The figure draws a Matplotlib marching-squares path on grid flux — the coarse, wavy curve visible in the twelve panels, with divertor legs running unclipped past the X-point. The production label is an eight-vertex ring from bilinear ray marches. The transport route consumes global-spline Bernstein-block corrections but emits no ordered polyline. Only the transport route touches the sanctioned curve source: the global not-a-knot C2 tensor spline, the authority the twice-refuted local reconstructions were replaced by (curved-clip-global-surface).

The capability reuse map (docs/figures/efit-baseline-demonstration/reuse-map.md, commit 4b702960, 25 candidates over nova and imas-ambix) found every ingredient in reach and exactly one missing contract: fixed-capacity assembly of per-cell global-spline arcs into one axis-enclosing closed branch plus separately retained open legs. This plan builds that one thing and factors two existing mechanisms; it adds no second spline representation and inherits no grid-resolution contour as geometry authority.

§2 — Stationary-point polish on the global spline

Factor the fixed-iteration gradient/Hessian Newton loop embedded in traced_spline_contour (nova/equilibrium/flux_surface_connectivity.py) into a seedable fixed-slot kernel polish_stationary_points(spline, seed_rz, valid) returning polished position, value, gradient norm, Hessian type, convergence, and in-domain validity. stencil_nulls.xpoint_candidates remains the candidate census and scoring boundary; its local quadratic _refine_selected_vertices stops being the position authority. The subordinate-union semantics of the dual sweep (commit 00006fda) are a contract to preserve: candidates in, polish out, primal coordinates never perturbed by the polish of another family's candidate.

Done when: polished saddles and extrema on manufactured C2 fields converge grad-psi to machine precision within fixed trip counts; existing candidate tests unchanged; JIT/eager/vmap parity held. The polished null feeds the O/X pair that profile-owned-solve-domain normalizes flux with, so precision here is solve-facing, not cosmetic.

§3 — Closed/open branch assembly at extraction resolution

Assemble a fixed-capacity graph whose nodes are canonical shared edge crossings plus the polished saddle, and whose edges are the valid cubic segments from traced_spline_contour. From the axis side, identify exactly one closed component as the boundary; emit saddle-connected remainders as separately typed open legs. Never select the closed boundary by longest-polyline ranking — that can pick a long open leg. Reuse the padding/overflow conventions of TracedClippedSupports; extraction resolution is independent of solve resolution. For limited states return the single closed boundary and empty leg slots.

Done when the five tests the reuse map enumerated pass: a manufactured diverted field (one closed lobe, two open legs, saddle-exact endpoints and branch identity); a limited field (one closed branch, zero legs); a double-null field (deterministic fixed slots, no leg merge); JIT/eager/vmap parity with exact-zero inactive padding and fail-closed capacity; and closed-branch metrics invariant when leg extent is extended beyond the X-point.

§4 — One comparator for both EFIT banks

One shared metric implementation, evaluated on the closed branch only, wired into the MAST frozen-arm corroboration harness (replacing its Matplotlib _binding_contour) and the DIII-D preregistered match (replacing the longest-contourpy-line _separatrix): topology-class agreement from the achieved saddle-aware read via class_margin — never ForwardTopologyState.diverted or a requested class — symmetric sup and symmetric RMS nearest-polyline distances in metres, and nearest polished saddle to the unordered EFIT X-point set in metres. Missing boundaries, classes, or X-points score as explicit named failures; nonconverged solves stay failed rows. EFIT remains an independent magnetics-fitted reconstruction: geometric comparison only, COCOS 3 to 17 with unit geometric factor on MAST.

Done when: both banks regenerate through the shared comparator with spline-precise closed boundaries, legs retained for plotting but excluded from every metric, and the twelve-panel figure redrawn with the clipped curves. These regenerated banks are the geometry input to the demonstration gate on efit-baseline-demonstration.

§ Decisions
