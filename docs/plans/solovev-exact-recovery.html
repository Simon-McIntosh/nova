§1 — The mandate, and the drift it answers

Owner commission 2026-08-20. The Solov'ev analytic equilibrium is this programme's fixed oracle. There is no confusion about authority: when the discrete forward model disagrees with it, the defect is nova's to find and fix — never the oracle's, never a bound's. The boundary-ring merge (main 3b3122fa) closed the source seam with every gate green, but the converged roots still sit displaced from the analytic solution by an h-independent offset: axis 42.4→42.5 mm, flux 6.51→6.69% of span, plasma current −1.12→−1.15% under a 1.9× cell refinement, while the local operator residuals genuinely converge (Grad-Shafranov residual 0.0436→0.0246 ≈ O(h²)). The same magnitudes — axis 41.2 mm, I_p −1.12% — were banked against DINA 135011/7 on the ITER 1587-cell mesh, a different reference on a different machine. A fixed systematic in the composed field is the only mechanism that produces the same numbers twice (attribution evidence).

The suspects each carry one prior measurement: the far-field filament truncation in the hybrid kernel (11.7% of the coupling pair error, removable by the exact kernel at fewer primitive evaluations than the quadrupole — 4 vs ~5 — so the truncation buys nothing); the rectangle-for-hexagon section substitution (a stable ~3.5% share of the composition error; hexagon vs equal-pitch rectangle second moments differ +20%/−10% radial/vertical); and the first-moment coupling truncation on clipped and near cells (a measured plateau, worst 5.1e-2 relative at near targets, that refinement does not remove). The free-boundary position mode is near-marginal (measured map eigenvalues 1.25–1.77 on diverted states), so small fixed forcing terms plausibly amplify into the observed rigid displacement — plausibly, not provenly: §3 convicts before §2's defaults are credited with the recovery.

§2 — Exact kernels by default: Urankar everywhere, hexagons are hexagons

Locked (kernel-default, section-fidelity). The Urankar/Part V exact section kernel becomes the production default on every coupling path; the far-field filament truncation is retired — its measured runtime advantage was never significant (production paid ~1.07 primitive evaluations per pair only because it truncated; the exact section costs 4 against the quadrupole's ~5 and is more accurate). And a cell authored as a hexagon couples through a hexagon section: no fallback to rectangle sections, ever. The substitution is removed, not deprecated — construction of a coupling that would route an authored polygon through a different section shape fails loudly.

Done-when: (a) an audit enumerates every coupling construction site (plasma, coil, passive, wall, sensor rows) with the kernel and section shape each actually uses, on main; (b) the exact kernel is the default on all of them with the filament far-field branch removed from reachable production code; (c) hexagon cells demonstrably couple through exact hexagon sections — a red-then-green test constructs a hexagon-authored machine and asserts the section moments used by the coupling equal the exact hexagon values (5/72 pitch²), with a guard test proving a shape-mismatched construction raises; (d) uniform-current rows reproduce the prior exact-kernel values bitwise where the kernel was already exact, and every changed row is accounted to the retired truncation or substitution; (e) the complete suite is green and the boundary-ring bank digits reproduce; (f) build-time impact is measured (§5 owns the formal benchmark; this section records the raw before/after build cost so the change is never credited or blamed unmeasured).

§3 — The cell-moment wiring: convict, then correct

Owner framing: we developed a highly accurate scheme and then failed at the last step by not wiring it correctly. The nine exact Part V moment blocks, the machine-precision clip, and the degree-nine density all exist and are individually verified — yet the composed field at the root drifts by constants. This section audits the wiring from the attributed cell moments to the field the fixed point actually consumes, and convicts the drift quantitatively before any repair is credited.

Done-when: (a) a wiring audit traces the production path from CellCurrentMoments through the coupling contraction to the flux and field each solve target consumes, stating for every stage which kernel, section, expansion centre and moment order it actually uses — discrepancies against the intended design (exact blocks, fixed centroids, first moments) are listed with file and line; (b) the map forcing g(x)−x is evaluated at the exact analytic state on both fixtures and decomposed by component swap — exact-section vs production, second-moment near-field comparator vs first-moment, kernel-constant variants — using the already-banked variant machinery, each component reported as a fraction of the observed forcing; (c) the linear-response check runs: (I−Dg)⁻¹ applied to the measured forcing, against the observed root displacement (42 mm axis, 6.5% span flux, 1.1% I_p) using the serialized terminal roots and the verified tangent — reproduction within stated tolerance convicts the composition constants, failure to reproduce is itself a recorded finding that redirects the hunt; (d) any wiring defect found is repaired in place (single code path) with the repair's effect on the root measured directly; (e) results JSON, the decomposition figure, and the run log are banked and the complete suite is green.

§5 — The benchmarked accuracy–cost ladder: correct, then fast

Locked (runtime-target). Solutions must be correct and they must be fast at runtime. The target: a converged Newton-Krylov — or Newton-only, if the exact tangent at these scales makes the Krylov loop unnecessary — free-boundary fixed point in ≈1 ms on GPU. Build cost is a separate axis: the design-matrix construction (coupling blocks, moment companions, clip geometry carriers) must be reasonable on CPU and on GPU, measured, because §2's exact kernels move work into the build where it belongs — and that trade is only sound if it is priced.

Done-when: (a) a ladder of configurations spanning the accuracy axis (kernel exactness, section fidelity, moment order, density degree, mesh resolution) is benchmarked on both axes — Solov'ev gate margins from §4 on one side, build time (CPU and GPU) and per-solve time (GPU; jit-compiled, fixed-shape, batch-1 and batched) on the other — so the cost of every increment of accuracy is a number, not a belief; (b) the solve benchmark reports the converged-fixed-point wall time per state against the ≈1 ms target, with the iteration count, tolerance, and device stated, and the batch-throughput figure beside it for the catalog use case; (c) the recommended production operating point is stated with its gate margins and its costs, and locked with the owner; (d) results and figures are banked in the cumulative evidence with the benchmark harness committed so the ladder re-runs on any future change.

§ Decisions

Which section kernel is the production default across all coupling paths?

Owner ruling 2026-08-20: there were never significant runtime advantages to the far-field filament truncation — the exact kernel costs 4 primitive evaluations against the quadrupole's ~5 and is more accurate, and the banked filament-truncation measurement already showed the exact section as the better buy at production's own far-field fraction. Exact is the default; speed is recovered at the ladder (§5), never by kernel truncation.

May a coupling substitute a simpler section shape for the authored cell geometry?

Owner ruling 2026-08-20: if we select hex then we use hex — no fallback to rectangle sections, ever, and the absence of the fallback is verified by construction and by test, not by convention. Measured basis: the substitution carries a stable ~3.5% share of the composition error with +20%/−10% second-moment distortion.

What is the accuracy authority for the forward model?

Owner ruling 2026-08-20: the Solov'ev solution is the fixed oracle and there is no confusion here — any disagreement between the discrete forward model and the analytic solution is nova's defect to fix. No gate is relaxed to accommodate a disagreement; an h-independent deviation is a defect whatever its size. Further forward progress gates on the §4 agreement set.

What is the runtime target for the production forward solve?

Owner ruling 2026-08-20: a converged Newton-Krylov or Newton-only free-boundary fixed point in about one millisecond on GPU, with design-matrix build time reasonable on both CPU and GPU. Accuracy is bought at build time through exact precomputed matrices; runtime stays fixed-shape matvecs. The §5 ladder prices every accuracy increment so the operating point is chosen on numbers.
