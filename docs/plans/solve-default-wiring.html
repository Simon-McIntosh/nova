Solve default wiring

The capability-wiring audit of 2026-09-02 (~/.config/reckon/crew/reports/nova/capability-wiring-audit.md) found that the production Newton–Krylov route carries the landed active-set safeguards by default while several drivers around it do not: the Solov'ev oracle and certificate call the bare fixed-point routine, the default EFIT parity command runs an absolute-source one-branch solve with the current-constrained seam behind a flag, the bank and MAST visual routes copy a reference seed into both portfolio branches, only one launcher enables the persistent compilation cache, and the EFIT parity run and the reduced certificate rung rebuild the machine instead of loading it. Each fix is one line on an existing route and needs no new type, so this plan ships them first, on today's call signatures, and pins them with a test; the contract that formalises the seam follows on forward-solve-api.

§1 — The one-line fixes

Six wiring changes, each its own node with the route's existing receipt and the seven referee tests as the gate. (1) Solov'ev oracle and certificate: replace the bare fixed_point.newton_krylov(operator.flux_map(), seed) with profile.solve_branch(seed, requested_class, route="newton_krylov", target_current=...), keeping the oracle budgets as keyword arguments; also in the non-pure topology-visual solves. (2) Compilation cache: call configure_persistent_compilation_cache(default_persistent_compilation_cache_root()) immediately after configure_dtypes() at every launcher's executable boundary. (3) EFIT parity: make the current-constrained solve the no-flag path and keep the absolute-source replay behind a named diagnostic flag. (4) Solov'ev seeds through profile.cold_seed_portfolio rather than the private moment-seed copies in the rebaseline and certificate scripts. (5) Exact-bank and MAST visual routes seed both portfolio branches from cold_seed_portfolio so the two-class portfolio tests independent basin entry, with the reference-seeded path retained behind a flag for the bank's own reproduction. (6) Cached machine: the default EFIT parity run loads the persisted response carrier and every certificate rung, including the reduced one, goes through cached_machine. Constraint pins and Anderson are recorded as intentionally opt-in and are not changed here. Done-when: each node's receipt shows the route producing the same terminal states as before where semantics are unchanged (bit-identical for (2) and (6), qualified change stated for (1), (3), (4), (5)), referees green.

§2 — The default-wiring test

One test module in the default pytest lane that, for each production entry point the audit named, constructs the route with no options and asserts every declared default resolved on: current pin, settled exit, own-mask acceptance, continuation, best-iterate retention, stagnation stop, exact kernels, cached machine, compilation cache. The assertions read the route's own receipt fields, not internal state, so the test survives the later migration onto the request contract. Done-when: the test is green in the default lane on main, the wiring audit rerun against main reads DEFAULT-ON in every production cell except the two intentional opt-ins, and a deliberate regression (removing one default in a scratch branch) makes the test fail.
