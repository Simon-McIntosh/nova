§0 — The defect, measured

The root conftest.py marks curated heavy modules and node ids slow at collection (_SLOW_FILES / _SLOW_NODEIDS in pytest_collection_modifyitems), and the pyproject default addopts = "-rfEs --doctest-modules -m 'not slow'" deselects them. For the forward-solve suite that combination is total: pytest tests/test_equilibrium_forward_solve.py reports “no tests collected (28 deselected)” and exits 0. The invocation any agent, contributor or CI step reaches for — the plain per-file run — reports a false green on a suite of 28 tests. It surfaced only because one parity worker quoted its collected count (efit-forward-parity §12, routed out as the followup this plan absorbs); the repository must not depend on a worker counting.

The fast-lane budget is the constraint the fix must respect: the slow marking exists so the default repo-wide lane stays cheap. The defect is not that the suite is marked slow; it is that an explicit per-file invocation — where the path names the intent — silently selects nothing and still exits 0.
