§0 — The defect, measured

The root conftest.py marks curated heavy modules and node ids slow at collection (_SLOW_FILES / _SLOW_NODEIDS in pytest_collection_modifyitems), and the pyproject default addopts = "-rfEs --doctest-modules -m 'not slow'" deselects them. For the forward-solve suite that combination is total: pytest tests/test_equilibrium_forward_solve.py reports “no tests collected (28 deselected)” and exits 0. The invocation any agent, contributor or CI step reaches for — the plain per-file run — reports a false green on a suite of 28 tests. It surfaced only because one parity worker quoted its collected count (efit-forward-parity §12, routed out as the followup this plan absorbs); the repository must not depend on a worker counting.

The fast-lane budget is the constraint the fix must respect: the slow marking exists so the default repo-wide lane stays cheap. The defect is not that the suite is marked slow; it is that an explicit per-file invocation — where the path names the intent — silently selects nothing and still exits 0.

§1 — Explicit paths collect, and zero-collected fails loudly

Make the plain per-file invocation select its tests: when the user names test paths explicitly, the default marker exclusion must not empty the run (either lift the default -m filter for explicitly named files, or an equivalent documented mechanism — the repo-wide default lane keeps excluding slow either way). Add the guard: a run that collects zero tests exits non-zero, repo-wide, so this defect class cannot recur silently anywhere.

Done when: pytest tests/test_equilibrium_forward_solve.py collects and runs its 28 tests with the count quoted in the receipt; the repo-wide default lane's collected count is quoted before and after and the fast lane's exclusion behaviour is unchanged; and a zero-collected run demonstrably exits non-zero on the exact case that previously exited 0, with both exit codes quoted.

§2 — State the policy once

Write the marker policy into the repository test guidance (the testing section of AGENTS.md): what slow means, what the default lane runs, what an explicit path selects, and the zero-collected guard — stated once, where both agents and contributors already look.

Done when: the policy paragraph exists in the test guidance, matches the implemented behaviour exactly, and the plan's evidence record links the commit.
