Polarity-ranked magnetic axis read

The fixed-shape read now considers every valid census extremum inside the carrier vessel cells. It requires a negative-definite Hessian after multiplication by the declared polarity, excludes an extremum whose signed flux persistence to its nearest saddle is within the fitted field's binary64 rounding enclosure, and selects the remaining maximum of polarity times ψ. The census keeps its nearest-to-previous axis first and retains other extrema after its saddles so the read can make that choice without sorting at a call site. If no qualifying axis exists, the read returns valid=false, qualified=false and a NaN axis.

Why a TCV minimum appeared as an axis

The census itself types an axis only when the polarity-signed Hessian is negative definite. With no such root, its fixed-size gather falls back to position zero but marks that slot invalid. The field-swap adapter's stationary_axis_admitted then rechecks only for any stationary extremum, sets slot zero valid even when it is a minimum under the declared positive orientation, and hands that rewritten slot to the read. A capture around the imported TCV driver on slice 0 saw that rewritten slot marked valid with signed Hessian eigenvalues +10.0881 and +10.5470; the revised kernel returned valid=false, qualified=false and a NaN axis. This is recorded in tcv-flag.log under the run directory. The old read took roots.position[0] without checking type. The adapter still publishes a limited or diverted label without inspecting reading.valid; its label is not a valid axis decision. That adapter check is outside this node's write scope.

The TCV input remains a data-sign diagnostic. LIUQE's stored scalar ψ-axis minus ψ-boundary is positive on all 17 distinct slices, while its stored grid has the opposite ordering on all 17, with grid-to-scalar span ratios from −0.94 to −1.12. COCOS 11 with negative plasma current declares the axis a ψ maximum. The read neither flips the sign inferred from the grid nor searches for a minimum. No LIUQE agreement score is claimed for these grids.
