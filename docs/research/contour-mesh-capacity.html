Contour mesh capacity from geometry

Summary

The topology contour carrier is sized from the geometry it must hold, and refuses a declared capacity it would overflow instead of returning a mesh with no valid vertex.

The defect and its reproduction

TopologyGeometry.from_cells (nova/equilibrium/topology.py) built its contour mesh with vertex_capacity = len(tree_centres) + len(points) + 1, where points is the wall unit's own vertices. The clipped triangulation adds a vertex for every intersection between a triangulation edge and the domain wall, which a wide wall can make exceed the formula.

build_contour_mesh then set overflow = True and blanked every array, so the read returned a mesh with zero valid vertices. Two calls later, occupied[-1] on an empty array raised IndexError: index -1 is out of bounds for axis 0 with size 0 at topology.py:2483.

Reproduced on the imas-efit BOUNDARY_LEVEL_TRACE 2 records under tests/unit/fortran/data/boundary_level, read through trace_record.py: at the coarsest lattice all eight records required 247 vertices against a declared capacity of 231, so all eight failed.

The change

  • The generation of the carrier lists is factored into a helper that runs before any capacity is applied, so the required size is read off the carrier the geometry produced.
  • build_contour_mesh leaves a capacity unset to size it from that carrier. A capacity that is declared is a ceiling: a carrier larger than it raises ContourMeshOverflow, which carries both the required and the declared count and states them in its message.
  • The blanking path is removed; no call returns a mesh with zero valid vertices from an overflow.
  • from_cells no longer passes the fixed formula, and refuses a carrier that admits no valid vertex.

Evidence

The wide-wall test builds a real ITER trace record at the lattice that failed and asserts the valid vertex count is below the capacity. The overflow test forces a capacity below the geometry and asserts the named error carries both numbers. The two files together pass in 12.21 s.

Open. The three-arm regression gate is begun but not recorded. The base archive, the worktree and a control tree that restores the fixed capacity formula were each run over tests/equilibrium/test_topology_read.py, tests/test_contour_tree_mesh.py and the new test file, and none reached its summary line inside the node's time budget; the arms were stopped and no EXIT= line was written. The gate must be rerun without the forced per-test timeout, which sits below the repository's declared value and is a candidate cause of the failures the two control arms showed before they were stopped.
