DD COCOS census — readers, writers and hard-coded signs

Measured landing fragment

nova's COCOS surface is one algebra with five owners and a small set of readers, writers and internal consumers. The single fixed-orientation sign test in the whole tree is PlasmaSlice.prescribe's span * plasma_current >= 0 guard, and it is calibrated on the one DD3 pulse in the survey that does not conform to COCOS 11: DINA 105014/1, whose σBp is −1 in every sampled slice above 1 MA. Every other DD3 equilibrium read in the survey conforms. The internal consumers already work in COCOS 17, declared either by nova/equilibrium/convention.py (total flux Φ = 2πRAφ) or by nova/equilibrium/steering_frames.py and nova/equilibrium/observation_kernels.py (COCOS = 17, refused if not), so §4's migration is a small set of literals, not a re-derivation.

Method, searches and positive control

Two searches fix the population, both run from the repository root over nova/, scripts/ and packages/. Search A finds the IDS reads of COCOS-dependent paths; Search B finds hard-coded sign sites and COCOS comments.

The census table below resolves those hits to the reader boundaries that declare or assume a convention; the count is stated so a later reader can re-run the search and see the same population. Search B's sign-test clause is the sharp one: exactly one line in the tree is a fixed-orientation sign test, nova/imas/plasma_source.py:76. The other 79 lines are COCOS comments, docstrings and the declared-convention constants listed below.

Negative control

Inverting the fixed-orientation guard in a scratch copy of nova/imas/plasma_source.py (changing span * self.plasma_current >= 0 to <= 0 in PlasmaSlice.prescribe) flips the census verdict for that reader. The unmodified guard accepts DINA 105014/1 (σBp = −1, the non-conforming pulse) and refuses CORSICA 130506/6 (σBp = +1); the inverted guard accepts CORSICA 130506/6 and refuses DINA 105014/1. The verdict follows the guard, not the pulse name, so the census row's "convention assumed" column is a live claim about the code rather than a restatement of the fixture's digits. The scratch copy is under the run directory and was not committed.

Scope note for §2–§5

The census does not show §2–§5 as mis-scoped. The population of raw IDS reads is small (the reader table above), the single fixed-orientation sign test is PlasmaSlice.prescribe exactly as §3 states, and the internal consumers already declare COCOS 17 in three places (§4's work is to make the remaining literals read from those owners rather than to re-derive the chain). One item §1 does not name falls out of the census: nova/io/ingest.py's cocos: int = 11 default and nova/io/signalstore.py's cache key write and key on the source DD version, not on a convention, so a store written from a DD4 source while the default stands would be keyed and labelled 11. That is a §4 cache-key concern (canonical_key), named here so §4 does not miss it.
