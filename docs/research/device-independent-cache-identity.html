Device-independent certificate fixture identity

The certificate store now addresses carriers and exteriors by defining inputs. The carrier key retains the analytic machine and constants, requested cells, wall node count and source mode, builder and builder revision. The exterior key retains the carrier key, source coefficients, analytic type, support arm and polygon-kernel revision. Computed wall, state and separatrix array digests no longer enter shared addresses. The stored payload carries this canonical identity and key; the fixture owner receives its local identity during a read, so its existing validation still runs.
