Measurement in progress. This record distinguishes the map defect at the reference from the solver’s ability to find a different self-consistent state.

Instrument and provenance

The DIII-D rows are frames 137, 146 and 179 selected through the registered benchmark’s select_frames. Each uses _build_profile, its EFIT-flux seed and physical wall, the completed circuit-current adapter and the frame’s recorded plasma-current target. The MAST row is shot 21978, slice 35, at 33 × 33 grid points, using the parity benchmark’s passive-inclusive fitted-circuit builder. Both builders are the same ones used by the finite-admission measurement. This is a measurement of those specific composed maps; no source, coil current, mask, tolerance or product code is repaired.

The primary residual is exactly max|g(ψref) − ψref| / max|g(ψref)|, over the full grid-plus-wall state, cross-checked against fixed_point._relative_residual. The largest grid defect’s location is reported separately because a wall entry can set the full-state maximum. A companion centred defect subtracts the median additive constant from the difference, using the same denominator. It diagnoses gauge sensitivity and does not replace the primary raw measurement.

The vertical-force quadrature is Fz = −Σ Icell BR 2πR, in newtons: the operator’s own clipped cell-current integrals supply Icell = Jφ dA, after its declared-current amplitude is applied. BR comes from the map image’s grid flux through Nova’s poloidal_field, which divides the total-flux derivative by 2πR. A second force uses the reference flux’s gradient instead. This distinguishes the field the composed model supplies from the one the label carries. The force fraction divides by μ0 Ip²/2, the characteristic thin-ring hoop-force scale before the aspect-ratio/internal-inductance geometry factor. It is a specified comparison scale, not a measured net radial force. Cell-centre force quadrature and finite-difference field gradients carry discretization error, including a possible discrete plasma self-force.

The negative controls translate the total reference grid and wall flux by rigid ±2 cm in Z while retaining the wall, external currents and prescribed profiles. Cubic interpolation evaluates ψ(R,Z−ΔZ); the spline extrapolates the outermost grid strip where necessary. The signed force offset and its displacement slope are reported, so a biased force need not cross zero for the displacement response to be visible.

Newton uses the benchmark’s registered ForwardSolveRequest and ExplicitSolveSeed, with only warmup=0 changed. No topology class is imposed. A finite saddle is not called an admitted X-point on a limited state, and no cross-branch saddle distance is reported as X-point displacement. Terminal residual convergence and public receipt qualification are kept separately.

Contributor switches

The diagnostic plasma tare applies Delta-star to the reference on the benchmark grid, retains the density inside EFIT’s LCFS, and images its node-area zeroth current moments through the map’s own Green operator. The difference splits algebraically into the prescribed plasma image minus this label-current tare, and the supplied external field minus the remaining label flux. Their sum is checked against the measured grid defect. This node-area tare has a different discretization from the older native-grid exact clipped-profile tare, so it is identified explicitly and does not silently inherit that instrument’s closure claims.

The target-current switch removes only the common amplitude applied to the reference-state current moments. The coil switch zeros the ordinary conductor-current vector; any prescribed current-field response remains and is reported separately. DIII-D’s absent driven passive state is not replaced by an invented current. MAST’s prescribed field contains both active and passive fitted circuits, so that switch alone cannot separate its passive circuits from its active ones.
