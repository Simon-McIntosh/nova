DIII-D vacuum gate diagnosis

The banked absolute current-only forward scored pooled exterior R² = 0.495267 over 20 shots and 4,140 frames, with best-scale 0.337957 and correlation² 0.407332. The low correlation already establishes a shape error. This report tests three candidate explanations without fitting currents, turns, amplitudes, or spatial modes to the cohort.

Verdict

Supported cause: contract mismatch, high confidence. The published ≈0.94 number is explicitly a fitted exterior Green-function decomposition, not an absolute current-only forward. It therefore does not apply to this gate as written. The no-fit sensitivity sweep gives directional support for an incomplete ohmic representation but no quantitative support that it causes the observed deficit: the entire predeclared ladder reaches only 0.512497. The shipped skew convention is supported: every sign reversal is slightly worse.

Does the starter-kit bar apply?

No. The deciding starter-kit sentence is: “Fitting ψ outside the plasma envelope to those Green’s functions … reaches R² ≈ 0.94.” A fitted decomposition can absorb missing members, turn conventions, calibration, and other exterior components into coefficients; the Nova gate permits only one additive gauge per frame and one global sign. The tests are not comparable, so 0.94 is not an applicable pass bar for the absolute current-only forward.

The same current starter text also states that neither machine ships coil_turns, that F-coil turns are already folded into their current values, that ECOILA is plain kA and should not receive a fabricated multiplier, and that ECOILB is a second co-located group absent from the shipped geometry. Sources: starter geometry contract and the pinned dataset inventory revision 1e280905b85f2a6fdde7e06fca8cf3a1edf447cb.
