Domain partition shadow root-cause analysis

The false private-flux shadow in the MAST topology panels is a production domain-partition defect, not a rendering error and not a defect in the saddle-aware hex flood. The 21985/51 wall-notch O/X pair is a second, upstream selection defect. Both must be corrected before dependent end-to-end results can receive scientific credit.

Current disposition: HOLD. Do not regenerate banks, score the comparator, credit achieved classes, or score the demonstration thresholds from the affected terminal states. The production repairs and the complete rerun sequence in Required rerun order must land first.

Headline verdict

Root cause found in the production domain partition. The visual generator faithfully plots profile.operator.read(state).masks.label. That production read reaches Topology.read_with_connectivity, where the connected operand is still Topology.x_mask: a conjunction of horizontal half-plane tests at every finite X-point. It is not a graph-connectivity flood. Closed cells rejected by those cuts are labelled PRIVATE_FLUX, and the same mask qualifies the core support used by the production residual.

The actual saddle-aware hex flood used for connectivity material, reachable-wall selection, and ForwardTopologyState.class_margin is a separate mechanism and is clean with respect to the half-plane defect. Its existing MAST results are nevertheless not clean for credit, because they consume terminal fields produced through the defective residual partition.

The 21985/51 top-wall primary O/X selection has a separate root cause. O and X are selected before either the legacy mask or the hex flood. The O-point selector takes an unqualified global extremum at the upper wall notch; admitting the nearest excluded material cell prevents an empty seed, but it does not validate that candidate as the plasma axis.

Mechanism trace: field to false interior shadow

  1. The figure generator calls profile.operator.read(state), stores masks.label as domain_labels, and plots every value equal to PlasmaDomain.PRIVATE_FLUX in purple. It performs no renderer-side spatial classification. Citation: docs/figures/topology-visual-corroboration/generate_topology_visuals.py:133–139,168–173,357–385.

  2. ForwardFluxOperator.read slices the physical field and delegates mask construction to _fixed_design_read. That helper performs a second read after admitting the axis-owning material cell, but both reads still call Topology.read_with_connectivity. Citation: nova/equilibrium/forward_operator.py:486–502,572–590.

  3. Topology.read_with_connectivity selects O, X, wall, and boundary landmarks, then sets connected = self.x_mask(data_o, vmap_x). Despite the method name, this operand has neither a seed nor an adjacency graph. Citation: nova/equilibrium/topology.py:360–385.

  4. x_mask loops over every finite X candidate. For a candidate below the O-point it keeps cells with Z > Z_X; for one above the O-point it keeps cells with Z < Z_X. Logical AND combines all cuts. Radial position, separatrix contours, shared hex edges, and axis reachability are absent, so any finite interior or side-wall saddle casts an infinite horizontal shadow across the machine. Citation: nova/equilibrium/topology.py:277–297.

  5. classify_domains maps closed & connected to CORE and closed & ~connected to PRIVATE_FLUX. This converts the half-plane rejection directly into the false purple region. Citation: nova/equilibrium/domain.py:101–124.

  6. The path is production-active. _support_partition receives the same connected operand, applies core_support.qualify(connected), and passes the masks and qualified support into source.current_moments. The converged terminal state is therefore a root of a residual whose source participation already used the false partition. Citation: nova/equilibrium/forward_operator.py:692–718.

The saddle-aware hex path: clean mechanism, contaminated terminal inputs

The true connectivity implementation propagates the axis component over a half-offset hex graph and blocks shared-edge links that cross the saddle level. At the binding level it forms confined_star, floods from the seed, and counts the connected region. Reachable-wall selection separately constructs the pre-saddle axis component and keeps only wall nodes reachable from it. Citation: nova/equilibrium/connectivity_boundary.py:20–45,339–386,979–1014,1157–1159.

Separate 21985/51 root cause: unqualified global O-point selection

Topology.o_point_index selects nanargmax(polarity * o_psi) across all O candidates without material, wall-polygon, component-size, or resolved-boundary qualification. x_point_index then selects the X candidate relative to that already chosen O. Both decisions precede the legacy mask and the true connectivity read. Citation: nova/equilibrium/topology.py:164–175,192–202,360–385.

For both 21985/51 arms, the selected continuous axis owns the cell centred at approximately (0.484375,1.75) m. The original material excludes that cell, so one cell is admitted. The original connected component contains zero cells, the repaired component contains only one, and neither read finds a boundary. Other central and lower stationary candidates exist, so the top-wall pair is a selection result rather than an absence of alternatives.

Relationship verdict: this is a separate upstream selection defect. It shares downstream seed and comparator machinery only after the invalid O is chosen. Correcting the 21978 half-plane shadow will not correct the 21985/51 wall-notch selection.
