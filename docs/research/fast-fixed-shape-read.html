Fixed-shape topology read and fused correction

On the 289-cell limited and 282-cell diverted analytic carriers, a fixed-shape read restores the reference boundary and selects the same 254 and 179 support cells. Its two-arc repair validates the previously refused four-crossing state, so all 37 limited in-wall and 32 diverted converged-oracle sweep states pass. The repaired read costs 0.759 and 1.487 ms, above the 0.12 ms target. The limited moment-map JVP agrees with central differences near 10−9; the diverted current and radial blocks retain approximately 10−5 and 5 × 10−6 discrepancies isolated to saddle-cut booking. Qualified one-correction warm convergence remains open.

Method and authority

The prototype lives in scripts/prototypes/fast_read and does not change the production topology module. It solves stationary points through the existing fixed-point machinery, evaluates both saddle and wall boundary candidates, and chooses the binding signed flux with array operations. Wall events include a quadratic peak candidate per edge: the limited certificate's actual contact is at the midpoint of a wall edge, while either adjacent wall node misses its flux by 0.049155. A preliminary saddle-frame-gated graph restricts wall events to axis-reachable cells. Bell polygons provide smooth-cell fractions and four-arc cut moments; four edge crossings use two contour arcs and retain two components when the Bell centre is outside. The selected normal-form sectors supply saddle-neighbourhood fractions and cut moments. Fixed-capacity arrays hold saddle cells; dense boolean reachability uses a static nine squaring steps. No cell, strip, or fragment-label loop is data dependent.

The H200 runs used binary64, printed the imported nova and measurement-module paths, and kept the analytic carriers read-only. A profiler trace had to contain the named compiled module, GPU kernel-detail events, and a host graph launch before its count was accepted. Both the existing read and candidate ran as compiled calls on the same carrier. The full logs and JSON receipts are in /home/ITER/mcintos/.config/reckon/crew/runs/r-20261015T091903690374-fast-read.

Fused correction and retained limits

The fused prototype uses jax.linearize to reuse the primal map and its linearized factor across four Krylov products. It calls fixed_points.maintain_rows as the row owner; its triangle index covers only 928/1,217 limited and 882/1,164 diverted stored sample nodes, so the coarse prototype retains all prebuilt rows for the map. A full-row fallback is a measured necessity here, not an independent moving-window policy. Earlier measurement-helper runs passed a wrong moment shape and then attempted to recompute all cached exterior jets in one batch, exhausting 296.63 GiB before map compilation. Stored exterior jets bound that helper.

Controls and interpretation

The centre-state comparison is a positive control for topology identity: both reference reads are valid, the candidate axis position matches, and the profiler sees nonzero GPU work. A global wall maximum is a negative mechanism control: on the diverted carrier it selects a private wall level of 0.000995 and only 144 cells; restricting the candidate to the axis side restores the near-zero saddle boundary and 179 cells. On the limited carrier, node-only wall sampling selects a contact at Z = 0.112943 m with flux −0.049155 rather than the true midpoint contact at Z = 0; vectorized wall-edge extrema restore the reference level. H200 job 1286010 reran the centre read with the valid axis and saddle entries exchanged: root validity stayed true and a convergence-only check accepted it, while axis identity turned false and the control row went red. H200 job 1286080 reran the final fused map without the saddle-frame gate: its map error rose from 0.001087 to 1.724, again turning the mapped error row red. Both controls execute the program rather than inspect a stored verdict.
