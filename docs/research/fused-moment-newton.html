Fused moment-Newton prototype

The fused coarse-carrier map passes the analytic flux-error ceiling on both machines, and a geometry-selected saddle cut keeps private cells out. A complete device correction still takes 25.65 ms limited and 35.52 ms diverted against the conditional 0.90 ms warm-slice target. The limited cold solve converges, but its one-correction neighboring slice does not; diverted cold solving also stalls. The measured executable therefore does not qualify a submillisecond warm solve.

Question and acceptance

The experiment uses device-built analytic certificate carriers at 289 limited and 282 diverted cells. The design budget allows 0.24 ms for two connected reads, 0.20 ms for two cut bookings, 0.06 ms for two interior bookings, 0.20 ms for two field contractions, 0.12 ms for the linear correction, and 0.08 ms for convergence and constraints. Together these make 0.90 ms per warm slice. The independent gates are a 10−2 analytic flux-map ceiling, a 10−12 scaled moment residual and current constraint, nulls within one pitch, no private-cell admission, one fixed-shape device correction, cold compilation within 60 s, and executable size within 50 MB. A warm wall is qualified only when its predecessor is converged on the same equation.

H200 measurements use binary64, XLA_PYTHON_CLIENT_PREALLOCATE=false, and the read-only device-built carriers from the prior lean-map run. The job log prints the imported nova path and the frozen measurement module path. Each warm wall is the median of five synchronised calls. JAX profiler counts require a named GPU process, the expected compiled module, a kernel-detail event and a host graph launch, so an empty trace cannot be read as zero work. The diagnostic map executable and the correction executable are compiled separately for attribution; the correction itself calls its maps and four JVP products inside one executable.

Program composition

scripts/prototypes/fused_newton/program.py starts from three physical moments per cell. Precomputed dense value and jet blocks form the live field; bounded Bell-row Newton locates the roots. topology.read_at_stationary_points determines the boundary and fragment record. A saddle-frame-gated wall-domain cell graph then selects the axis-connected cells. An 18-point fan books full hexagons, four-arc Bell polygons book ordinary cuts, and a four-chord cubic-sector ring books a saddle cell only where the ordinary crossing pattern is invalid. The program normalises the total current, emits the physical moment residual and current-pin row, and applies a four-product device Arnoldi correction with a checked terminal map.

This is a prototype of the fixed machine shape. The exact fragment read still supplies the saddle frame and binding boundary level, and its internal fragment work remains in the compiled map. The prototype returns the binding level rather than both independently qualified wall and saddle candidates. It carries only the prescribed total-current constraint row, not arbitrary augmented isoflux or moment pins. The fixed Bell-row window is not mobile. These boundaries matter when interpreting the latency and perturbed-state result.

Accuracy controls and local repair

The first H200 attempt reproduced a 1.804 × 10−4 limited flux-map error at 289 cells with 254 selected graph cells. At 282 diverted cells its graph selected the expected 179, and roots shifted by at most 2.22 × 10−5 pitch, yet the map error was 0.289. An ungated graph admitted five more cells and raised that error to 0.328; the gate fired, but both rows were already red. The discrepancy was traced to the saddle cut rather than inferred from the graph count.

The committed selector therefore uses the sector rule only for a cut whose ordinary Bell crossing pattern is invalid; the valid neighbors use Bell moments. It never substitutes an exact booked moment inside the compiled map. This geometry criterion was chosen from the crossing flag, not by comparing each new state with the exact answer.

The geometry-selected H200 map in job 1285872 books one invalid-crossing saddle cell with cubic-sector rings and the two valid neighbors with Bell polygons. It selects 179 diverted cells, returns a zero scaled current row, shifts the farthest root by 2.22 × 10−5 pitch, and gives flux-map error 0.001087, inside the 0.01 ceiling. Compiling the same map with its frame gate removed admits 184 cells and yields 0.158676 error: the five private cells turn a passing analytic row red. The limited map selects 254 cells, returns a zero current row, keeps the axis at its reference root, and gives 0.000180 flux error. From analytic moments, the limited cold solve reaches scaled residual 6.72 × 10−13 and terminal flux error 0.000452. Diverted cold solving stalls at 0.003423; its finite terminal flux error is not a converged-flux result. Terminal root positions were not separately saved, so the one-pitch observation applies to the analytic-state map, not the accepted limited cold terminal. Moving-state continuity remains unmeasured.

The best per-state wall is 25.665 ms limited at width 128, 28.5× the whole 0.90 ms target before qualification; diverted reaches 36.474 ms per state with an unconverged predecessor. Every width-specific compile takes 108–120 s, above the 60 s ceiling. The 1-member vmapped wall differs from the scalar correction wall because it is a separately compiled batched shape; the batch result is reported as measured, not inferred from the scalar call.

This prototype rejects the 0.90 ms hypothesis for its measured implementation while preserving the correct coarse analytic map and a private-cell guard. The exact fragment construction still precedes the cell graph, and each of four JVPs repeats the roots, read, field and booking; those operations leave thousands of kernels in the one-executable correction. A faster design must remove that repeated work and qualify both wall and saddle candidate levels with a moving row window. The present program also lacks arbitrary augmented constraint rows and a converged diverted predecessor. None of its measured walls is a section-wide production acceptance result.
