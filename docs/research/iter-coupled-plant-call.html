Overview

The coupled plant — the sectioned coil winding, the reduced passive system, and the plasma flux drive at every coil section and passive mode — is returned through one public call and one result type. nova.circuit.coupled_plant.coupled_plant(machine, source) returns a CoupledPlant and nothing else is exported from the module. The call composes the machine binding, the sectioned conductor set, the passive reduction and the prescribed plasma; it does not re-derive any of them.

The plant is cached through the circuit tier's own serialisers: nova.circuit.passive.save_coupled_plant and load_coupled_plant, which sit beside save_circuit_system and save_eigenbasis in the module that owns circuit persistence, and which nova.circuit.coupled_plant imports and re-exports so the call reaches them without naming the tier. The location is resolved through nova.database.filepath.FilePath. The cache key is a digest over the machine, the frequencies and the reduction settings, so a plant is reused only when it was built from the same inputs; a test asserts that the module object the call caches through is the one nova.circuit.passive exports, so a private serialiser pair cannot reappear here unnoticed.

What this is for. A switched converter model has to see the plant as a state-space multiport: which coil sections exist, how they couple, how the passive modes screen them and what the plasma drives into them. This call is that interface; it is a composition, so the physics it returns is exactly the physics the underlying nodes already measured.

One call and one result type

CoupledPlant carries, per the brief: coil_names; the section-level coil_inductance and coil_resistance; the reduced passive system as mode_tau and mode_coil_coupling (every retained mode against every coil); the plasma flux drive as section_plasma_flux and mode_plasma_flux against plasma_times at the frequencies the plant was reduced for; reduction_error against frequency; and provenance naming the machine label, the plasma source label and the nova revision.

CoupledPlant.terminal_impedance(frequency_hz) returns the (n_freq, n_coil, n_coil) terminal impedance with the retained passive modes shorted. It is the same function the reduction search minimises against, so the returned error is the error of the returned object rather than a separate estimate.

The plasma source is accepted through a minimal interface: an object exposing plasma_times, coil_current_times, coil_currents and a prescribed_currents() -> list[PrescribedCurrent]. Nothing in the module names a concrete source type, so the IMAS-backed source and a reduced test source are interchangeable.

Cold and cached, reduced and full

The call returns the same plant cold and from its cache, and the comparison is by value on every array field, including mode_tau — an earlier form compared only shapes and would have passed a perturbed cache.

The reduced plant's terminal impedance matches the full model's to under 1% for every coil from 0.1 Hz to 5 kHz, and the returned reduction_error is under 1% over the same band.

The retained count grows with the sectioning, and that is the cost of the guarantee. On the eight-coil case above the search retains all 64 modes: at 48 of 64 the worst relative error is 191%, and the ratio only falls below 1% once the set is complete. The error is a maximum over coil pairs and frequencies including near-cancelling off-diagonal entries, so it is a strict criterion; a weaker pairing criterion would retain far fewer modes. The retained count and the error it achieves are both on the result, so a consumer can trade them rather than take a default.

On the real ITER sectioned set

The reduced plant's terminal impedance is within 1% of the full cached system for every one of the 14 coils over 101 log points from 0.1 Hz to 5 kHz, on both cached sectioned meshes. The systems were loaded from the section 1 cache (12 mm, 1,312 passive circuits; 6 mm, 2,163) and the plant was built through the call above; the meshes were not rebuilt.

The count the guarantee needs is much lower than the count the call returns, and the difference is the criterion. The call grows the retained set until the error is within tolerance over every coil pair, and that maximum is set by near-cancelling off-diagonal entries where the relative error is ill-conditioned: re-ordering the full mode set against itself already reads 2.4e-7, so the pairwise criterion cannot be satisfied far short of the full set. Judged on the per-coil self impedance — what "for every coil" means here — the 1% band is met at 908 of 1,312 modes on the 12 mm mesh and 1,459 of 2,163 on the 6 mm. A consumer that cares about the terminal self impedance of each coil, which is what a converter model sees, can pass that count explicitly rather than take the pairwise-driven default.

Both meshes agree: the worst per-coil error sits at the top of the band (5 kHz) and the coils that carry it are the vertical-stabilisation pair and PF1, the sections with the smallest self inductance. The 6 mm refinement moves the error by an order of magnitude in absolute terms and changes which coil is worst, so the number is a property of the mesh rather than of the reduction settings.

Reading the diagnosis. The plasma drive is omitted in this measurement: the terminal-impedance reduction is a property of the machine alone, and the call now accepts source=None, returning empty plasma fields with the impedance untouched. The plasma-bearing path is exercised by the tests instead.

The point-flux kernel now has one owner

The vessel-evolution driver's passive_flux_at_points derived a per-ampere point coupling of its own. It now calls nova.circuit.linkage.sensor_grid_couplings, the finite-area kernel the rest of the circuit tier uses, and takes the grid column the point index selects. The two agree, and the section 3 receipt's VS3 peaks are unchanged to the reported precision: 8.40230532 → 8.40042344 Wb (relative −2.24e-4) and 10.0803061 → 10.09798884 Wb (relative +1.75e-3). The recomputation is logged: the pulse-105014 12 mm run over the refactored path reads 8.40042344 and 10.09798884 Wb at the two VS3 points, agreeing with the stated after-values to every printed digit (vs3-recompute-105014-12mm.log and its JSON receipt). A test pins the equality, so a second point kernel cannot reappear unnoticed.

The driver's assembly — coupled section flux and coil voltage from the section linkage, the passive currents and the prescribed plasma — previously had no test. It is now exercised on a reduced case through evolve.psis_and_voltages and evolve.integrate.

The terminal impedance and the mode search moved to the same owner. The call's screened terminal impedance is computed by nova.circuit.passive.terminal_impedance_spectrum, extended to take an already-reduced mode set: passing mode_coupling and mode_rate uses the retained modes directly, and omitting them solves the eigenbasis from the dense passive matrices as before, so one screening algebra serves both callers. The retained-set search is nova.circuit.passive.select_modes_to_tolerance, which ranks modes through the tier's own mode_relevance and doubles the retained prefix until the supplied error falls within tolerance. The call supplies its impedance error as that error and keeps every other policy, so the ordering and the returned set are the ones the tier already defines.

Controls

The gate is tests/test_coupled_plant.py, tests/test_circuit_passive.py and tests/test_iter_vessel_evolution.py together: thirty-one tests, all passing, against the committed revision, of which the coupled-plant and vessel-evolution files hold twelve.

The negative control perturbs one cached array — mode_tau, scaled by 1.5 where the plant is written — in a scratch copy of the module outside the repository. The cold-and-cached comparison then fails on mode_tau, whose two values differ by exactly that factor, and the log ends EXIT=1; the head arm on the same scratch tree passes with EXIT=0. Each arm prints the module file it imported, so the arm is known to have loaded the mutated module and not the worktree's. The first attempt at this control passed on both arms: pytest prepends the invocation directory to sys.path, so a run started inside the worktree imported the unmutated package even with the shadow on PYTHONPATH. The arms now run from a neutral directory holding a copy of the test, which is what makes PYTHONPATH alone select the package.

The positive controls are the analytic ones the earlier nodes established: the single-ring L/R decay and the exact zero-order-hold propagation, both still green in the same gate.

Caveats

The tolerance search now doubles the retained count on each trial rather than growing it one mode at a time. The one-at-a-time form is O(n_modes) trials and does not finish on a wall set of a thousand circuits; the doubling form reaches the same decision in a logarithmic number of trials. The mode counts at which the search lands can differ from the linear form between successive doublings, so a caller who pinned a retained count to a number between powers of two should pass that count explicitly.

The reduced-vs-full guarantee is measured on the real ITER sectioned set (both cached meshes, all 14 coils, 101 log points) as well as on the reduced test sectioning. The real-set numbers are above; the eight-coil case remains only as a figure source.

The pairwise tolerance criterion forces a near-full retention on the real set. Narrowing the call's default criterion to the per-coil self impedance — the quantity a converter model actually sees — would retain 908 of 1,312 modes, but it would change what the guarantee covers, so it is left to the caller to pass that count rather than made the default here.
