Design

nova/imas/mast_block_scale.py promotes a BlockScaleTable as tracked data (113 blocks / 76 channels / 19 stepping), applied by default in the vacuum-fit, solve-input, and EFC-screen read paths with the raw path reachable. The correction divided out is the discrete ladder rung nearest the described field — never the fitted ratio, which would launder model error into the data; static per-channel gain remains the sensor ledger's question. Every read returns a ScaleCorrection with one of four dispositions — measured / bracketed / refused / unmeasured — and the last two read exactly as published, flagged; a shot between two blocks is unmeasured however narrow the gap, because that is where the switch is and a guess there costs the factor of two.

The sweep, and two honest refusals

All 400 plasma-free excitation shots swept (coverage 40 → 85 shots/channel median); the estimator reproduces the adjudication exactly on the original split. 0 of 37 switches pinned to the shot — brackets stay campaign-wide (median 4,942 shots). Two narrowing routes failed honestly and are recorded: pre-breakdown windows are defeated by the solenoid swing transient, and a model-free amplitude-ratio observable that would have cut brackets 200× was refused by its own pre-stated gate (it invents 10–18 boundaries on every steady channel and matches only 41/75 real steps — the field-pattern confound dominates).
