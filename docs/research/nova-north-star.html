§1 — The single sentence

Nova is the exact forward operator for magnetically confined plasma: a deterministic, differentiable, receipts-bearing library that maps declared physical sources — conductor geometry and currents, flux-function profiles, transport closures — to fields, equilibria, evolved profile states and synthetic-diagnostic responses, and that fits with none of them. Every statistical operation — priors, noise models, innovation, correction, uncertainty — lives on the other side of a typed seam, in imas-ambix. Nova's competitive claim is not that it infers well; it is that its forwards are exact enough, fast enough and honest enough that a thin estimator wrapped around them beats a fitted reconstruction.

§2 — Doctrine

Five commitments recur across every landed plan, and they are the durable identity of the codebase rather than the residue of any one project:

  • Produce, don't use. Nova builds every response kernel — the magnetics design matrix, chord→ψ_N sampling, Δ* extraction, moment operators — exactly as precisely as if it fitted with them, and never fits with them. A measurement array accepted by a public forward solve is a test failure.
  • Receipts, not rails. Conservation ledgers, convergence receipts, conditioning receipts and provenance travel with every result. A solve that cannot converge raises; it never returns a silently degraded state, and it never accepts a constraint hook that would smuggle fitting into force balance.
  • Absolute sources. No silent renormalisation, no gauge shuffling, no per-slice rescaling. Declared model fidelity — from the native ψ-diffusion rung to the embedded TORAX multi-channel step — is a provenance field, never an approximation the consumer must reverse-engineer.
  • Differentiable and batchable end to end. jit/vmap/grad-safe kernels so an ensemble is a vmap, a sensitivity is an adjoint, and a fixed point differentiates by the implicit-function theorem rather than unrolling.
  • Machine portability as a recipe. Onboarding a machine is a repeatable path from shipped machine description to converged free-boundary forwards with published throughput budgets — not a bespoke porting project.

§3 — The program arc: three rehearsals

The direction is tested by three progressively harsher external contacts, each one an existing plan cluster:

  • Reference parity (internal). Reproduce what established codes produced, forward-only: DINA/CORSICA/ASTRA reference equilibria (forward-profile-validator-set), EFIT parity on measured MAST slices (spine-efit-parity, efit-forward-parity), and the full-catalog GPU solve (mast-catalog-gpu-solve). This proves the operator is right, cheap and portable across producers.
  • The Sophelio Fusion Equilibrium Challenge (external, adversarial, dated). Development closes 2026-10-18; blind final 2026-10-19–26. The challenge deletes the magnetics design matrix and asks whether state estimation over an exact forward operator can replace it — from actuators and Thomson scattering alone, with zero-shot transfer to a second machine. Nova's side is diiid-forward-onboarding: the first true second-machine onboarding, and the carrier of both entry kill gates (the quiescent-window vacuum-geometry check and the label-extraction re-solve). The estimator side is imas-ambix:magnetics-free-equilibrium-recovery, and the cross-repository execution order, gate ledger and sequencing decisions are persisted in the master plan imas-ambix:sophelio-entry-master, which both nova entry plans block.
  • ITER first plasma (the goal). Day-one state estimation on a machine with no operational history: sparse, partially commissioned diagnostics, exact as-built machine description, and a forward-model-backed estimator whose physics transferred because physics that is physics transfers exactly. Everything above is rehearsal for this.

§4 — The seam, and why the estimator is thin

The state that crosses the seam is deliberately low-dimensional: the two flux functions p′(ψ) and FF′/μ₀(ψ) with their coordinate map, uncertainty and causal provenance — the typed FluxFunctionState (imas-ambix:flux-function-state-interface). Nova closes the loop around that state twice: the free-boundary Grad–Shafranov solve maps it to a flux map and every synthetic response (spatial closure), and the transport forward advances it in time (temporal closure). Because both closures are exact forwards, the estimator that joins them to data needs only to correct a slowly drifting low-dimensional state — a Kalman-structured filter over flux functions, not a fit over a 65×65 map. That division is what makes the whole architecture portable: the machine enters through the description and the forwards; the data enters through ambix's measurement models; and neither contaminates the other.
