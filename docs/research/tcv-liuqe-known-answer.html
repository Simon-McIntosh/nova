TCV 77549 LIUQE known-answer: nova's boundary read scored against LIUQE

The aim is a known-answer check of nova's topology read on a machine whose reconstruction is trusted. TCV 77549 is that machine: the LIUQE reconstruction is stored as an IMAS equilibrium IDS with a rectilinear profiles_2d/psi grid per slice, and nova's read is run unchanged on that field with the per-loop TCV wall. LIUQE's own axis, X-point, flux levels dominated this node. The measure below is incomplete and the reasons are data facts, stated first because they bound every number that follows.

What the archives actually carry

Two facts stop a per-slice score being produced as the brief imagined, and both were measured, not inferred.

  1. The named input is degenerate. The brief names imas-efit/tests/data/imas/TCV/77549/validation/liuqe as the LIUQE equilibrium with 1,703 slices. That extract holds 50 slices over 0.793–0.839 s, and profiles_2d/psi is bit-identical across all fifty (one md5 digest over every slice, verified through imas.DBEntry in fresh processes), equal to no slice of the source reconstruction. Compressed as MAG_ONLY in imas-efit's data manifest, it kept the boundary geometry and dropped the per-slice field.
  2. The source reconstruction's grid is piecewise-constant. The LIUQE reconstruction at public/imasdb/tcv/3/77549/1 (DD 3.41.0, 1,703 slices, 0.014–1.62 s, the brief's count) carries only 17 distinct psi grids across its 1,703 slices, each frozen over one contiguous block (block sizes 6, 8, 10, 10, 12, 72, 88, 42, 43, 42, 43, 80, 86, 69, 185, 461, 446). A per-slice read inside a block would score one field repeatedly.

A third fact governs the label. equilibrium/time_slice/boundary/type is unset (-999999999) on every slice of both stores, so LIUQE's own limited-or-diverted label cannot be read from the enum the brief names. It is read instead from the boundary X-point LIUQE stored: absent through the limited phase, present through the diverted one.

Slice choice

Because the field is frozen within a block and independent across blocks, the snapshot takes one representative slice per distinct grid block — 17 slices spanning 0.014–1.62 s, covering both phases (limited at t = 0.046–0.287 s, diverted before and after).

nova's read

nova's read was run on each selected LIUQE psi grid (rebuilt through efit_field_swap.spline_field) on a square lattice inside the per-loop TCV wall, with the wall trace geometry and the read call reused from efit_field_swap.crosscheck. On the three slices that completed inside the budget — indices 0, 6 and 14, all diverted — nova's census admitted no saddle at lattices of 24, 32 and 48 cells, so nova returned unqualified: no axis, no X-point, no label.

Outcome

The measure is unfinished. The dominant obstacle is the LIUQE archive: a per-slice score needs a per-slice field, and neither store supplies one over the pulse — the named extract has a single frozen grid, the source has 17 across 1,703 slices. Against that input nova's read qualified on none of the three slices it reached. The nearest measured figure is therefore not a gap but a qualification failure: 0 of 3 slices scored, all unqualified, on a field of 65×129 samples with the TCV limiter as wall.

No representative poloidal panels are shown: with no qualified read there is no nova boundary to draw beside LIUQE's, and drawing LIUQE's alone would present a reference as a result. The driver scripts/prototypes/tcv_liuqe_known_answer/measure.py is committed and resumes against any slice list.
