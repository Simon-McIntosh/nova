The cause, measured

The read is refused by the axis-persistence test added to scripts/prototypes/fast_map_production/kernel.py at commit 78ed4ac03 ("reject unresolved root-saddle islands", 2026-10-19 00:52), which landed after the read test was written (2026-10-18 18:08). This is not a booking defect and not a region definition: it is the read refusing to name the axis, which is why there is no region and no booked value downstream.

This is the same tension the 72% booked-moment note resolved for the interior: a representation discrepancy is an enclosure, but here it exceeds the physical separation between two nearby nulls, so a real axis is discarded with the unresolved island the guard was written to reject. The owner of that decision is kernel.py, outside this node's write scope; the fix — an enclosure that distinguishes "unresolved island" from "resolved axis near a saddle" — belongs there.
