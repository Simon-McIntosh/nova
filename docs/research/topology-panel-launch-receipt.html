Both the MAST and DIII-D authorities enable ordered per-trip active-set streaming. Because import failed before extraction, the job emitted no per-trip trajectory and no panel artifacts.

Machine-checkable panel record

The committed generator defines each JSON record to carry the panel identity, convergence and qualification, numeric private-flux shadow count inside the Nova closed separatrix, total private-flux shadow count, selected primary X- and O-point coordinates, count of other qualified X-points, closest plasma-wall point, boundary availability, and a numeric converged-panel containment verdict. PNG and JSON are published atomically as each extracted row completes, so already published pairs remain usable if a corrected job is interrupted.

A later successful harvest must assert that shadow_cells_inside_lcfs == 0 for every converged panel. This failed job produced no record values to interpret.
