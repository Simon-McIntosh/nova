Vertical position of the converged forward solve

An elongated plasma can move vertically along a weak equilibrium direction. The free 550-cell diverted lobe solve reproduced a line-search stall at 1.54987034415 × 10−3. A current-centroid height row held by one radial-field amplitude reached 2.09179996955 × 10−13 on the same booked map.

Public solve and source

ForwardSolveRequest.vertical_pin and ForwardProfile.solve(vertical_pin=...) accept a VerticalPositionPin. It builds a ConstraintPair from the existing CurrentCentroidConstraint and a ConstraintBinding. The target is the current-centroid height on ALL_DOMAIN booked support. If the caller declares a vertical-field circuit direction, the single unknown is the current along that direction; the focused test solves this branch and checks its flux response. When no set is declared, the unknown is a uniform radial-field amplitude. One owner in constraint.py supplies the axisymmetric −2π R Z BR flux value, gradient and Hessian to both the public pin and the lobe runner.

AugmentedConstraintSystem owns the pin row and compensating unknown. VerticalPositionPin(active=False) retains that layout but fixes its unknown at zero; an active row holds the centroid. The public ForwardProfile.solve now passes the complete pair through Newton-Krylov's map_arguments, so the target, field image and scale enter its compiled loop as runtime operands. A public test changes both height and field scale between requests, observes those arguments at the Newton entry, and sees one public compilation-cache identity with the second request marked as a cache hit. It would fail if the public route returned to a closure-only pair. A separate lowered test compiles the augmented Newton-Krylov routines once and calls that executable for the free and pinned cases. Profile fitting does not enter either solve.

Elongated analytic carrier

The analytic flux map books two equal-current cells with current, radial first moment and vertical first moment. At each solved terminal state, the independent test read divides the sum of booked vertical moments by the sum of booked currents; it does not call the solve's centroid observation. The solved radial centroids are 0.8 and 1.2 m, so their measured radial extent is 0.4 m; the solved vertical extent is 0.72 m. Their ratio gives elongation 1.8, above the asserted 1.6 floor. The free-height expectation is independently computed from the seed's booked moments (0.6 m), so changing the residual's free-height constant alone breaks the check. The restoring row weakens as 1/κ².
